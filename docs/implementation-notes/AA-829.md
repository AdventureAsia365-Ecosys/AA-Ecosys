# AA-829 — implementation notes (root repo)

Scope of this note: the S248 DRY RUN of the 2026-09-16 real-data dumps and the DSN CNAME prerequisites. The PITR
drill (S241) is recorded in `docs/audits/2026-10-17-S241-restore-drill/`.

## Decisions

- **Recommend deleting the dumps (option A), not moving them.** The same 16/09 point in time already lost its RDS
  snapshot by Nghiệp's S241 decision (AA-869), the reset audit is closed, and the files hold password hashes, tenant
  webhook auth headers and TripPlanner customer contact data with no current use. Option B (dedicated SSE-KMS bucket)
  is written out in full in case Nghiệp wants to keep them.
- **No "locked prefix" in bronze.** The CIS task role's S3 Allow is `Resource = "*"`, so only an explicit bucket
  Deny keeps the containers out; a dedicated bucket keeps the bronze policy untouched.
- **Repo-wide ignore patterns for dump formats** (`*.dump`, `*.pgdump`, `*.sql.gz`, `*.sql.zst`, `*.backup`) while
  root is public: gitleaks does not look inside binary dumps.
- **Cell values were not inspected.** Sensitivity is judged from DDL and row counts only.

## Changed

- `docs/audits/2026-10-23-S248-aa829-dumps/README.md`: DRY RUN record, options, commands, DSN CNAME checklist.
- `docs/audits/2026-10-23-S248-aa829-dumps/SHA256SUMS`: hash manifest of the six files (deletion evidence).

## Tradeoffs

- Deleting loses the only copy of the pre-reset derived rows (~21.6k). Accepted in the recommendation because the
  RDS snapshot of the same moment was already deleted on purpose.
- Option B costs about 1 USD/month for a customer managed key; `aws/s3` is free but its key policy cannot be narrowed.

## Should know

- The S3 sweep for stray copies (audit §6) was not run: the MFA session had expired. Run it before deleting.
- DSN CNAME: `set-password` in `db/run_migration.py` requires every role secret to use the same host as the master
  secret, so all six DSN secrets move in one window. No client verifies the TLS hostname today.
- `docs/STYLE.md:105` still calls the root repo private; ADR 0014's S247 amendment made it public (not changed here).
