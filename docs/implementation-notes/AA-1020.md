## Decisions

- **Live reads on 2026-11-01, read-only:** STS; ECS services and task definitions (env names only: `LLM_DAILY_PROBE`,
  `CRM_LLM_*`, `SCRUB_GUARDRAIL_*`); Lambda list; EventBridge Scheduler; CloudFront aliases; ElastiCache; S3 bucket
  count; ECR repositories; KMS aliases; Cognito pool names; Bedrock guardrail list; Secrets Manager secret NAMES under
  the AI providers (no value read); and in the management account (profile `aa-mgmt`) Organizations (feature set,
  accounts, OUs, SCPs and their targets), the CloudTrail trail, Identity Center instance, permission sets and groups,
  budgets and anomaly monitors. IAM reads in the management account were not run (the subagent guard blocks
  `aws iam`), so the management CI roles are described from Terraform, not checked live.
- **Management state stated as live:** organization with all features, OUs NonProd / Prod / Suspended, the three
  `aa-scp-*` SCPs on each OU (only `FullAWSAccess` on the root), org trail `aa-org-trail` (organization, multi-region),
  Identity Center with 3 groups and 4 permission sets, budgets `aa-org-monthly` and `aa-management-*`, the default
  services anomaly monitor; the management account is the only member.
- **No account ID anywhere** (all repos are public): the onboarding page now says the management ID is read with
  `aws sts get-caller-identity --profile aa-mgmt` instead of adding it to the account map, which ADR 0018 had planned.
- **New page** `docs/architecture/ai-gateway.md` (`ARCH-01-ai-gateway`, `status: draft` until the tech lead reads it):
  callers, Mermaid, registry v2, routing, guards, ledger v2 and observation, shared core, live / planned table.
- **New diagram** `gateway.py` / `gateway.svg` and redraws of ecosystem, infra, cis, tripplanner and partner, rendered
  with Graphviz 2.42 unpacked without root (`apt-get download` + `dpkg -x`) and `diagrams` in a scratch venv; every
  view prints 0 layout problems and `render.py --check` passes.
- **DM-10.4 → data standards v1.10:** the amendment is the one ADR 0009 decision 8 already made (accepted 31/10), written
  as built; no other rule changes.
- **Route table:** the snapshot was not re-captured (that needs ECS exec); only the generator's header text now names
  AI providers › Routing, and the page was re-rendered from the same snapshot (`gen_llm_routes.py check` passes). CIS
  320–324 add no route row, so the routes are unchanged.
