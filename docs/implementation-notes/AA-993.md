## Decisions

- **C6.3a / DM-11.4 (G5).** A backend deploy waits only while a CIS rerun wave is open (CIS deploys) or a
  deploy-blocking kind of the deploying owner runs, or is queued and due within 15 min (review follow-up: the guard runs
  before the image build and the old task would claim such a row before its SIGTERM). The deploy-blocking kinds are named per app in C6.3a (CIS
  `data_erasure`, `s1_batch_ingest`; Booking the two retention kinds; Partner `crm_dispatch`). DB Migrate and instance
  changes keep the all-job-tables-idle rule (C6.3b unchanged; ADR 0017 relaxes it for expand files later).
- **ADR number 0017, not 0016.** The design draft called its ADR "0016"; that number went to the UI kit ADR (AA-994).
  ADR 0017 covers design D2 only (the task asked for the migration-flow ADR). D1 (drain + guard), D3 (verify), D4
  (merge queue), D5 (hooks) are slices under the data standards and need no ADR; ADR 0017 has a numbering note
  explaining that code comments citing "ADR 0016 D1 / D3" mean the AA-993 design draft.
- `skill/aa-ship` §2 keeps Vietnamese (the skill is written in Vietnamese).
- **Review follow-up: other root texts brought in line** with C6.3a: `docs/glossary.md` (Deploy gate row; it now
  matches the handbook glossary), `docs/guides/devops.md` (gate column for CIS, Booking, Partner; the guide is English
  only today, so no second language was added), `docs/ecosystem-architecture.md` (CIS and Booking deploy bullets),
  `skill/aa-wave-rerun/SKILL.md` §3 (the old line said CI blocks only on jobs, now the opposite: it blocks on an open
  wave), `skill/aa-ecosys-repos/references/cis-app.md` (Deploy line), and a dated note on the `docs/backlog/README.md`
  session rule. The runbook, aa-ship §2, DM-11.4, C6.3a and the handbook row also gained the due-within-15-min clause.
