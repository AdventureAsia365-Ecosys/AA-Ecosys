## Decisions

- **Two commits, one PR.** Commit 1 fixes facts and moves stray files. Commit 2 is the data standards v1.1
  text plus the restated merge rule in `.claude/CLAUDE.md` and the steering. The reconciliation (§5.1 item 3)
  asks for DM-11.5, the approval table, CLAUDE.md and steering in the same PR, and N-1 says Nghiệp approves the
  v1.1 wording, so commit 2 can be dropped or reworded alone without touching commit 1.
- **Stray `docs/` files go to `docs/archive/2026/`, not `docs/ops/`.** None of them is current: the CIS data
  reset ran on 16/09 (S183), the AA-603 DROP ran on 21/09 (S191), the org rename and its G5 trust removal are
  done (AA-588), the SSM-tunnel design needs a bastion that was terminated in S186 (AA-602) and does not exist
  today (EC2 list on 19/10: only the NAT instance), and the Booking hand-off draft is superseded by the live
  intake (`bk-002`, `bk_inquiry_pull`). Each moved page and script got an "Archived" banner; `db-tunnel.sh`
  lost its executable bit and `g3-remote-update.sh` is marked do-not-run (its paths are relative to the old place).
- **Journals are not rewritten.** Session logs and audits that cite the old paths keep them (they describe what
  was true then). Only current pages were relinked: README, ecosystem-architecture §6/§7, ERD v2 README,
  ecosystem-review §6.2 note, `skill/aa-ecosys-repos/references/tripplanner.md`.
- **Account IDs stay in `.claude/CLAUDE.md` and steering.** The docs standard (proposal §2.3 rule 5) exempts
  agent-instruction files: an agent needs the account map at start-up and cannot follow a link then.
  Resource IDs that change (API Gateway id, pool ids) were removed from CLAUDE.md in favour of names.
- **ecosystem-architecture §5** now lists the five per-job OIDC roles from `cicd_split.tf`, `booking.tf`,
  `tripplanner.tf` (read on Infra `main`, 19/10) and refers to Terraform locals for the exact subjects instead
  of repeating org/repo ids in prose. The Mermaid diagram no longer shows the retired `aa-cis-dev-role`.
- **Data standards v1.1 scope (U-09 remainder + the items the reconciliation names):** DM-11.5 + approval-table
  note (D-13), DM-8.4 / C2.3g / Part A SEC-10 and §9 row (D-12, already shipped as CIS #792), DM-7 log-group rows
  and C4.2b 365 days (D-09, AA-872), DM-11.2 (generated reference), DM-1.2 (`owners.yaml` exists, Infra #163),
  status facts C4.2a, C7.1, DM-9.1. Every "Exists" claim was checked the same day against Terraform on Infra
  `main` and read-only AWS calls (below).
