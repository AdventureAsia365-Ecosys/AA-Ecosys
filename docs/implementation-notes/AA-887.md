## Decisions

- **Front-matter = proposal §2.1** (reconciliation K-29a-c, correction 16): `last_reviewed` (underscore), status
  adds `archived`, audience = `owner`, `staff`, `engineer`, `devops`, `cto`, `cio`, `pm`, `agent`. `owner` is
  Ms. Thư (CEO); no separate `ceo` value so the same reader never has two names.
- **Schema extras beyond the task list**: `description` (pro-practices §5.9, recommended for agents), `tested_where`
  and `generator` (proposal §2.1). Conditional rules: `superseded_by` required when `status: superseded`,
  `generator` required when `generated: true`. `additionalProperties: false`, so `last-reviewed` (hyphen) fails.
- **ID pattern** `PREFIX-NN(-suffix)*` with prefixes CAT, ARCH, APP, OPS, PROD, SEC, FIN, GUIDE, TPL, PLAT. A page
  that is one of several under one entry adds a suffix (`ARCH-08-scaling`, later `OPS-02-cis`).
- **Catalog IDs for the new rows** (reconciliation §4 G-01…G-21): GUIDE-04 CEO (bilingual), GUIDE-05 DevOps,
  GUIDE-06 CTO, GUIDE-07 PM, GUIDE-08 add-a-new-app, GUIDE-09 CIO, GUIDE-10 new engineer, GUIDE-11 `llms.txt`;
  ARCH-09 Dead Table Registry; APP-08 connection budget; APP-09 job kinds; OPS-08 capacity+cost review;
  OPS-09 data subject request; OPS-10 break-glass; OPS-11 isolation probe; SEC-05 access review; SEC-06 page
  placement (a STYLE section); PLAT-01 U-xx status (backlog section); CAT-00 the catalog; TPL-02 STYLE; TPL-03 schema.
- **Role guide paths follow the task brief**: `docs/guides/{ceo,new-engineer,devops,cto,cio,pm}.md` and
  `docs/agents.md`. The reconciliation table proposed `ops-onboarding.md`, `cto-cio-brief.md`, `pm-guide.md` and a
  combined CTO/CIO brief; the brief splits CTO and CIO and uses short names, so the catalog lists those.
- **`docs/onboarding.md` stays GUIDE-01** (correction 16) and holds the only account-map table; the new-engineer
  role guide (GUIDE-10) links to it instead of repeating access steps. Links in STYLE/glossary/runbook template
  point to `onboarding.md#account-map`, so the guides lane must use the heading "Account map".
- **CEO guide lives in `docs/guides/ceo.md`** (brief), not `docs/business/` (K-29g). `docs/business/` is kept for
  owner-facing reports (release notes, cost summaries). Drive holds PDF exports only.
- **FIN-02 merged with OPS-08** (K-05, correction 11): one monthly "cost and capacity review" saved to
  `docs/audits/<date>-S<nnn>-capacity-review/` (C8a), reading `shared.cost_explorer_snapshot` and
  `shared.llm_call_log`; the template carries the C8b checklist. No `docs/ops/cost/` folder.
- **`last_reviewed` on existing docs = the date of their last commit** (2026-10-15 to 2026-10-18), not today: this
  PR did not re-check their content against the live system (STYLE rule against fake freshness).
- **Titles match the H1** exactly (YAML-quoted when the H1 contains a colon).
- **ADR template has no front-matter** and copies the style of the accepted root ADRs (0004b, 0006a, 0008):
  `# ADR NNNN — Title`, Status/Scope/Amends/Implements/Design/Related bullets, Context, Decisions, Consequences
  (Positive / Negative-cost), Alternatives, Follow-ups. Not the older `ADR-2026-NNN` format in
  `skill/ai-nghiep/references/adr.md`.
- **Skill edits stay in Vietnamese** (the skill files are Vietnamese); the DoR template itself is English because
  Linear issues are English.

## Tradeoffs

- **Templates validate against the schema** (placeholders such as `replace-me`, `OPS-00-replace-me`), so a copied
  template is a valid draft from the start. Cost: a lint must not treat `docs/templates/` as catalog pages
  (AA-888 should skip IDs ending in `-replace-me` or the folder).
- **markdownlint MD025** flags front-matter `title` + H1 as two titles. Keeping both is intentional (agents read the
  title without parsing Markdown); AA-888 should set `MD025: {front_matter_title: ""}`.
- **Catalog in one page** (wide tables) rather than one page per area: one place to keep in step, and AA-898 can
  read the allowlist from it. If it grows past ~80 rows, split per area.
- **No new section folders** (`docs/ops/runbooks/`, `docs/security/`, `docs/guides/`): created by the lanes that add
  real pages (pro-practices: no empty tree).
