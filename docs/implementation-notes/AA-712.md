# AA-712 — Implementation notes (root repo, lane: ADR)

Design: `docs/audits/2026-10-14-S236-design-review/aa712/03-design.md` (approved by Nghiệp, S236, all
recommendations Q1–Q7). This file covers the root-repo docs lane; code lanes keep their own notes in
their repos.

## Decisions
- ADR number **0007**, not 0006 as the design says: 0006 is ecosystem identity (Cognito).
- Status "Accepted 14/10/2026 S236"; implements ADR 0002 (consequence 1); amends nothing else.
- Geocoding first written **provider-neutral** (adapter + "storage rights required") while the provider
  was open. **Updated S236 after Nghiệp's decision:** decision 9 now names **Geoapify** for all
  countries (Mapbox basemap only, Amazon Location not used), with the bake-off acceptance rule
  (top-3 scan, name similarity + result_type + 25/50 km distance; `rank.confidence` recorded, not a
  gate), the `located_by='llm'` area-precision fallback, rate/credit guard, secret
  `aa-cis/dev/geoapify`, `model_only` kept for tests/emergency, and the attribution requirement.
- Rejected providers get one line each in the ADR (Amazon Location: city-only results + unsupported
  countries + Japan storage ban; Mapbox Permanent: Product Terms §2.7.3). Google, OpenCage and
  Nominatim stay in the research doc only.
- The ADR keeps the acceptance rule as a summary; the full scoring table stays in `05-geocoder-bakeoff.md`.
- Model choice recorded as approved: Sonnet for `a3_place_days` with GPT-5.6 Luna 20% shadow, Sonnet for
  `a3_place_locate`, cohere-embed-v4 1536-d for `a3_place_embed`.
- Destinations / `geo.place_name` key fixed as **`(name_norm, country, locality_norm)`**, `locality_norm`
  `NOT NULL DEFAULT ''` (non-empty only for generic names) and `country NOT NULL` (review r1, finding 1–2):
  the design (§2.2, §4) said `(name_norm, country)` and "generic names keyed with a locality", which cannot
  both hold on one unique index; a NULL country would also slip past it.
- Batch gate recorded as automatic between ≤ 50-tour batches (thresholds from design §7c).

## Tradeoffs
- The ADR summarises; numbers (cost, caps, thresholds) that may move after the trial point back to the
  design doc rather than being duplicated in full.
- Cost: geocoder priced $0 (Geoapify Free, 3–4 days of quota for the backfill); API 10 ($59/month)
  named as the paid fallback instead of re-opening the provider choice.
- Kept the provider's Free-plan risk (no SLA, terms may change) as a consequence rather than a blocker:
  provider + `geocoded_at` per row make a switch a re-run job.
