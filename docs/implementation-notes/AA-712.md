# AA-712 — Implementation notes (root repo, lane: ADR)

Design: `docs/audits/2026-10-14-S236-design-review/aa712/03-design.md` (approved by Nghiệp, S236, all
recommendations Q1–Q7). This file covers the root-repo docs lane; code lanes keep their own notes in
their repos.

## Decisions
- ADR number **0007**, not 0006 as the design says: 0006 is ecosystem identity (Cognito).
- Status "Accepted 14/10/2026 S236"; implements ADR 0002 (consequence 1); amends nothing else.
- Geocoding written **provider-neutral** (adapter + "storage rights required"): the approved decision
  leaves the provider open between Amazon Location (intended use `Storage`) and Mapbox Permanent. The
  design's Mapbox-specific details (secret name, `permanent=true`) are kept only as one option.
- Model choice recorded as approved: Sonnet for `a3_place_days` with GPT-5.6 Luna 20% shadow, Sonnet for
  `a3_place_locate`, cohere-embed-v4 1536-d for `a3_place_embed`.
- Destinations / `geo.place_name` key fixed as **`(name_norm, country, locality_norm)`**, `locality_norm`
  `NOT NULL DEFAULT ''` (non-empty only for generic names) and `country NOT NULL` (review r1, finding 1–2):
  the design (§2.2, §4) said `(name_norm, country)` and "generic names keyed with a locality", which cannot
  both hold on one unique index; a NULL country would also slip past it.
- Batch gate recorded as automatic between ≤ 50-tour batches (thresholds from design §7c).
