# AA-1021 — Architecture video pipeline, public-content gate and the Ep1 pilot

Slice of the S262 plan (`docs/audits/2026-11-01-S262-arch-video-plan/README.md`, steps 6-9) built in S264 lane l8.
Code only in this repo (`tools/uat/arch/`); the deny-list, the episode script with its diagram sketches, the blog
draft and every render stay outside git.

## Decisions

- **Per-episode sketches, not the committed diagrams (fix pass).** The first build relabelled the committed
  `docs/architecture/diagrams/*.svg` through a private label profile. Review found that this keeps every node position,
  icon, frame and arrow route of a figure that is public in this repo: a visual fingerprint no text layer can see. Now
  each episode carries hand-built sketches (`sketch.py`: groups on a grid, nodes, edges, drawn as plain SVG with
  neutral `n<i>` keys, no icons), and `scene.load` refuses a diagram given as a committed SVG name. The label profile
  (`labels.py`) is gone. The SVG keeps the Graphviz-like structure (`g.cluster` / `g.node` / `g.edge`, labels as direct
  `<text>` children, `data-k` / `data-from` / `data-to`), so `page.py` reveal / focus / highlight work unchanged.
- **Every drawn label goes through the full layer 1 (fix pass).** `make_episode.layer1` reads the text back from each
  rendered sketch, one entry per label (so a 5-gram never runs across two labels), and checks it like narration:
  deny-list, identifier shapes, n-gram phrases and internal-looking tokens. The multi-word labels feed the label-set
  check; cloud product names ("Amazon ...", "AWS ...") are left out of that count because they sit together on every
  architecture page.
- **Hyphenated tokens (fix pass).** The corpus tokenizer splits on '-', so a hyphenated script token could never match.
  Internal-looking tokens are now matched with one regex over the lower-cased corpus text (not through the tokenizer),
  bounded by non-alphanumerics, so a token also matches as a prefix of a longer identifier (`x_y` in `x_y_z`). Any
  hyphenated token of 2+ parts is internal-looking unless it is an ordinary English compound (`GENERIC_HYPHENATED`)
  or a single-token line of the allow-list.
- **Identity check (fix pass).** The series name, the on-screen series tag (minus "Ep N") and any `identity` phrase of
  the episode must not appear in any public file at all, however short: they are what a viewer types into a search.
- **Public gate summary only (fix pass).** `gate-summary.md` (layer, status, hit count) is the only gate output that
  may be copied into a repo; cut lengths, the build date, counts and tool versions stay in the private gate folder.
- **Keyframes, not screen recording.** `capture.cjs` shoots each distinct visual once per aspect at deviceScaleFactor 2
  and `video.py` joins them with cross-fades; labels stay sharp and the encode is crf 19.
- **Camera frames the revealed core.** With `reveal`, the view zooms to the revealed groups and nodes (not their
  enclosing account / VPC frames); `focus` overrides it. Without it a 2900-pt diagram is unreadable at 1080p.
- **One voice per sentence**, defaulting to scene-by-scene alternation (F first in odd episodes), only the two
  approved local voices accepted; each clip is loudness-normalised in two passes (-16 LUFS, linear gain) and cached by
  a hash of voice + text.
- **Gate layer 1 runs before any TTS**, so a failing script costs nothing. N-gram size 5 with 2+ content words: size 4
  flagged common English idioms found in unrelated audit JSON; size 5 kept the real echoes (the plan's own episode
  titles, a sentence of an ADR).
- **Label-set check (new, not in the plan).** One public file holding 4+ of the multi-word labels on screen is a
  hit. The plan page itself was the only such file: it listed the public labels and the episode outlines, so the
  combination on screen would have led back to this repo.
- **Plan page redacted in this PR** (separate commit): the episode list, scene outlines and the label mapping example
  were replaced by a pointer; the full original is kept with the private series files.
- **Gate logs and REVIEW.md sit beside the publish folder** (`<slug>-gate/`), not in it: they are for the team, are not
  scanned by layer 4, and a checklist naming risk words would otherwise trip the deny-list.
- **Chapters**: `-map_metadata -1` also blanks chapter titles in ffmpeg 6.1, so a master with chapters takes its
  (empty) global block from the ffmetadata file instead; the only tag set is the neutral title either way.
- **OCR**: tesseract 5.3.4 unpacked from the Ubuntu archive with `apt-get download` + `dpkg -x` (no root), run with
  `--psm 11`; layer 3 reports SKIPPED with a warning when it is missing.
  Fix pass: the text is rebuilt from TSV output and words lower than 5 px are dropped; a 2 px dashed edge of the new
  sketch read as a currency amount, and no viewer can read text that small.
- **CI**: the stdlib gate tests run in Docs lint (path filter `tools/uat/arch/**`); TTS, browser, ffmpeg and OCR stay
  local.

## Changed

- The series and episode titles differ from the plan's: the plan's wording is public in this repo (and in its history),
  so the n-gram layer rejected it. The on-screen series tag and hashtag were changed again in the fix pass: the first
  wording also appears in committed backlog and session files.
- Diagrams: sketches instead of the plan's "public label profile" over the committed SVGs (Step 6), see Decisions.
- The X and LinkedIn cuts come out a little shorter than the plan's targets; the length rules still hold.
- Ep1 draws one sketch of the whole platform; the next episodes each author their own sketches.

## Tradeoffs

- The n-gram corpus is every tracked text file of the root repo and the four app repos plus Infra (about 9 s per run).
  It reads the local checkouts, which can lag origin; run it after a pull.
- Fuzzy OCR matching (edit distance 1) applies to deny terms of 6+ letters only; short terms are matched exactly to keep
  OCR noise from failing builds.
- Sketches cost authoring time per episode and simplify the real views; in return no frame matches a committed figure,
  and a sketch only shows what the episode says. Layer 5 checks a sketch against the facts.
- Hyphenated tokens: counting every non-generic hyphenated word as internal-looking can flag an ordinary compound that
  also appears in a public file; the fix is one line in the private allow-list, which is cheaper than a missed coined
  name.
- The voice IDs and the font stay as constants in the code (the tool needs them); they are among the most common
  defaults of their tools, so they do not single out these videos. Prose here and in the README keeps them generic.
- Text removed from the plan page remains in git history; the redaction lowers discoverability, it does not erase it.

## Should know

- Build: `tools/uat/venv/bin/python -I tools/uat/arch/make_episode.py <ep.json> --out <dir>` with
  `ARCH_VIDEO_PRIVATE` pointing at the private folder; setup in `tools/uat/arch/README.md`.
- The Ep1 pilot was gated against this branch's root repo (`ARCH_VIDEO_ROOT_REPO`): the plan-page redaction must be
  merged before any upload. It was rebuilt in the fix pass with the sketch, the new series wording and the stricter
  layer 1.
- Committed files that still name the old series wording (backlog row, tracker title, S262 session log) are records
  of other sessions; the on-screen wording no longer matches them, which the identity check enforces for every build.
- Layer 5 is open: an independent review agent reads the script and post with `REVIEW.md`, then the tech lead watches
  all four cuts.
