## Decisions

  shape AA-Booking also serves (`GET /booking/ops/checks`); the CIS alerts catalogue reads both with the staff member's
  own token (no cross-schema read).
- Tagging standard: optional keys `Severity` (`page` | `ticket`) and `Mutable` (`true` | `false`), required on alarms and
  SNS-notifying rules by the Infra source guard; the machine copy `tools/terraform/tag_policy.json` gets the same
  patterns in the Infra PR.
- Incident response: an "Alert severity" section (page / ticket rule, page topic, alert severity vs SEV).
- Guides (devops, CIS admin runbook EN + VI, app access EN + VI): Platform › Alerts (Catalogue, Recipients) instead of
  "Alert recipients"; in-app thresholds are settings.
