## Decisions

- **Catalog ID GUIDE-14 for the playbook** (suffix per page, `GUIDE-14-setup` etc.). The Setup page fills the planned
  GUIDE-08 slot by pointing its catalog row at `playbook/03-setup.md`, instead of giving one page of the family a
  different ID.
- **Gap 7 rules went into the handbook operating model, not into skills**: the handbook is the operating model and
  the playbook principles link to it. The AA-1104 lane (Academy gap G5) wrote "decide, don't ask" and "no agent-made
  gates" as section 2.4 in the same session, so this branch is **stacked on that lane's commit** and adds the other
  five as section 2.5 (W3 to W7, numbering continued from 2.4's two rules). The two habits "do it, do not remind" and
  "finish before closing" are one line under the table, not rules of their own.
- **FinOps acc1 layout and DM-11.1 (gap 8)**: the AA-1104 commit already fixed both (data standards v1.14), so this
  branch keeps its version and adds nothing there. The other gap-8 items (role-guide language in `ai-nghiep`, PR-title
  coverage in `aa-linear-issue`, the audits index note) are this branch's.
- **ADR 0011 and 0014 were amended, not accepted.** Accepting an ADR is the tech lead's act; the amendments record the
  approved D13 (public `project-template`) and the six-repo scope. Status stays Proposed with a line saying the practice
  runs daily. The acceptance is listed as a live step for the tech lead.
- **Template front-matter** follows the existing pattern: a template for a filled document carries the placeholder ID
  of that document (`PROD-00-charter-replace-me`); a template that is itself a reusable checklist carries a `TPL-01-*`
  ID (release checklist, retirement checklist, session checklist, migration file, settings entry).
- **No `.vi.md` for the two templates without front-matter** (`adr-http-api-conventions.md`,
  `implementation-note.md`): ADRs and journals carry no translation (STYLE, Language).
- **Agent-ready SDLC recommendations taken into R2a:** 1 (path field in the DoR), 2 (Plan section in the implementation
  note template; the hard diff check stays for AA-1103 / `lane.js`), 6 (lesson scope tag, described in `agents.md`),
  7 (decision page format, in `agents.md`). Left for later: 3 (failing-test-first git check), 4 (CI-written verified-live
  receipt), 5 (instruction budget lint).
