## Decisions

- The report lives in `docs/audits/2026-10-28-S255-aa838-capacity/` (Vietnamese, audit for Nghiệp, N-7). Later monthly
  reviews use `docs/audits/<date>-S<nnn>-capacity-review/` and the new template `docs/templates/capacity-review.md`;
  quarterly access reviews use `docs/templates/access-review.md` (shaped on the S245 review).
- The probe ran once through ECS exec as `cis_app` (no `pg_read_all_stats`), so TripPlanner / Booking / tenant-pool
  SLIs are scored per role, not per statement. Granting `pg_read_all_stats` to `cis_app` is not proposed (DM-6); full
  text comes from the same script through DB Migrate `run-script` (D6, D12).
- Retention windows were taken from the CIS code (`services/retention/policy.py`), not from the probe's own map.
- The first weekly C4.3 paragraph ("C4.3 tuần W44") is section 5a of the report; the orchestrator links it from the
  S255 session log.
- C2.2 fix is a facts-only change: data standards v1.6, changelog row, no rule change.

## Tradeoffs

- p95 from `pg_stat_statements` is `mean + 2 × stddev` (C1.1b); it overstates p95 for skewed statements (one 45 s
  advisory-lock wait). Kept, labelled as approximate.
- Cache hit (99.05 %) is cumulative since instance creation, including the `t3.micro` period; the weekly check should
  use the delta between two probes.
