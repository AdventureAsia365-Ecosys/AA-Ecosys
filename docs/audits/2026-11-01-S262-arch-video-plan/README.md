Rules: (1) write the scripts in generic industry vocabulary and avoid coined terms (atom, slate, segment, wave, A0-A4, T0-T11, Model Gateway, shared.job, aa_llm, llm_call_log, Content studio, break-glass as a named feature); (2) never commit the narration scripts, storyboards, public labels or rendered videos to any public repo (keep them in .tmp-session / Drive); (3) run an automated n-gram check that flags any 3+ word phrase or rare token from the script that appears verbatim in apps/, docs/ or infra/ and is not on a generic whitelist.
- GATE LAYER 1, source: a gitignored deny-list (brand and people literals plus case-insensitive word-boundary regexes) plus the GUARD_PATTERNS from tools/docs/build_docs_reader.py and the redact() patterns from lib/dryrun-core.cjs (12-digit IDs, ARNs, VPC/SG/subnet, pool IDs, execute-api IDs, access keys) plus the repo n-gram check. Runs over the scene JSON, narration, slide specs, YouTube/X/LinkedIn descriptions and hashtags.
- GATE LAYER 2, DOM: before each keyframe capture, Playwright asserts that document.body.innerText, every SVG <text>/<title>/<desc>, alt, aria-label, data-* attributes and any embedded href/src contain no deny-list hit. The AWS icons are inline base64, with no external references. This check is exact and is the primary pixel-level guard.
- GATE LAYER 3, pixels: OCR on every keyframe PNG plus one frame every 2 s of each final MP4, per aspect ratio, with fuzzy matching for 'AA' and hostnames. Tool: rapidocr-onnxruntime in tools/uat/venv ($0, no sudo; onnxruntime is already there), or tesseract via apt-get download + dpkg -x. OCR is a second layer only.
- GATE LAYER 4, artifacts: SRT/VTT, chapter titles, file names, zip entries and the package README run through the deny-list. ffprobe -show_format -show_streams shows no title/comment/encoder tag containing a product name; encode with -map_metadata -1 and a neutral title. Audio is checked through its source text, because TTS reads the narration JSON verbatim. No ASR is installed.
- GATE LAYER 5, human: an independent review subagent reads each script for security disclosure (weak points, planned-shown-as-live, fingerprints). Then Nghiệp watches every final cut in every aspect ratio before upload. The gate result is logged per video in docs/audits/<date>-S<nnn>-arch-video/ as layer, status and hit count only (S264: cut lengths, build dates, counts and tool versions stay in the private gate folder, since they would let anyone match the repo to the videos). That folder holds no script text.
- OTHER: AWS Architecture Icons are used unmodified, with no implied AWS endorsement and no named customers. The description carries 'Narration: synthetic voice'. No music, or CC0 only. No screen recordings or screenshots of any real app. No sign-in, no Dev data and no AWS calls are needed to build the videos.
