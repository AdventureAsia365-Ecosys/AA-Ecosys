Auto-merge của agent và Dependabot đang mâu thuẫn với DM-11.5 (D-13; mặc định: chỉ người merge).

Môi trường

  • Không dựng staging thường trực; khi có prod, Dev đóng vai pre-prod.
  • Prod trên acc2 (ADR 0001), kèm biện pháp bù: role/trust OIDC riêng, KMS CMK riêng, ABAC env=prod, DB và SG riêng, state key riêng, agent không có quyền prod.
  • Giới hạn: không áp được cho principal từ management account TrueIDC.

CI/CD

  • concurrency theo service, guard fail-closed, smoke theo contract, rollback bằng task-def revision trước.
  • Dependabot gom PR hằng tuần; audit/Trivy chặn build với ignore có hạn; CodeQL trên repo public, gitleaks trên private.
  • Build once theo digest, attestation, reusable workflow: P2.

Secret

  • Nguồn sự thật: Secrets Manager (runtime) và GitHub env secret.
  • Register docs/security/secrets-register.md; xoay ngay khi nghi lộ.
  • OIDC, GitHub App token, Vercel token chỉ ở env production. Không PAT cá nhân trong CI.
  • Agent không đọc secret runtime, không đọc ~/.aws/**.

API

  • Bây giờ: kiểm role ở backend, cô lập tenant fail-closed, rate-limit login, WAF và throttle, security header, khoá docs.
  • Khi tenant tích hợp: OpenAPI /v1, problem+json, Deprecation/Sunset, idempotency key.
  • Đích: Cognito (ADR 0006), deny-by-default, bỏ god-key.

Quan sát và hỗ trợ

  • Sentry 3 app; log JSON có request ID; alarm 5xx/latency mỗi API; uptime ngoài.
  • Trước tenant đầu: quy trình sự cố một trang, SLA gọn, support@ vào Linear, status page free.
  • Khi có prod: SLO burn-rate, dashboard, release-please, CHANGELOG.
