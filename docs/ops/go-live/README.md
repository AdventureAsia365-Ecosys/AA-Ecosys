# Go-live gate

Prod opens to real users only when every line below is met. The list is the single gate: the eight items of the
[ADR 0012](../../adr/0012-environment-model.md) go-live gate (decision 11), plus the proofs a first real agency needs
that the S282 ecosystem audit found spread over many issues (price coverage, the Booking restore drill, a load test,
edge rate limits, a capacity baseline, the enforce_admins plan, no real personal data before the DPA, the AI caps at
prod), and one line for the go-live date.

## How the gate works

- **Source:** [`checklist.yaml`](checklist.yaml) in this folder. Edit that file, never the table below.
- **A line is met** when it links a proof: a repo path (optionally with a `#heading` or `#L<line>` anchor) or an https
  URL. Evidence that exists but does not prove the line (a Dev drill for a prod item, a method to copy) goes under
  "Evidence so far" and does not count.
- **An open line** names an owner role (tech lead, business owner or engineer on duty) and an ISO due date.
- **The go-live date line** may stay unset only with an owner. Once the date is set, every open line must be due on
  or before it, and the gate fails if the date arrives with lines still open.
- **The guard** is `tools/ops/golive_gate.py check`, run by the Go-live gate workflow on every pull request that
  changes the checklist or the tool, and weekly on Monday. It fails on a dead proof path or anchor, an unknown owner
  role, an open line past its due date, a missing owner or due date, and a table below that no longer matches the
  checklist.
- **After an edit:** `python3 tools/ops/golive_gate.py render --write` rewrites the table, then
  `python3 tools/ops/golive_gate.py check` must pass.

The due dates were set on 2026-11-25 as planning dates while no go-live date exists. When the business owner sets the
date, re-date every open line in the same pull request.
