# Which source wins

**Objective:** find where each kind of process state lives, and say which source wins when two of them disagree.

AA-Ecosys keeps its process state in a few places on purpose: the order of work, the state of each issue, what
happened in a session, what the business owner was told and how a task is done each have one home. Every other place
only links there. When two places still disagree, a fixed order decides, so nobody has to guess and nobody picks
silently.

Read the two sections shown with this lesson:

1. The engineering handbook's table of the sources of truth for process state, and the precedence line under it.
2. The session rules on sources of state: what to read first, and what to check live before acting.

## Check yourself

- Where does the order of work live, and where does the state of one issue live?
- The repo says one thing and an agent's memory says another. Which wins, and what else do you do?
- A deploy status in last week's audit looks right. Can you report it as the current status?
