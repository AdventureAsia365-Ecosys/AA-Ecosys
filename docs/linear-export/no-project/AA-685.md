# AA-685 — [Gateway P1b] Move the 5 unlogged model call sites + TripPlanner behind the gateway (cost log for every call)

Split from [AA-659](https://linear.app/aa-ecosys/issue/AA-659/gateway-p1-stage-routing-for-every-call-site-acc3-first-fallback-chain) (Nghiệp, 28/09, S200).

## Why

These call sites bypass `LLMClient` and write **no** `shared.llm_call_log` row. External Spend is therefore lower than the AWS bill (the [AA-635](https://linear.app/aa-ecosys/issue/AA-635/be-llm-call-log-under-reports-bedrock-spend-vs-aws-bill-acc1-99percent) gap).

| Call site | Model | Account |
| -- | -- | -- |
| `services/export/handler.py` (`invoke_claude` direct) | Haiku / Sonnet | acc3 / acc1 |
| `shared/llm_client/column_mapper.py` (A0, raw boto3) | Haiku 4.5 `us.` | acc2 |
| `services/acp_shared/h3_rule_extractor.py` (raw boto3) | Haiku 4.5 `us.` | acc2 |
| `services/acp_shared/content_embedding.py` (F10) | Cohere Embed v4 | acc2 |
| AA-TripPlanner-Web `backend/shared/bedrock_satellite.py` (a copy) | Sonnet 4.6 compose, Cohere embed | acc3 / acc1 |

## Scope

* Each call site gets a Stage (new rows in `shared.llm_role_config`) and goes through the gateway route. Prices come from `shared.llm_model_catalog`.
* **Embeddings:** add `gateway.embed(stage, texts)`, using `api_style='embed'` in the catalog (Cohere Embed v4 priced at $0.12/1M since migration 170).
* **TripPlanner \[DECISION at build time\]:**
  * (a) a thin shared client package that reads the same catalog and route tables (read-only DB role); or
  * (b) an internal CIS endpoint.

  Either way TripPlanner's own `bedrock_satellite.py` copy goes away and its calls are logged.
* Remove the leftover hardcoded model ids. Done when `grep` finds none outside catalog seeds / tests.

## Done when

Every model call in both repos produces an `llm_call_log` row with a catalog price. External Spend for one day matches Cost Explorer Bedrock within \~5%.
