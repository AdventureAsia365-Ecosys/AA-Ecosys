# AA-623 — [Sub F][BE+INFRA] AWS Cost Explorer reconcile — đối chiếu hóa đơn Bedrock/AWS thật với cost tính từ token

## Bối cảnh (epic [AA-616](https://linear.app/aa-ecosys/issue/AA-616/epic-giam-sat-chi-phi-llmdfs-toi-uu-modelbatch-tung-stage), tách từ [AA-622](https://linear.app/aa-ecosys/issue/AA-622/sub-efebe-ui-admin-external-spend-thong-nhat-llm-theo) Sub E — Nghiệp duyệt S188)

Trang External Spend (`/admin/llm-usage`, [AA-622](https://linear.app/aa-ecosys/issue/AA-622/sub-efebe-ui-admin-external-spend-thong-nhat-llm-theo)) hiện tính chi phí **từ token/response cost** lưu trong `shared.llm_call_log` + `shared.dfs_call_log` — **KHÔNG phải hóa đơn AWS thật**. Reconcile note trên tab Overview ghi rõ: "Cross-check against Cost Explorer by hand until a CE integration is built (tracked separately)". Đây là issue "tracked separately" đó.

## Việc

Xây tích hợp **AWS Cost Explorer** để đối chiếu cost ước tính (từ token) với hóa đơn AWS thật:

1. **IAM** (terraform, repo AA-CIS-Infra): thêm permission `ce:GetCostAndUsage` cho role backend (ECS task role `aa-cis-dev-ecs-task-role`). Cost Explorer là global service (us-east-1 endpoint).
2. **Service BE:** module gọi CE `GetCostAndUsage` — group by `LINKED_ACCOUNT` (acc1/acc2/acc3) + `SERVICE` (Bedrock, ...), filter theo ngày. **LƯU Ý CE API tính phí \~$0.01/request** → phải cache (Redis/DB, refresh 1 lần/ngày là đủ), không gọi live mỗi lần load trang.
3. **Endpoint** `GET /admin/cost-explorer` trả cost AWS thật theo account + service + ngày.
4. **FE:** tab Overview External Spend — thêm cột/panel "AWS actual (Cost Explorer)" cạnh "estimated (token)" để thấy chênh lệch. Bỏ/cập nhật reconcile note.

## Ranh giới

* DFS (DataForSEO) là API bên thứ 3, KHÔNG có trong Cost Explorer — CE chỉ đối chiếu được phần Bedrock/AWS (LLM satellite acc1/acc3 + acc2 native). DFS vẫn chỉ có `dfs_call_log`.
* acc3=786888028788, acc1=867490540162, acc2=005097885195 — CE cross-account cần các account này được include trong CE của payer account (kiểm tra Organizations/consolidated billing).
