# AA-218 — [AA-193·DFS] Persist PAA + related_keywords vào seo_context (migration + handler + endpoint)

Parent: [AA-193](https://linear.app/aa-ecosys/issue/AA-193/s1-content-quality-dataforseo-keyword-sourcing-brand-differentiation). **Blocker — làm TRƯỚC** [AA-219](https://linear.app/aa-ecosys/issue/AA-219/aa-193ui-versioncompare-surface-judge-quality-audit-failure-codes) (UI surface) + [AA-220](https://linear.app/aa-ecosys/issue/AA-220/aa-193export-multi-version-compare-export-xlsxcsv-single-version-full) (export). Full DFS view cho Ms. Thư cần PAA/related persist trước.

## Vấn đề (verified S74, đọc code thật)

Ms. Thư muốn thấy **toàn bộ thông tin DFS** mỗi run: tất cả keyword_ideas + competition + volume + cpc + competition_index + **people_also_ask + related**.

`seo_context` table hiện CHỈ persist `keyword_ideas` (25 full-metric) + `top_keywords`. **PAA + related KHÔNG có cột → không persist.**

Bằng chứng:

* `/admin/tours/{id}/seo-context` (admin_pipeline.py:1623, [AA-203](https://linear.app/aa-ecosys/issue/AA-203/ui-hien-thi-dataforseo-keyword-ideas-tren-admin-s1-bang-keyword-volume)) trả `people_also_ask: []` + `related_keywords: []` cứng, note: *"seo_context schema stores no PAA/related columns — return empty, don't fabricate."*
* DFS client ([AA-197](https://linear.app/aa-ecosys/issue/AA-197/aa-193f2-dataforseo-rebuild-seed-locationactivity-buyer-market)) FETCH được PAA — verify S74 `dfs_payload.json` có 4 PAA thật ("What's the best month to visit South Korea?"...). Nhưng pipeline chỉ ghi keyword_ideas vào DB, PAA bị bỏ.
* `seo_intelligence/handler.py:101` persist keyword_ideas; PAA/related transient, mất sau run.

**Liên quan** [AA-31](https://linear.app/aa-ecosys/issue/AA-31/admin-catalog-seo-section-hien-thi-keywords-nguon-dfs-keyword-search) (Done 15/05, mô tả "Data đã có trong seo_context") — code thật mâu thuẫn. [AA-218](https://linear.app/aa-ecosys/issue/AA-218/aa-193dfs-persist-paa-related-keywords-vao-seo-context-migration) = hoàn thành phần persist còn thiếu.

## Scope

### 1. Migration (số tiếp theo — VERIFY schema_versions + migration dir trước, đừng giả định 069)

* Thêm 2 cột vào `silver_aa_internal.seo_context`: `people_also_ask jsonb`, `related_keywords jsonb` (nullable).
* INSERT row schema_versions.

### 2. Handler (`services/seo_intelligence/handler.py`)

* Đọc PAA + related từ DFS client response ([AA-197](https://linear.app/aa-ecosys/issue/AA-197/aa-193f2-dataforseo-rebuild-seed-locationactivity-buyer-market) client trả `people_also_ask` + `related` ở top-level seo_data) → persist vào 2 cột mới khi INSERT/UPSERT seo_context.
* Verify shape thật: PAA = list strings; related = có thể null (dfs_payload S74 thấy `related: null`).

### 3. Endpoint (`admin_pipeline.py:1623` get_tour_seo_context)

* Đọc 2 cột mới → trả `people_also_ask` + `related_keywords` THẬT thay vì `[]` cứng. Bỏ note "not persisted".

## Verify

* Cần AWS: apply migration + re-run 1 DFS → đọc seo_context row mới có PAA/related.
* Phase B verify (12 cell S74) sẽ tự sinh PAA mới nếu [AA-218](https://linear.app/aa-ecosys/issue/AA-218/aa-193dfs-persist-paa-related-keywords-vao-seo-context-migration) deploy trước → 12 cell có full DFS.
