# AA-67 — T-09: CIS→AAA sync job (6h) + Mobile API contract (Sanctum)

## Mục tiêu

Build CIS → AAA sync job (Laravel, every 6h) và full Mobile API contract cho Flutter app.

## CIS → AAA Sync Job (Laravel)

Sync CIS gold.published_tours → AAA.trip_plans qua cis_tour_id FK.

**8 trường sync:**

```
aa_name, aa_subtitle, aa_summary, aa_highlights (json),
aa_itineraries (text), seo_title, seo_meta, aa_quality_score
```

**Logic:**

```php
// Mỗi 6h (Laravel scheduler)
$tours = CisGoldApi::getPublishedTours(); // GET /v1/tours?status=published
foreach ($tours as $tour) {
    TripPlan::updateOrCreate(
        ['cis_tour_id' => $tour->id],
        [...$tour->aa_fields, 'cis_synced_at' => now()]
    );
}
```

**Monitoring:** CloudWatch alarm nếu sync không chạy trong 12h.

## Mobile API Contract (Laravel Sanctum)

RESTful API cho Flutter app. Tất cả endpoints trả JSON.

### Auth

* `POST /api/auth/otp/request` — gửi OTP (SNS SMS hoặc email)
* `POST /api/auth/otp/verify` — verify → Sanctum token
* `POST /api/auth/logout`

### Discovery (public)

* `GET /api/countries` — list với media
* `GET /api/destinations?country_id=X`
* `GET /api/activities?destination_id=X`
* `GET /api/trip-plans` — paginated, filter by country/style/price
* `GET /api/trip-plans/{id}` — with itinerary

### Wishlist (authenticated)

* `POST /api/wishlist/{trip_plan_id}`
* `DELETE /api/wishlist/{trip_plan_id}`
* `GET /api/wishlist` — user's saved trips

### Trip Inquiry / Case

* `POST /api/inquiries` — tạo trip_case từ trip_plan
* `GET /api/my-trips` — list user's trip_cases
* `GET /api/my-trips/{id}` — với versions

### Maps data

* `GET /api/map/destinations?country_id=X` — GeoJSON cho map pins
* `GET /api/map/activities?destination_id=X`
