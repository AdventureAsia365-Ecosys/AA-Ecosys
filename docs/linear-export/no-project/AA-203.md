# AA-203 — [UI] Hiển thị DataForSEO keyword_ideas trên admin S1 (bảng keyword + volume + competition + cpc)

## Context

1. **Verify storage trước (diagnostic):** xác định keyword_ideas/related/PAA lưu ở đâu — generated_content column? acp_run_context? seo_result blob? Cần biết để UI đọc. (Có thể chưa persist đầy đủ → cần thêm column/field.)
2. **API:** endpoint trả SEO data của 1 run/tour: keyword_ideas (bảng keyword+volume+competition+cpc), top_keywords, PAA, related, seed dùng, buyer market location.
3. **UI:** trên admin S1 page (hoặc tour detail) hiển thị bảng keyword ideas sortable (volume desc), kèm seed + buyer market. Giống Ahrefs-style view.
