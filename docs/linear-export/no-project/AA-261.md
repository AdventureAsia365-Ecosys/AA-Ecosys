### Q5 curl live — dữ liệu thật

```
root: 307 -> /login        ✅ root redirect đúng
workspace: 200             ⚠️ workspace 200 KHÔNG cookie → xác nhận 0 server-side guard (client-side only)
grep: rỗng                 ✅ HTML shell không leak secret inline
```

**403 vs 401:** không phải vấn đề — cả hai là denial. 403 nhiều khả năng từ API Gateway authorizer chặn trước backend (gotcha [AA-230](https://linear.app/aa-ecosys/issue/AA-230/review-queue-compare-vo-vi-cors-review-page-goi-backend-cross-origin): gateway trả code khác backend). Điều mấu chốt: KHÔNG fail-open.

### 2 claim mấu chốt chứng minh bằng dữ liệu

1. `workspace: 200` không cookie → client-side-only guard, không server check. Tech debt duy nhất.
2. `no-secret 403` + `bad-secret 403` → security boundary thật (backend/gateway) còn nguyên. → "public shell + protected data": shell mở nhưng data 403 = không khai thác được.

### Tech debt cần nâng cấp (KHÔNG khẩn cấp) → follow-up AA-264

* `sessionStorage` cho token (admin secret + `acp_tenant_token`): dễ XSS hơn httpOnly cookie.
* 0 Next.js middleware: chưa phải lỗ hổng vì mọi page `"use client"` + data qua API header. Cần nếu sau này có server component render data nhạy cảm.
* Nâng cấp TRƯỚC khi có B2B tenant thật đầu tiên ([AA-180](https://linear.app/aa-ecosys/issue/AA-180/epic-acp-pipeline-orchestration-s1s42-stage-runners-eventbridge-chain) orchestration xong).
