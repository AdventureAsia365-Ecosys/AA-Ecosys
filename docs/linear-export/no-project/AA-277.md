Migrate AA-CIS-App, AA-ACP-App, AA-CIS-Infra from feature→develop→main to trunk-based feature→PR→main, per ADR-2026-023 (Accepted). AA-ACP-Core excluded (package, no deploy environment).

**Reason:** CIS/ACP has only one real AWS environment (account 2). The "develop soaks for a few days" buffer isn't used in practice — failing PRs get fixed same-session, rarely sit open overnight.

**Scope per repo:**

* AA-CIS-App: ci.yml + deploy-dev.yml triggers develop→main; add main branch protection (required status check, previously had zero protection on either branch)
* AA-ACP-App: ci.yml push trigger develop→main-only; existing main protection (required check "Lint + Type-check + Build") preserved as-is
* AA-CIS-Infra: terraform-apply.yml push:develop → workflow_dispatch (manual-only apply, since private repo on GitHub free plan cannot support required-reviewer environment protection); environment dev→prod (reusing existing env, not creating new "production")

**Not in scope:** deleting the develop branch (deferred until all 3 PRs are merged and verified working on main).

Tracking issue for the 3 PRs (one per repo), to be linked as this work lands.
