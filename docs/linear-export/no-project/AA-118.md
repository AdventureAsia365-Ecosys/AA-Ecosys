# AA-118 — [HRN-13] Cost Tracking End-to-End (acp_runs.total_llm_cost_usd)

## Harness Gap: X-H2 — LLM cost not tracked end-to-end

**Mirrors CIS tech debt:** pipeline_runs.cost_usd = NULL (same root cause)

## Problem

`acp_runs.total_llm_cost_usd` is designed but likely not being populated. Each stage makes Bedrock calls but doesn't aggregate cost into the run record. Admin dashboard cost chart = flat/zero (same bug as CIS pipeline_runs.cost_usd).

## Fix

Each Bedrock call must log token usage:

```python
response = bedrock.invoke_model(...)
usage = response['usage']  # input_tokens, output_tokens
cost = (usage['input_tokens'] * INPUT_PRICE + usage['output_tokens'] * OUTPUT_PRICE)

# Write to acp_stage_runs.llm_cost_usd (per stage)
# Aggregate to acp_runs.total_llm_cost_usd (sum across stages)
```

Pricing constants: Sonnet $3/$15 per 1M tokens I/O, Haiku $0.25/$1.25 per 1M.

After fix: run Vietnam test → verify `acp_runs.total_llm_cost_usd` populated. Admin dashboard chart shows non-flat data.
