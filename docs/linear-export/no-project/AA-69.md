## Mục tiêu

Integrate Stripe/Xendit cho AAA payments + invoice generation.

## Payment flow

```
Trip Case approved → Invoice created (draft) → Customer pays → Payment recorded → Trip confirmed
```

## Tasks

1. \[ \] Invoice generation: auto-create draft invoice khi trip_case version được approve
2. \[ \] Stripe integration: payment intent + webhook handler
3. \[ \] Xendit integration (SEA markets): xendit-php package
4. \[ \] Payment status: pending → paid → refunded
5. \[ \] Admin: mark payment verified manually (trip_case_checks.payment_verified)
6. \[ \] Receipt email: send on payment confirmed
7. \[ \] Partial payment: deposit (50%) + remainder logic
8. \[ \] Refund flow: admin triggers refund via Stripe/Xendit API

## ENV vars needed

* STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET
* XENDIT_SECRET_KEY, XENDIT_CALLBACK_TOKEN

## Note

Payment integration is M4 — can be stubbed in M3 with manual 'Mark as Paid' for UAT purposes.
