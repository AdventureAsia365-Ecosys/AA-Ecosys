## Context

Meeting with Ms. Thu 19/05/2026: B2B tenants self-approve their own S2/S3/S4 content. AA team (Nghiep/Trang/Ms. Thu) ONLY reviews AA Internal runs. HITL gates v1.1 spec was AA-only — now needs to split by reviewer_type.

## Scope

### DB: Update acp_shared.acp_hitl_requests

```sql
ALTER TABLE acp_shared.acp_hitl_requests
  ADD COLUMN reviewer_type TEXT CHECK (reviewer_type IN ('aa_internal','tenant_self'))
    DEFAULT 'aa_internal',
  ADD COLUMN auto_proceed_at TIMESTAMPTZ;
    -- for tenant_self: auto-proceed after 72h if no action (configurable per tenant)
```

### Logic: Approval routing

```
IF run.tenant_id == 'aa_internal':
  → existing HITL gate flow (Step Functions waitForTaskToken)
  → reviewer: Nghiep (Gate 1), Ms. Thu (Gate 2), Trang→Ms. Thu (Gate 3)
ELSE (B2B tenant):
  → reviewer_type = 'tenant_self'
  → show content in tenant portal with Approve/Reject/Request Edit buttons
  → auto_proceed_at = NOW() + INTERVAL '72 hours' (if no action, auto-approve)
  → no AA team notification required
```

### UI: Tenant self-approval flows

#### S2 self-approval (after research completes)

* Page: /workspace/research/{run_id}
* Show: keyword clusters, market preference summary, tour visibility report
* Actions: "Approve and run Planning" / "Reject and restart"
* If confidence_score < 0.85: show warning banner, suggest adding more competitor URLs

#### S3 self-approval (after calendar ready)

* Page: /workspace/calendar/{run_id}
* Show: content calendar preview (12 weeks, 24 posts), Google Ads plan
* Actions: "Approve Calendar" / "Edit (request revision)" / "Reject"
* Approve → triggers S4 blog + S4-social

#### S4 self-approval (per blog + per tour social)

* Page: /workspace/content/{run_id}
* Tab: Blog (list of drafted blogs with preview)
* Tab: Social (TikTok + FB per tour)
* Actions per item: "Approve and Publish Draft" / "Reject" / "Request Edit"
* Approve blog → push to WordPress as draft (tenant publishes manually)
* Approve social → save to acp_gold_output.published_social

### Notification: tenant email on completion

* "Your S2 research for {country} is ready — review here: {url}"
* "Your content calendar is ready — approve to start blog generation"
* "3 blog drafts are ready for your review"
