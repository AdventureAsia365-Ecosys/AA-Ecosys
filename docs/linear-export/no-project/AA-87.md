## Context

WildKind Travel rewrote "Mountain Biking Bhutan" using generic AA voice instead of WildKind's conservation-focused voice, even though brand rules were seeded. Brand identity is NOT being injected into the S1 LLM call.

## Problem

`tenant_brand_rules.system_prompt` exists in DB but pipeline ignores it for new tenants (or possibly for all tenants). Content quality cannot improve until this is fixed — all downstream S2/S3/S4 content inherits bad master content.

## Task

1. Trace S1 pipeline code — find where LLM call is constructed for content rewrite
   * Look for: `bedrock_client.invoke()`, `anthropic.messages.create()`, system prompt injection
   * Likely in: `services/content/rewriter.py`, `pipeline/nodes/content_node.py`, or similar
2. Verify: is `tenant_brand_rules.system_prompt` being read at all during S1 rewrite?

   ```python
   # Should find something like:
   brand_rules = db.query(TenantBrandRules).filter_by(tenant_id=tenant_id).first()
   system_prompt = brand_rules.system_prompt if brand_rules else DEFAULT_PROMPT
   ```
3. Add logging at the point of LLM call:

   ```python
   logger.info(f"S1 rewrite | tenant={tenant_id} | prompt_len={len(system_prompt)} | tour={tour_id}")
   ```
4. Fix injection if missing — system_prompt must be prepended to EVERY S1 LLM call:

   ```python
   messages = [
     {"role": "user", "content": f"{system_prompt}\n\n---\n\n{rewrite_prompt}"}
   ]
   ```
5. Add validation gate:
   * If `system_prompt` is NULL or len < 100 chars → log warning + flag tour in review_queue
   * Do NOT block pipeline — use AA default voice but mark output as "unbranded"
   * Show warning in tenant dashboard: "Brand identity not configured — content uses AA default voice"
6. Re-run rewrite for WildKind "Mountain Biking Bhutan" after fix, verify brand voice applied

## DoD
