# AA-658 — [Gateway P0] Bedrock Converse provider + model catalog table (single source for admin dropdowns and pricing)

## Why

* `LLMClient` builds Anthropic-native bodies (`anthropic_version`, `invoke_model_with_response_stream`), so OpenAI-on-Bedrock models (GPT-5.6 Luna, GPT-6 Astra) cannot be called.
* Tiers are hardcoded strings (`haiku` / `sonnet` / `gpt-4.1`).
* `pricing.py` is hand-maintained.

## Scope

**Table** `shared.llm_model_catalog`**:**

* `model_key`, `provider` (`bedrock` / `openai` / `typesafe`), `vendor` (`anthropic` / `openai` / `cohere` / `typesafe`);
* `bedrock_profile_id` per account (acc3 / acc1 / acc2 / null);
* `api_style` (`converse` / `anthropic_native` / `openai_chat`);
* capabilities: streaming, temperature, seed, reasoning, max output;
* `price_in` / `price_out` / `price_cache` per 1M tokens;
* `enabled`, `notes`.

**Provider code:**

* A `BedrockConverseProvider` (Converse + ConverseStream) that plugs into the existing stream sink (ADR 0004) and cost log.
* Keep the existing Anthropic-native path behind a flag until parity is proven.

**Consumers:**

* The admin Settings model dropdown reads the catalog.
* Pricing is read from the catalog. `pricing.py` becomes a fallback only.

**Seed rows:**

* Haiku 4.5, Sonnet 4.6, Sonnet 5, Opus 5.5 (eval only);
* GPT-5.6 Luna, GPT-6 Astra;
* GPT-4.1 (OpenAI API, legacy);
* Cohere Embed v4.

Take the prices from the Bedrock pricing page at build time.

## Done when

Each seeded model can be called through the Gateway from ECS, with a correct cost row in `llm_call_log`.
