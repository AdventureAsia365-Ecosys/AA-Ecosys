## Mục tiêu

Cert-only knowledge gap cho DVA-C02. **KHÔNG áp dụng prod** — stack AA_Ecosys là PostgreSQL thuần (RDS 15 + pgvector), zero DynamoDB. Đây là học để thi, không build vào hệ thống.

## Scope học

* Single-table design (vs relational thói quen Postgres của mình — đây là điểm khó nhất khi đang quen RDS).
* Partition key / sort key, GSI vs LSI, khi nào dùng cái nào.
* DynamoDB Streams + Lambda triggers (đối chiếu với EventBridge pattern đang dùng).
* Capacity: on-demand vs provisioned + auto-scaling.
* TTL, conditional writes, transactions, optimistic locking.
* DAX caching (đối chiếu ElastiCache đang dùng).
