# AA-66 — T-06: Admin Portal scaffold — Laravel 12 + OTP auth + 8 CRUD modules

## Mục tiêu

Scaffold Laravel 12 + PHP 8.2 admin portal với authentication, base layout, và 3 modules đầu tiên.

## Tech stack

* Laravel 12 + PHP 8.2 (backend API + Blade views hoặc Vue 3 SPA)
* Laravel Sanctum cho API token authentication
* PostgreSQL 15 (DEV RDS) — blocked by [AA-65](https://linear.app/aa-ecosys/issue/AA-65/t-05-aws-db-setup-dev-rds-19-table-schema-migration)
* S3 + CloudFront CDN cho media — blocked by [AA-7](https://linear.app/aa-ecosys/issue/AA-7/legacy-image-migration-s3-cloudfront-cdn)

## Modules cần build (theo Figma 14 screens)

### Phase 1 (M2 target):

1. Auth module (OTP login — không phải password!)
2. Dashboard (overview metrics)
3. Countries + Areas CRUD
4. Destinations CRUD (with map preview)
5. Activities CRUD (geo-coded)
6. Suppliers management
7. Trip Plans (tour templates) — read-only from CIS sync + manual create
8. Trip Cases list + detail view

### Phase 2 (M3 target):

 9. Trip Case versioning (V1/V2/V3 flow)
10. Staff Assignment panel
11. Trip Case Checks checklist
12. Payments + Invoices view
13. Users management (OTP-only, soft delete)
14. File/media management (S3-aware)

## Tasks (Phase 1 only for M2)

 1. \[ \] `laravel new aaa-api` + PostgreSQL config + Sanctum
 2. \[ \] OTP auth flow: POST /api/auth/otp/request → POST /api/auth/otp/verify → token
 3. \[ \] Base layout: sidebar nav, breadcrumb, dark/light mode
 4. \[ \] CRUD: countries, areas (nested), destinations
 5. \[ \] CRUD: activities + geo-coord picker
 6. \[ \] CRUD: suppliers
 7. \[ \] Trip Plans list (read from DB, display CIS fields: aa_name, aa_quality_score, cis_synced_at)
 8. \[ \] Trip Cases list + status filter + basic detail view
 9. \[ \] Files upload component (multipart → S3, store s3_bucket + s3_key only)
10. \[ \] ENV: APP_KEY, DB\_\*, SANCTUM config
