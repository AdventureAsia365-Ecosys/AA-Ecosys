## Scope

### Services to build: `services/acp_s4_social/`

Port from Ms. Thư `content_agent.py` + `SKILL.md` + reference files:

**Core modules:**

* `brief.py` — ContentBrief dataclass, anchor validation (brand + audience + channel + goal)
* `formula.py` — SelectiveReferenceLoading: map channel+goal → formula → load reference files
* `angles.py` — generate 3 angles (auto: return best; guided: return all 3)
* `writer.py` — write final content per approved angle + channel adaptation rules
* `quality.py` — LLM Quality Editor Pass (auto-revise + flag warnings)
* `output.py` — save to acp_silver_s4.social_content DB + optional markdown file
* `handler.py` — Lambda/ECS entry point, mode detection (auto vs guided)

**Reference files to include** (from Ms. Thư zip):

* 11 formula files: aida.md, pas.md, fab.md, bab.md, hook-value-cta.md, sss.md, slap.md, acc.md, coc.md, pppp.md, storytelling.md
* toolkit.md, funnel.md
* SKILL.md (content strategy rules — wins on conflicts)
* CONTEXT.md (domain language)

### API endpoints (AA-CIS-App)

* `POST /v1/acp/s4/social/generate` — auto mode: takes brief + run_id, returns content_id
* `POST /v1/acp/s4/social/angles` — guided mode step 1: takes brief, returns 3 angles
* `POST /v1/acp/s4/social/write` — guided mode step 2: takes brief + selected_angle, returns content
* `GET /v1/acp/s4/social/{content_id}` — fetch result

### Portal pages (AA-ACP-App)

* `/workspace/s4/social/generate` — guided mode UI: brief form → 3 angles → angle selection → final content preview → approve/save

### Workflow (shared by both modes)

```
1. Collect brief (brand, audience, channel, goal, topic, tone, CTA, must_include, must_avoid)
2. Validate 4 anchors (brand + audience + channel + goal)
3. Select formula internally (map channel+goal → formula list)
4. Load reference files selectively (channel/goal/topic matching)
5. Generate 3 angles with: name + why_it_works + length/style signal
6. Auto: pick angle 1 | Guided: human picks
7. Write final content (channel adaptation + formula applied silently)
8. Quality Editor Pass (LLM): auto-revise + flag warnings
9. Save: acp_silver_s4.social_content + optional markdown
```

### Quality rules (from SKILL.md)

* First line strong?
* Message specific?
* Audience clear?
* CTA obvious?
* Sounds human?
* No generic AI-style writing?
* Proof handled honestly?
* Channel-appropriate?
* Not too salesy for premium brand?

**Avoid list:** "In today's fast-paced world", "game-changing", "revolutionary", "unlock your potential", "take your X to the next level", fake urgency, unsupported claims, exaggerated emotional drama.
