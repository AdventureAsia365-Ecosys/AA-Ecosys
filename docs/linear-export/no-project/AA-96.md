## Gap: Prometheus + Grafana

DOP-C02 expects open-source observability knowledge. AA stack uses CloudWatch + Langfuse only.

## Why this matters

* DOP-C02 exam covers Prometheus/Grafana concepts
* DevOps Engineer role: Prometheus listed as Must-Have 2026 skill
* Current gap: no metrics scraping, no dashboards outside CloudWatch

## Approach (lowest cost for AA)

1. Study Prometheus concepts: scraping, PromQL, exporters, alertmanager
2. Study Grafana: data sources, dashboard design, alerting
3. Optional: spin up Prometheus + Grafana on ECS dev cluster (free tier friendly) alongside Langfuse
4. Document: how Prometheus complements CloudWatch (not replaces)

## Study resources

* Prometheus official docs (Getting Started)
* Grafana Play (free sandbox: [play.grafana.org](<http://play.grafana.org>))
* DOP-C02 Udemy course — monitoring section
