# AA-620 — [Sub G][BE] Tách stage t2_generate (config UI) + Sonnet cho T2 tenant (A1 giữ Haiku) + thread tenant_id qua S1 graph

## Bối cảnh (epic [AA-616](https://linear.app/aa-ecosys/issue/AA-616/epic-giam-sat-chi-phi-llmdfs-toi-uu-modelbatch-tung-stage), S187 — Nghiệp chốt)

Nghiệp phát hiện: **thiếu stage riêng cho A2/T2 tenant writer**. A1 admin rewrite và T2 tenant rewrite dùng CHUNG `graph.py`, cùng stage `s1_generate` (haiku). Nhưng bản chất khác nhau:

* **A1 admin** = tạo Master Content generic nội bộ, brand 'default' rỗng → judge brand-fit SKIP. Batch 763 tour → nên rẻ (Haiku).
* **T2 tenant** = tenant viết THẬT để publish, với **brand identity riêng + DFS keyword riêng** → judge brand-fit CHẤM (bug AA-612a đã fix S185). Sản phẩm khách hàng trả tiền → chất lượng brand-voice quan trọng → cân nhắc Sonnet.

Hiện KHÔNG thể "A1=Haiku, T2=Sonnet" chỉ bằng đổi config vì cùng row `s1_generate`.

## Việc (Hướng 1 — Nghiệp chốt: tách stage, config đổi được ở admin UI)

1. **Thêm stage** `t2_generate` vào `llm_role_config` (migration + SAFE_DEFAULTS). Hiện trong admin Settings/LLM Models (đổi model + account được như các stage khác).
2. **Tách caller ở code**: `v1_pipeline._rewrite_tour` (T2 tenant, gọi từ `v1_tours.trigger_rewrite`) truyền `stage="t2_generate"`; `admin_pipeline._execute_run_tour` (A1) giữ `stage="s1_generate"`. Thread stage qua ContentState/LLMRequest. (`model_tier` explicit vẫn thắng — giữ nguyên.)
3. **Thread** `tenant_id` **qua S1 graph** (gộp từ gap [AA-518](https://linear.app/aa-ecosys/issue/AA-518/llm-ops-model-selection-qua-ui-admin-writer-claudepalmyra-x5-judge-gpt)/[AA-434](https://linear.app/aa-ecosys/issue/AA-434/step0-audit-theo-doi-usage-llm-theo-tenant-t-stage-dja-co-chua-lien)): ContentState mang tenant_id → record_call log đúng tenant cho s1\_\*/t2_generate (hiện luôn NULL). Cho phép tách spend S1 theo tenant trên UI (Sub E).
4. **A/B đo brand-voice** Haiku vs Sonnet trên vài tour tenant THẬT (brand + DFS thật) trước khi chốt Sonnet cho T2 — không đổi mù.
5. Chốt: **A1 admin GIỮ Haiku**; T2 tenant set Sonnet nếu A/B chứng minh brand-voice tốt hơn rõ (admin đổi lại được qua UI).
