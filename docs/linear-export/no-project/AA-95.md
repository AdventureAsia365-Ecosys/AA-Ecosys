## Gap: Vector Databases

AA-CIS currently uses PostgreSQL full-text search only. For AIOps Engineer role, vector DB is a must-have skill per 2026 infographic.

## Why HIGH priority

* CIS semantic tour search would benefit directly (finding similar tours)
* AIOps Engineer job descriptions increasingly require Pinecone/Weaviate experience
* pgvector (PostgreSQL extension) = lowest friction entry point given existing RDS stack

## Recommended approach

1. Start with pgvector on existing RDS PostgreSQL 15 — no new infra
2. Build prototype: embed tour descriptions with Bedrock Titan Embeddings
3. Semantic search endpoint in FastAPI
4. If scale requires: evaluate Pinecone or Weaviate managed

## Study resources

* pgvector GitHub docs
* AWS Bedrock Titan Embeddings docs
* Pinecone quickstart (concept only, not deployment)
