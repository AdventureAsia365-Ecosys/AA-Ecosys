# AA-206 — [AA-193·F1] S1 Two-Model Generate–Judge: Bedrock viết + GPT-4.1 chấm brand-fit + tăng cường diff_block (gộp AA-207)

**ADR:** ADR-2026-014 (Notion). Gộp finding #1 ([AA-206](https://linear.app/aa-ecosys/issue/AA-206/aa-193f1-deep-brand-differentiation-van-generic-qua-ui-ke-ca-sonnet) brand differentiation) + [AA-207](https://linear.app/aa-ecosys/issue/AA-207/aa-193audit-audit-score-khong-phan-biet-differentiation-brand-100-cho) (brand-fit metric thật) thành 1 epic thực thi.

## Root cause (verified từ code thật, S65 — KHÔNG phải giả thuyết)

S1 graph (`services/content_generation/graph.py`) hiện **single-LLM**:

* `generate_node` (Bedrock haiku/sonnet) = LLM call duy nhất. System = `SYSTEM_PROMPT` + `brand_system_prompt` + `_build_brand_diff_block(state)`.
* `validate_node` = deterministic (regex), không bắt generic vs differentiated.
* `brand_audit_node` = self-score Bedrock chấm chính nó → 9.6 vô dụng.
* Loop: generate → validate → should_retry (trên quality_score) → brand_audit → flag_fix → END.

`_build_brand_diff_block` CÓ inject đúng (byte-proven 970 chars) nhưng yếu:

1. CONTRAST chỉ phủ summary + highlights — KHÔNG phủ itineraries (14k, phần lớn nhất) + day-titles.
2. good_examples = 1 câu → model coi là ví dụ phong cách, không phải ràng buộc tái hiện angle.
3. Không có negative contrast.

**GT-C bị bác:** đổi good_examples Sigiriya→neutral KHÔNG đổi output. Mission (conservation/leave-better) rớt bất kể địa lý exemplar. Self-eval single-model = blind spot.

## Decision (ADR-2026-014)

Two-model generate–judge. Bedrock viết, GPT-4.1 chấm.

## Scope thực thi

1. **Thêm node** `llm_judge` (GPT-4.1 qua `LLMClient` `model_tier="gpt-4.1"` — đã wired sẵn trong `shared/llm_client/client.py`) sau `validate`. Judge chấm brand-fit + cross-brand contrast → set `quality_score` + `feedback`. KHÔNG sửa content.
2. **Wire vào loop:** judge fail → feedback → `should_retry` route lại `generate` → Bedrock sửa theo feedback. Dùng `feedback` field + retry loop có sẵn.
3. **Thay self-score** `brand_audit` bằng GPT-4.1 judge (giải quyết [AA-207](https://linear.app/aa-ecosys/issue/AA-207/aa-193audit-audit-score-khong-phan-biet-differentiation-brand-100-cho)).
4. **Tăng cường** `_build_brand_diff_block`: CONTRAST phủ cả itineraries + day-titles; thêm negative contrast (bản generic cần tránh).
5. **Judge prompt** phải định nghĩa brand-fit rõ: cross-brand contrast (bản này khác bản brand khác không?), mission-hook presence — KHÔNG phải generic quality score.

## Verify (sau build)

* Chạy cùng tour × 2 brand khác nhau (WildKind vs Terra) qua S1 → output PHẢI khác rõ ở framing/emphasis, không synonym-swap.
* Judge score brand-fit phải phân biệt được 2 brand (không cùng ~9.6).
* Mission-hook (conservation/leave-better cho WildKind) xuất hiện trong itineraries, không chỉ summary.
