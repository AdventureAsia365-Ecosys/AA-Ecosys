# AA-19 — CIS → AAA sync — implement content pipeline to trip_plans (Option A: scheduled pull)

# CIS → AAA Integration — Sync Pipeline Setup

Implement content sync từ CIS Gold layer vào AAA `trip_plans` table.

## Field Mapping (CIS published_tours → AAA trip_plans)

| CIS Field | AAA Field | Note |
| -- | -- | -- |
| `tour_id` UUID | `cis_tour_id` | Traceability — NOT used as PK |
| `aa_name` | `aa_name` | AI-rewritten name |
| `aa_subtitle` | `aa_subtitle` |  |
| `aa_summary` | `aa_summary` |  |
| `aa_highlights` JSONB | `aa_highlights` JSONB |  |
| `aa_itineraries` | `aa_itineraries` |  |
| `seo_title` | `seo_title` |  |
| `seo_meta` | `seo_meta` |  |
| `country` string | → `country_id` lookup | Map name → FK |

## Implementation: Option A (scheduled pull)

```php
// Laravel scheduled job — runs every 6 hours
Schedule::job(new SyncCisToursJob)->everySlxHours();

// SyncCisToursJob:
// 1. GET https://api-cis.lumiguides.it.com/v1/tours (JWT from env)
// 2. For each tour: UPSERT trip_plans WHERE cis_tour_id = tour.tour_id
// 3. Only update aa_* and seo_* fields — never touch src_* or title or price_from
// 4. Update cis_synced_at = NOW()
```

## Sync Rules (non-negotiable)

* CIS updates ONLY `aa_*` fields — NEVER overwrites supplier `src_*`, `title`, `price_from`
* `cis_synced_at` updated on every sync (track stale content)
* If `cis_tour_id` IS NULL → supplier-only record, not yet processed by CIS
* 215+ tours currently in CIS Gold layer to sync on launch

## Cross-region Note

* CIS API: AWS us-west-1 | AAA: ap-southeast-1
* Cross-region HTTPS call — no VPC peering needed, just JWT auth

## Option B (future — Phase 3)

* Event payload: tour_id + all aa\_\* fields
