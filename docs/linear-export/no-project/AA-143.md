# AA-143 — [OBS-04] Synthetic canary E2E run (regression detection)

## Goal

A scheduled synthetic canary: run one small fixed country batch end-to-end (S0→S4.2) on a dedicated `canary` tenant on a cadence (e.g. daily/weekly via EventBridge Scheduler) to catch regressions automatically — especially important during and after the S2–S4.1 rebuild.

## Scope

1. Fixed canary fixture (small tour set + a known brand brief).
2. Scheduled run via EventBridge Scheduler → asserts: all stages complete, validators pass, evaluator score ≥ threshold, cost within band, no forbidden-word slip.
3. On failure → alarm (SNS/Slack) + mark in Run-Health ([AA-141](https://linear.app/aa-ecosys/issue/AA-141/obs-02-run-health-single-pane-dashboard-sloalerting)).
4. Canary tenant excluded from billing/metering and from production pools.

## Verify

* Introduce a deliberate regression → next canary run fails and alerts.
