* **S3 manifest upload cross-account: OK** (`s1_batch_manifest_uploaded`, 1.93MB → `s3://aa-cis-bronze-005097885195/batch-input/s1-rewrite/...`).
* **CreateModelInvocationJob: FAIL** — `ValidationException: Your account is not authorized to perform this action. Please create a support case`.

→ **KHÔNG phải AccessDenied IAM** (Terraform IAM acc3 đã đúng: CreateModelInvocationJob + Get/List + PassRole + batch service role + S3 grant, prefix atom-decompose/\* đã có sẵn). Đây là **service-level entitlement**: AWS chưa bật Bedrock Batch Inference cho acc3 (786888028788). Chỉ mở được bằng AWS support case.

Hệ quả: [AA-606](https://linear.app/aa-ecosys/issue/AA-606/build-bedrock-batch-inference-cho-s1-rewrite-100-tourlan-xin-iam-batch) **(S1 batch, đánh Done S186) cũng CHƯA từng chạy job batch thật** vì cùng rào chắn này — code đã merge nhưng chưa verify được.

**AWS support case đã mở:** `178979743800653` (Service limit increase → General, acc3, us-west-1, Web). Chờ AWS phản hồi.
