## Tasks (v0.3 additions to v0.2 scope)

### H-1: acp-s4-evaluate Lambda (Isolated Evaluator)

Create new Lambda function `acp-s4-evaluate`:

* Runtime: Python 3.12, 512MB, 60s timeout
* Input schema: `{"text": "<blog_draft_content_only>"}` — STRICT. No other fields.
* Processing:
  1. SHA256 hash of input text → evaluator_input_hash
  2. Call Bedrock Haiku 4.5 with evaluation rubric (NOT brand brief)
  3. Rubric dimensions: Readability(0-10), Factual trust(0-10), Engagement(0-10), Keyword naturalness(0-10), Completeness(0-10)
  4. Composite score: weighted average (fail threshold: 7.5)
* Output: `{evaluator_score, dimension_scores, issues: [], evaluator_input_hash}`
* Critical: evaluator_input_hash stored in blog_drafts for audit trail

### H-2: apply_output_rules() integration

Write `app/services/acp_post_processor.py`:

```python
def apply_output_rules(output: dict, stage: int, tenant_id: str) -> dict:
    rules = db.query("SELECT * FROM acp_output_rules WHERE (tenant_id IS NULL OR tenant_id=$1) AND (stage IS NULL OR stage=$2) AND is_active=TRUE", tenant_id, stage)
    for rule in rules:
        if matches(rule, output):
            db.execute("UPDATE acp_output_rules SET run_count=run_count+1 WHERE rule_id=$1", rule.rule_id)
            if rule.rule_type == 'block': raise OutputRuleViolation(rule.error_message)
            if rule.rule_type == 'replace': output = do_replace(output, rule)
            if rule.rule_type == 'truncate': output = do_truncate(output, rule)
            if rule.rule_type == 'flag': output['review_flags'].append({"rule_id": rule.rule_id, "message": rule.error_message})
            if rule.rule_type == 'score_gate': raise OutputRuleViolation(rule.error_message)
    return output
```

Integration point in S4 flow:

1. Sonnet generates draft → apply_output_rules(draft, stage=4, tenant_id) → if violation → rewrite (max 2)
2. Then call acp-s4-evaluate Lambda → evaluator_score
3. If evaluator_score < 7.5 → rewrite flagged dimensions (max 2)
4. Store: evaluator_score, evaluator_input_hash, review_flags, rules_applied

### H-3: rejection_note extraction in acp-hitl-router

On Gate 3 rejection:

```python
if hitl_request.status == 'rejected' and hitl_request.review_notes:
    extraction = bedrock_haiku(
        f"Extract rule from rejection note: '{review_notes}'. Return JSON: {{pattern_type, pattern_value, suggested_action, confidence_score}}"
    )
    db.update_hitl_request(rejection_note_structured=extraction)
    if extraction['confidence_score'] >= 0.80:
        new_rule_id = db.insert_output_rule(
            tenant_id=hitl_request.tenant_id,
            stage=4,
            rule_type=extraction['pattern_type'],
            pattern=extraction['pattern_value'],
            action_value=extraction['suggested_action'],
            source_type='hitl_rejection',
            source_hitl_id=hitl_request.hitl_id
        )
        db.update_hitl_request(rule_created_id=new_rule_id)
```
