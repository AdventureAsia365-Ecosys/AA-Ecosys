## Re-scoped (S203, 29/09 — Nghiệp): enforce, not shadow-only

Design: `docs/architecture/at-series-v2-design.md` §3. Changes to the scope below:

* **Modes:** per-question `off` / `shadow` / `enforce`, with 3 zones (`accept_floor` / `reject_ceiling`; the grey zone keeps today's behaviour). `enforce` requires a calibration record ([AA-661](https://linear.app/aa-ecosys/issue/AA-661/research-jev-confidence-thresholds-when-may-jev-block-content)).
* **Fail-open:** on a timeout or error, `zone=error` and the stage runs its existing rule. Never an auto-reject.
* **Tenant allow-list guard:** tenant data is sent only for allow-listed (AA test) tenants until the DPA/ZDR is confirmed; other tenants get `zone=skipped`.
* **Seam location:** `shared/llm_client/decide.py`, covered by the no-raw-model-calls test. Logs `llm_call_log` (provider `typesafe`, role `validate`) and cost guard provider `jev`.
* **Admin Decisions view** (Operations): counts per stage/question/zone, drill-down per subject, calibration record.
* **Key:** the Secrets Manager secret `aa-cis/dev/typesafe` (created by Nghiệp).

## Scope

* `gateway.decide(stage, state, questions)` wraps `typesafe-sdk`:
  * Noul / Choice / Score question types;
  * the key comes from Secrets Manager (never in code or the repo);
  * timeout and retry.
* Table `shared.decision_log`:
  * `stage`, `subject_id`, `question_key`, `probabilities jsonb`, `decision`, `threshold_used`;
  * `mode` (`shadow` / `enforce`), `model`, `latency_ms`, `cost_usd`;
  * `compared_to` (the verdict of the existing check).
* Per-stage mode in admin Settings: `off` / `shadow` / `enforce` (enforce requires a calibrated threshold — see the calibration issue).
* Cost guard hook (provider `jev`).
* DPA/ZDR confirmation with TypeSafe before any **tenant** content is sent. Platform content first.
