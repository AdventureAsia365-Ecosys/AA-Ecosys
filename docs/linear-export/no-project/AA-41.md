## Tasks (v0.3 additions to v0.2 scope)

### New table: acp_shared.acp_output_rules

```sql
CREATE TABLE acp_shared.acp_output_rules (
  rule_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id VARCHAR(50),  -- NULL = all tenants
  stage SMALLINT,          -- NULL = all stages
  rule_type VARCHAR(20) NOT NULL CHECK (rule_type IN ('block','replace','truncate','flag','score_gate')),
  pattern VARCHAR(500) NOT NULL,
  action_value TEXT,
  error_message VARCHAR(500),
  source_type VARCHAR(20) NOT NULL CHECK (source_type IN ('system','hitl_rejection','manual')),
  source_hitl_id UUID REFERENCES acp_shared.acp_hitl_requests(hitl_id),
  run_count INTEGER DEFAULT 0,
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- RLS: tenant-specific rules only visible to that tenant
CREATE POLICY output_rules_rls ON acp_shared.acp_output_rules
  USING (tenant_id IS NULL OR tenant_id = current_setting('app.current_tenant'));
```

### Add columns to acp_silver_s4.blog_drafts:

```sql
ALTER TABLE acp_silver_s4.blog_drafts
  ADD COLUMN evaluator_score NUMERIC(3,1),
  ADD COLUMN evaluator_input_hash VARCHAR(64),
  ADD COLUMN review_flags JSONB DEFAULT '[]',
  ADD COLUMN rules_applied JSONB DEFAULT '[]';
```

### Add columns to acp_shared.acp_hitl_requests:

```sql
ALTER TABLE acp_shared.acp_hitl_requests
  ADD COLUMN rejection_note_structured JSONB,
  ADD COLUMN rule_created_id UUID REFERENCES acp_shared.acp_output_rules(rule_id);
```
