## Nguồn gốc

Yêu cầu Nghiep (05/07/2026, session audit): muốn 1 trang admin duy nhất giám sát đầy đủ toàn bộ hệ thống — hạ tầng, vận hành pipeline, LLM, và chi phí thật chi tiết. Hiện tại KHÔNG thấy được số liệu hạ tầng, LLM vận hành chi tiết, và chi phí phải trả ở đâu tập trung — `AWS Cost Tracker` (Notion) cập nhật tay, đã đứng yên 7 tuần; `AA-141` Run-Health chỉ cover ACP run state; `AA-254` chỉ scope rule-based diagnosis.

## Quyết định kiến trúc (đề xuất — không thêm hạ tầng mới)

KHÔNG dựng Prometheus/Grafana. Lý do: thêm 1 service mới cần host + bảo trì cho 1 người vận hành, trong khi toàn bộ dữ liệu cần thiết đã có sẵn trong hệ thống hiện tại:

* **Cost thật:** AWS Cost Explorer API (`ce:GetCostAndUsage`) — chưa từng được gọi tự động, hiện 100% tay trên Notion.
* **LLM ops:** `pipeline_runs.cost_usd`, `generated_content` (model_editorial/model_schema/fallback_used/requested_tier), `acp_runs.total_llm_cost_usd`, `quality_scores` — đã có cột DB, chưa có UI rollup.
* **Infra state:** CloudWatch + boto3 (ECS task health/digest, RDS status, NAT instance state, ElastiCache) — đã có, chưa surface lên UI, chỉ verify qua CLI tay mỗi session.
* **Diagnosis/alerting:** `AA-254` (rule-based triage) — giữ nguyên, trở thành 1 tầng trong epic này thay vì đứng riêng.

Nếu sau khi build xong vẫn thấy thiếu (VD cần lưu metric dài hạn hơn CloudWatch retention, hoặc cần custom business metric linh hoạt hơn) — quay lại đánh giá Prometheus/Grafana lúc đó, không làm trước.

## Scope (4 sub-issue, xem child issues)

1. AWS Cost Explorer integration — cost breakdown theo service/ngày, tách CIS vs ACP nếu tag được, dòng riêng cho Bedrock/GPT-4.1.
2. Live infra state endpoint — ECS/RDS/NAT/Redis health qua boto3 (cache ~60s tránh rate limit/cost gọi API).
3. LLM ops rollup — model tier usage, fallback rate, judge/quality score trend, cost/run.
4. Frontend Command Center page — 4 tab: Infra / CIS Pipeline / ACP Pipeline / Cost, gộp luôn [AA-254](https://linear.app/aa-ecosys/issue/AA-254/cis-obs-ops-diagnosis-panel-rule-based-failure-triage-extend-health) làm tầng cảnh báo.
