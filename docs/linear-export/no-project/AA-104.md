## Harness Gap: S1-H2 — Race condition on state bridge

**Principle violated:** Principle 6 (Error paths are main paths) + Anti-Pattern 3 (Runtime improvisation)

## Problem

`s1_keywords_used` and `s1_tour_ids` are written to `acp_run_context` after `acp.s1.completed` is published. If the DB write fails (timeout, connection drop), the EventBridge event has already been consumed by S2. S2 starts with empty keywords → zero anti-cannibalization protection. Fails silently.

## Fix

1. **Write-before-publish**: ensure `acp_run_context` write is committed BEFORE publishing `acp.s1.completed`. Use DB transaction: write → commit → then publish event.
2. **Guard clause in S2 start**: if `s1_keywords_used == NULL or []` in acp_run_context → block S2, return explicit error `S1_CONTEXT_NOT_READY`, do not proceed silently.
3. **Verify**: after fix, simulate DB write failure → confirm event is NOT published.
