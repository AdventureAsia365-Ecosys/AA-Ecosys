# AA-195 — [AA-193·F3] Itinerary: strip fabricated meals + clock-times (prevent in prompt, catch in audit)

Parent: [AA-193](https://linear.app/aa-ecosys/issue/AA-193/s1-content-quality-dataforseo-keyword-sourcing-brand-differentiation). F3 — remove fabricated meal names + clock-times from itinerary content. **Two-layer fix** (prevent at generation, catch at audit).

## Root cause (STEP 4 + 6)

No rule anywhere forbids meals/times. `prompts.py` rule 5 + `brand_standards.py` AA_ITINERARIES (L51-53) say "preserve factual details / don't invent" → LLM keeps `08:00 breakfast…` if present in `src_itineraries`, and may fabricate.

## Scope

**Prevent (generation):**

* `services/content_generation/prompts.py` (SYSTEM_PROMPT rule 5) + `brand_standards.py` AA_ITINERARIES (insert after L53): negative rule — NEVER invent meal names (breakfast/lunch/dinner) or clock-times (e.g. "7:00 AM departure") unless explicitly in source; fabricated details = PRODUCT_TRUTH_RISK. Describe activities by sequence only.

**Catch (audit):**

* `brand_audit_node.py` (~L62, after ELEPHANT_RIDING block): module-level regex on `generated["itineraries"]` for `breakfast|lunch|dinner` + `\d{1,2}(:\d{2})?\s?(am|pm)` → new code `ITINERARY_MEAL_TIME_INVENTED`. Auto-merges via L211 dict.fromkeys (no schema change — failure_codes has no enum).
* `flag_fix_node.py` STAGE2_FIX_MAPPING (L18-39): add `ITINERARY_MEAL_TIME_INVENTED → itineraries`.
* `brand_standards.py` FAILURE CODES list (L83-92): add the new code so LLM-judge uses exact string.
