S1 rewrite hiện chạy **từng tour một** (LangGraph nhiều node, mỗi node 1 LLM call), throttle `Semaphore(2)` server + 3 browser worker. Rerun 700+ tour rất chậm + đắt (giá on-demand đầy đủ).
