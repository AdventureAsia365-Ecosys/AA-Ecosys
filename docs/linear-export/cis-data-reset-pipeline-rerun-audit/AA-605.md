## Bối cảnh (S184, Nghiệp yêu cầu)

Admin portal (CIS Admin) hiện có style riêng, chưa đồng bộ với trang chính [**https://adventure.asia/**](<https://adventure.asia/>) (brand du lịch, tông editorial/exotic, destination-driven). Nghiệp muốn admin trông đồng bộ, đẹp, chuyên nghiệp, khớp brand.

## Tại sao tách issue riêng (không làm gộp phiên S184)

Đây là việc **design pass** cần điều tra kỹ, không phải sửa nhanh:

* Cần audit trực quan [adventure.asia](<http://adventure.asia>): bảng màu, typography (serif/sans), logo, spacing, ảnh hero, tông chữ.
* Cần đối chiếu với design token hiện tại của admin (`frontend/app/admin/_components/adminUi.tsx` — object `A` chứa màu, `serif`/`sans`/`mono`).
* Làm ẩu sẽ ra lệch, không chuyên nghiệp → phải có mẫu/spec rõ trước khi code.

## Việc cần làm (khi bắt tay)

1. **Audit [adventure.asia](<http://adventure.asia>)** — chụp/ghi lại: palette (primary/accent/neutral), font families, heading style, button style, card/spacing, logo lockup.
2. **Đối chiếu** với `adminUi.tsx` token hiện tại — lập bảng "hiện tại vs mục tiêu".
3. **Đề xuất design** (mockup/mô tả) cho Nghiệp duyệt TRƯỚC khi code.
4. Áp token thống nhất qua `adminUi.tsx` (1 nguồn) để mọi trang admin đổi theo, tránh sửa rải rác.
5. Verify từng trang không vỡ layout.

## S196: audit and design proposal ready, awaiting approval

Scope now covers **both admin and the tenant portal**, per Nghiệp's request in this session.

**Audit of adventure.asia (live HTML/CSS):**
- Fonts: Fahkwang for headings, Poppins for body and buttons, Satisfy for script accents.
- Primary button is gold `#DB9628`, going to `#9E6E16` on hover. Outline buttons use `#DDA64E`. Buttons are pill-shaped and uppercase.
- Text colour is `#33363D`, the secondary colour is slate `#35495E`, the alert red is `#C20101`, and the background is `#F8F6F2`.
- The logo is the gold mountain mark at `/logo.png`.

**Current admin UI** (`adminUi.tsx`, token set `A`):
- The background and body text already match the site.
- The accent is **red `#EF4444`**, used in 150 places for both accent and error meanings.
- Fonts are Fraunces and IBM Plex Sans.

**Current tenant portal** (`portal/_components/ui.tsx`, token set `T`):
- The accent is already gold.
- It uses the same fonts as admin.
- The two token sets drift: red is `#B14A3B` vs `#EF4444`, and green is `#2E7D5B` vs `#22C55E`.

**Proposal:**
- Create one shared `app/_brand/tokens.ts` and have `A` and `T` read from it.
- Use gold as the accent everywhere, with a separate `danger` token.
- Switch to Fahkwang and Poppins.
- Use pill buttons.
- Put the real logo in both sidebars.
- Replace the red colouring on admin-only nav items with an "ADMIN" tag.
- Ship in two PRs: shared tokens plus admin first, then the portal.
- Check all 27 pages on a Vercel preview before merging.

**Decisions A–D** are on the proposal page, alongside before/after mockups for admin and portal. Nothing has been coded yet.
