# AA-615 — [Social tenant][Sub3-FE admin] Monitor telemetry gate/severity/retry/publish theo tenant/kênh (mở rộng run-health/platform-stats)

## Bối cảnh

Sub 3 (FE admin monitor) của redesign social tenant T7-T11 — chốt [AA-612](https://linear.app/aa-ecosys/issue/AA-612/tenant-sync-fix-bug-t2-brand-fetch-lam-luon-djieu-tra-t7-t11-djoi)(b) (S186). Phụ thuộc Sub 1 (metrics table + severity + export/publish audit). Đây là nơi DUY NHẤT thấy gate/held/severity/retry (tenant không thấy) — để admin biết hệ thống yếu chỗ nào mà cải thiện.

## Việc (FE admin, `frontend/app/admin/`)

1. **Mở rộng trang có sẵn, KHÔNG tạo trang mới**: thêm section/tab vào `run-health` hoặc `platform-stats` (đã có `page.tsx`). Tránh phình sidebar.
2. **Telemetry hiển thị** (nguồn: metrics table + gate_ledger/flags/repair_log DB + audit_log publish/export từ Sub 1):
   * Theo tenant/kênh: bao nhiêu bài ship có `warn`, bao nhiêu `block-after-retry` (fail gate nhưng vẫn ship), gate nào hay fail nhất.
   * Retry rate (bao nhiêu bài cần attempt 2).
   * Publish/export count per tenant/kênh (ai dùng nội dung, qua đường nào).
3. **Mục tiêu**: admin nhìn ra "gate X hay fail cho kênh Y" / "tenant Z hay ship bài warn" → quyết cải thiện prompt/gate/rubric.
