## Bối cảnh (S184, phát hiện qua ảnh chụp Nghiệp)

S0 Upload báo "Tours Ready for Rewrite **793**" nhưng sang S1 Rewrite chỉ còn **763**. Chênh 30 tour bị S1 loại vì thiếu itinerary, nhưng S0 vẫn đếm là "sẵn sàng viết" → sai bản chất.

## Root cause (điều tra code + DB thật)

* **S0** `GET /admin/tours-ready` (`api/routers/admin_pipeline.py:1618`) lọc CHỈ `pipeline_status='ingested'` + not-trashed → 793.
* **S1** `GET /admin/tours` (`admin_pipeline.py:1705`) lọc THÊM `deleted_at IS NULL` + `src_itineraries` không NULL/rỗng (floor copy từ `acp_contract.v_trip_registry`, [AA-345](https://linear.app/aa-ecosys/issue/AA-345/acpv2-khong-co-djuong-nap-atom-thieu-ui-chon-tour-dje-atom-hoa-khong)) → 763.
* **Parser** (`services/ingestion/excel_parser.py`) KHÔNG phân biệt tour vs POI — mọi dòng có `src_name` → 1 "tour". KHÔNG validate itinerary ở cả preview (dry_run) lẫn commit. Preview chỉ check thiếu `src_name/country/duration/price_raw` (`admin_pipeline.py:1180`), không check `src_itineraries`.

## 30 tour thiếu itinerary (DB confirmed)

| Nước | Số | Bản chất |
| -- | -- | -- |
| Japan | 23 | POI/attraction: bảo tàng, tiệm thuê xe, "Suggested Route Course 1/2/3", giờ mở cửa nằm ở cột `duration` |
| India | 4 | Hoạt động 1 ngày (cycling/camping) |
| Laos/Nepal/Thailand | 3 | Excel nguồn thiếu cả itinerary lẫn description (chỉ có tên + duration) |

Cả 30 đều KHÔNG cứu được (nguồn thiếu, không phải parser hỏng) → trash hết.

## Việc cần làm

1. **S0** `tours-ready` **áp cùng itinerary floor với S1** (thêm `deleted_at IS NULL` + `src_itineraries` không rỗng) → "Tours Ready" khớp S1.
2. **Cảnh báo empty-itinerary khi upload:** preview (dry_run) đưa dòng thiếu itinerary vào `blocked_tours` (reason `empty_itinerary`); commit đếm + ghi vào `ingest_details`.
3. **Trash 30 tour hiện có:** `UPDATE raw_tours SET source_status='trashed', deleted_at=now()` (transaction, verify).
