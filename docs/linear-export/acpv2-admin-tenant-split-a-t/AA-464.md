## Bối cảnh

`trust_ramp.py::suggest_ramp_transition()` (dòng 73) — hàm đã viết sẵn từ trước, có logic tính toán tenant nào đủ điều kiện chuyển bậc Trust Ramp (dựa trên `engagement_ok`, `weeks_active`, và các tiêu chí khác trong thiết kế gốc Ms. Thư — khớp `aamc/delivery.py::publish_gates()`) — nhưng **0 caller**, chưa có API/UI nào kích hoạt nó chạy.

[AA-437](https://linear.app/aa-ecosys/issue/AA-437/a4-cross-tenant-oversight-use-case-djau-tien-xem-t3-auto-pass-log-theo) (A4 Cross-Tenant Oversight, Done 24/08) xây UI Trust Ramp dashboard CHỈ để hiển thị trạng thái hiện tại — quyết định có chủ đích lúc đó là "không tự động hoá", để admin tự nhìn số liệu và tự tay chuyển bậc.

Nghiệp xác nhận (S159): nên nối dây — hàm gợi ý (không tự chuyển, chỉ đề xuất để admin duyệt) nên chạy và hiển thị trên UI A4.

1. STEP 0: đọc lại `suggest_ramp_transition()` hiện tại — xác nhận input/output, logic tính điều kiện đủ để lên bậc, có cần cập nhật gì sau các thay đổi kiến trúc gần đây (T7 viết lại, distinctiveness mới) không.

## What was built

- `services/acp_produce/trust_ramp.py`: new `compute_tenant_weeks_active()`, `compute_tenant_engagement_ok()`, `compute_tenant_ramp_signals()`, `compute_ramp_suggestion()`. **`suggest_ramp_transition()`/`confirm_ramp_transition()` themselves are unchanged.**
- `api/routers/admin_a4.py`: `GET /admin/a4/trust-ramp` gains `engagement_ok`/`weeks_active`/`suggested_mode`/`eligible` per row — still a pure read, computed on-demand (no scheduler/cron/new table, per the issue's own recommendation §2). Two new mutating endpoints, both requiring an explicit admin click, never automatic (ADR-2026-038 §0.2):
  - `POST /admin/a4/trust-ramp/{packet_id}/approve` — first real caller of `confirm_ramp_transition()`.
  - `POST /admin/a4/trust-ramp/{packet_id}/skip` — new; logs a dismissal to `acp_shared.audit_log` (`action='ramp_suggestion_skipped'`), never mutates `packets.publish_mode`. Closes the "log every suggestion given + admin approve/skip" ask for the skip half, which had no mechanism before.
- `frontend/app/admin/a4-oversight/page.tsx`: Trust Ramp panel now shows a suggestion badge + Approve/Skip buttons on eligible packet rows (grouped by tenant, matching the existing per-packet UI — AA-437 decided against a tenant-level collapse, so this build kept that shape even though the issue text says "Tenant X đủ điều kiện").
- **No migration** — reuses `acp_deliver.packets` (094/106), `acp_shared.content_metric_snapshot` (112), `acp_shared.audit_log` (030), all already live.
