3. Thêm persist call ở từng điểm gọi đã xác nhận (16 điểm từ [AA-518](https://linear.app/aa-ecosys/issue/AA-518/llm-ops-model-selection-qua-ui-admin-writer-claudepalmyra-x5-judge-gpt), cộng thêm nếu STEP0 tìm ra chỗ thiếu).

Đề xuất cấu trúc cây hợp lý (Claude Code tự đề xuất, có thể là accordion/expand từng cấp, hoặc bảng pivot) — báo cáo thiết kế trước khi build UI thật.
5. Endpoint đọc lại cho cả AA/A4 ([AA-501](https://linear.app/aa-ecosys/issue/AA-501/t9-t11-ui-xem-bai-viet-dja-cham-goc-aa-trang-thaidjiemretryloi-qua-a4)) VÀ trang giám sát mới này dùng chung nếu hợp lý.
