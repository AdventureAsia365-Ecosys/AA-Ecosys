**Scope decisions**: didn't re-ask about cross-tenant scope — this issue's own text says to confirm with Nghiệp, but that confirmation already exists (Q6=B, 25/07/2026, AA-332 origin, cited in AA-484's own comment) for the one cross-tenant use case this build enables (AA-484's blocking cannibalization gate).
