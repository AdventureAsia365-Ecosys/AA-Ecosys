# AA-256 — [COMMAND-CENTER 1/4] AWS Cost Explorer integration — cost breakdown thật theo service/ngày

## Goal

Backend endpoint gọi `ce:GetCostAndUsage` (AWS Cost Explorer API), trả cost breakdown theo service + theo ngày, thay cho việc đọc invoice PDF tay hàng tháng lên Notion `AWS Cost Tracker` (đang đứng yên từ 18/05).

## Scope

* IAM: thêm quyền `ce:GetCostAndUsage` cho role/profile đang dùng (read-only, không cần quyền ghi).
* Endpoint `GET /admin/costs/summary?range=7d|30d|mtd` — group by SERVICE, filter theo account (867490540162).
* Tách được Bedrock cost riêng (đã có dòng invoice riêng theo Cost Tracker cũ) — hiển thị theo model nếu Cost Explorer hỗ trợ resource-level tag, nếu không thì fallback dùng `pipeline_runs.cost_usd` + `acp_runs.total_llm_cost_usd` từ DB (đã tracked, xem [AA-118](https://linear.app/aa-ecosys/issue/AA-118/hrn-13-cost-tracking-end-to-end-acp-runstotal-llm-cost-usd)/[AA-20](https://linear.app/aa-ecosys/issue/AA-20/fix-dashboard-cost-tab-real-cost-from-db-remove-hardcoded-cost-per)).
* Cache kết quả (Cost Explorer tính phí theo API call — $0.01/request — không gọi trực tiếp mỗi lần load trang, cache Redis/DB 6-12h).
* So sánh với budget threshold cũ ($150/mo) — cảnh báo khi vượt.

## Verify

* Số liệu khớp với invoice AWS thật tháng gần nhất (đối chiếu tay 1 lần khi build xong).
* Xác nhận có thấy rõ tác động của NAT Instance (ADR-2026-011, chuyển từ NAT Gateway 05/06) trong xu hướng cost — đây là điểm chưa từng được verify bằng invoice thật kể từ khi đổi.
