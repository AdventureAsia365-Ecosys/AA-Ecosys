# AA-177 — [SEC-01] Container + Lambda image scanning + SBOM in CI (Trivy + syft)

## Bối cảnh

Không có image/dependency scanning trong CI ở cả 3 repo. Cả 3 roadmap + DevSecOps landscape (Trivy/Snyk/Aqua) đều liệt đây là mục bắt buộc. Hiện shared API image (ECS) + Lambda deps đi thẳng vào prod không scan.

## Áp dụng ACP

Trực tiếp. Image ECS dùng chung serve ACP; ACP Lambdas có dependency tree riêng. Security posture bắt buộc trước khi onboard paying B2B tenant.

## Scope

1. **Container scan-on-push:** Trivy trong GHA build job (AA-CIS-App) — fail pipeline nếu có CRITICAL/HIGH fixable. Hoặc bật ECR enhanced scanning (Inspector) như layer thứ 2.
2. **Lambda dependency scan:** `pip-audit` hoặc `trivy fs` trên requirements của ACP Lambdas (AA-CIS-Infra/dist/lambdas + acpcore).
3. **SBOM:** `syft` sinh SBOM (CycloneDX/SPDX) mỗi build, attach làm artifact + push vào ECR cùng image. Phục vụ audit B2B + supply-chain provenance.
4. **Gating policy:** define rõ severity gate (block CRITICAL/HIGH, warn MEDIUM) — tránh CI noise spam (đồng bộ nguyên tắc "alerts that don't spam").

## Cert mapping

DOP-C02 — Domain 5 (Security & Compliance): image scanning, ECR/Inspector, pipeline security gates. DVA-C02 — security best practices. Khớp Stage 10/12 roadmap (Security Best Practices: scanning, SBOM, compliance).
