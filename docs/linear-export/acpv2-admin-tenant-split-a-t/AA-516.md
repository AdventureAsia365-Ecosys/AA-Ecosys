# AA-516 — [CLEANUP] Dead code layer N4-N6 (fetch_trips/runway_map/plan_quarter/allocate_month) — không route nào gọi tới

## Bối cảnh

Phát hiện qua [AA-500](https://linear.app/aa-ecosys/issue/AA-500/aa-494-decision-6-build-fix-fetch-trips-tenant-filter-xac-nhan) (01/09): `runway.fetch_trips()` và toàn bộ layer nó nuôi (`runway_map()`, `plan_quarter()`, `allocate_month()`, `allocate_and_persist_month()`, `allocate_and_persist_week()`) — từng gọi N4/N5/N6 theo naming cũ — **không có route/service nào đang live gọi tới**. Chỉ còn sống qua unit test (mock) + 2 verify_scripts chạy tay (`tests/verify_scripts/aa377_aa378_run_persist_verify.py`, `tests/verify_scripts/aa375_slot_production_verify.py`), không nằm trong CI.

Route thật (T7 `v1_planning.py`, T8 `acp_angle_gate/service.py`) đều tự đọc trip/atom qua `tenant_pool.py` ([AA-448](https://linear.app/aa-ecosys/issue/AA-448/t7-content-planning-viet-lai-hoan-toan-self-service-thay)) rồi gọi thẳng các hàm pure (`compute_runway_map()`/`compute_quarter_plan()`/`compute_slot_grid()`) — bỏ qua hoàn toàn lớp async wrapper N4-N6.

`services/acp_produce/slot_runner.py` (N7, live) có docstring xác nhận cố tình KHÔNG gọi `allocate_month()` (quyết định [AA-377](https://linear.app/aa-ecosys/issue/AA-377/acpv2n6-slot-schedule-khong-persist-slotgrid-chi-in-memorypreview-slot) — tốn kém nếu re-run mỗi lần trigger).

## Việc cần làm (KHÔNG build vội — cần xác nhận trước)

1. Xác nhận với Nghiệp: có còn ý định dùng admin-triggered quarter-plan (`plan_quarter()`/`allocate_month()` gọi tay/qua route riêng) trong tương lai không, hay hoàn toàn thay thế bởi Slate ([AA-511](https://linear.app/aa-ecosys/issue/AA-511/t7-slate-thay-weekly-slots-schema-subject-service-router-frontend))?
2. Nếu xác nhận không cần: xoá `fetch_trips()`, `runway_map()`, `plan_quarter()`, `allocate_month()`, 2 wrapper persist — kèm xoá/viết lại 2 verify_scripts + `test_aa377_aa378_run_slot_persist.py` phụ thuộc chúng.
3. Nếu cần giữ làm fallback dự phòng: ghi rõ lý do + gắn comment trong code giải thích tại sao vẫn giữ dead-from-live-app code.

## Không thuộc scope

`compute_runway_map()`/`compute_quarter_plan()`/`compute_slot_grid()` (bản pure function) — vẫn đang được T7/T8 dùng qua đường `tenant_pool`, KHÔNG đụng.
