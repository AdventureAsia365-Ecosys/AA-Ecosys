## Context

Follow-up from [AA-343](https://linear.app/aa-ecosys/issue/AA-343/cis-s0-ingest-2907-lam-hong-raw-tours-src-itineraries-lay-nham-cot-aa) Part C (đề xuất ĐK2, không sửa trong PR [AA-343](https://linear.app/aa-ecosys/issue/AA-343/cis-s0-ingest-2907-lam-hong-raw-tours-src-itineraries-lay-nham-cot-aa) vì ngoài phạm vi — không đụng endpoint/UI trong lượt hard-delete + status fix).

`GET /admin/upload-history` (`api/routers/admin_pipeline.py:1493-1518`) backs the Upload History table on `/admin/upload`. Its `row_count` field comes from `raw_sources.row_count` — the **parsed** count, not the landed count. This is exactly the number that read "30" for `laos_biking_publish_ready.xlsx` on 29/07/2026 while only 16 rows actually landed in `raw_tours` (14 silently dropped, [AA-343](https://linear.app/aa-ecosys/issue/AA-343/cis-s0-ingest-2907-lam-hong-raw-tours-src-itineraries-lay-nham-cot-aa) P1.3) — misleading, and gave no visible signal that anything was wrong.

[AA-343](https://linear.app/aa-ecosys/issue/AA-343/cis-s0-ingest-2907-lam-hong-raw-tours-src-itineraries-lay-nham-cot-aa) Part C added `shared.pipeline_runs.ingest_details JSONB` (migration 091: `{"rows_parsed", "rows_landed", "rows_dropped", "drops": [{"reason", "count", "sample_ids"}]}`), written by `services/ingestion/handler.py` at the end of every ingest. The column exists and is populated, but nothing reads it back — a column nobody queries is effectively still silent.

## Proposal

1. `get_upload_history()` (`admin_pipeline.py:1493-1518`) — JOIN `shared.pipeline_runs` on `batch_id`, pull `ingest_details->>'rows_landed'` and `ingest_details->>'rows_dropped'`. NULL for any source ingested before migration 091 (no backfill needed — page just shows nothing new for old rows, degrades gracefully).
2. Add `rows_landed` / `rows_dropped` to the response shape.
3. Frontend (`/admin/upload` Upload History table): split "TOURS PARSED" into "PARSED / LANDED", and show a dropped-count badge (e.g. red "14 dropped") when `rows_dropped > 0`, so a partial ingest is visible on the page that already displays this table, rather than only inside a JSONB column.

## Should know

* No endpoint or UI code was changed for this — pure proposal, written up in `docs/implementation-notes/AA-343.md` (Round 3 / ĐK2 section) and in the [AA-343](https://linear.app/aa-ecosys/issue/AA-343/cis-s0-ingest-2907-lam-hong-raw-tours-src-itineraries-lay-nham-cot-aa) PR/comment.
* `ingest_details` write path already shipped in [AA-343](https://linear.app/aa-ecosys/issue/AA-343/cis-s0-ingest-2907-lam-hong-raw-tours-src-itineraries-lay-nham-cot-aa) Part C — this ticket is read-side only.
