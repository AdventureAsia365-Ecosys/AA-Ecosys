## Vì sao quan trọng

* Đây là gap chặn đứng khả năng verify bất kỳ bug liên quan nội dung prompt nào trong tương lai (không riêng [AA-314](https://linear.app/aa-ecosys/issue/AA-314/bug-build-user-prompt-render-highlights-bi-loi-anh-huong-ca-2-nhanh)) — mọi lần cần xác nhận "prompt có đúng format không", "brand rules có được inject đúng không", "highlights có leak JSON thô không"... đều phải dựa vào suy luận gián tiếp từ output hoặc code tĩnh, không thể quan sát trực tiếp request thật.
* Trực tiếp chặn việc khép kín [AA-314](https://linear.app/aa-ecosys/issue/AA-314/bug-build-user-prompt-render-highlights-bi-loi-anh-huong-ca-2-nhanh): checkbox "Manual verify on Dev after deploy: run a tour through /admin/run-tour, confirm S1 prompt highlights render as a clean joined list (not raw JSON) in logs" (test plan PR #78) không thể tick theo đúng cách đã cam kết — phải đổi sang phương pháp gián tiếp (đọc output DB) thay vì đọc log trực tiếp.
* Liên quan [AA-289](https://linear.app/aa-ecosys/issue/AA-289/quality-khong-co-prompt-versioning-eval-regression-gate-khong-truy) (Backlog, prompt versioning + eval regression gate) — nhưng khác vấn đề: [AA-289](https://linear.app/aa-ecosys/issue/AA-289/quality-khong-co-prompt-versioning-eval-regression-gate-khong-truy) lo về việc *đổi prompt qua thời gian* gây tụt chất lượng, không phải việc *quan sát 1 request cụ thể ngay lúc chạy*. Có thể cùng giải quyết 1 lần nếu build prompt logging, nhưng là 2 nhu cầu khác nhau.

## Việc cần làm (chưa quyết hướng, cần Nghiep chọn — không tự chọn)

1. **Log nội dung prompt đầy đủ** vào CloudWatch (structlog thêm field `prompt_text` hoặc tương tự) — đơn giản nhất, nhưng cần cân nhắc: prompt có thể chứa nội dung nhạy cảm/dài, ảnh hưởng cost lưu trữ log, và cần đảm bảo không log secrets nào lẫn vào.
2. **Bật lại Langfuse** (hoặc tương đương) cho riêng mục đích trace prompt — đã gỡ trước đó vì lý do cost, cần cân nhắc lại trade-off.
3. **Log có điều kiện** (chỉ log full prompt khi có flag debug/khi retry, không log mặc định mọi request) — giảm chi phí nhưng vẫn có khả năng bật khi cần điều tra.
4. Kết hợp với [AA-289](https://linear.app/aa-ecosys/issue/AA-289/quality-khong-co-prompt-versioning-eval-regression-gate-khong-truy) nếu Nghiep muốn giải quyết chung 1 lần (prompt versioning cần lưu prompt thật để so sánh qua thời gian — có thể cùng 1 cơ chế lưu trữ).
