## 6 vấn đề cần sửa (xác nhận qua ảnh Nghiệp chụp 09/09/2026)

### 1. Ngôn ngữ — vi phạm rule "UI text luôn English" (ways-of-working)

Retry History đang hiện label **tiếng Việt**: "Round 1 — Lý do yêu cầu viết lại (F9_brand_voice)" — đây chính là label [AA-568](https://linear.app/aa-ecosys/issue/AA-568/buildui-gop-3-trang-con-writereviewpublish-thanh-1-trang-06-content) build theo yêu cầu gốc nhưng quên dịch. **Phạm vi sửa ngôn ngữ CHỈ áp dụng cho UI của trang admin này** (label, tiêu đề section, text tĩnh) — KHÔNG đụng vào nội dung bài viết gốc của tenant trong phần CONTENT (đó là sản phẩm thật, giữ nguyên ngôn ngữ viết, không dịch). Cụ thể cần sửa:

* "Round N — Lý do yêu cầu viết lại (...)" → "Round N — Retry reason (...)" (hoặc tên tương đương tiếng Anh, giữ format).
* Rà toàn bộ trang (sidebar description, section header, mọi label tĩnh khác) xem còn chỗ nào tiếng Việt không — sửa hết.
* Audit/violation quote text bên trong Retry History (trích câu cụ thể bị gate) giữ nguyên — đó là trích dẫn content thật của bài viết, không phải label UI.

### 2. Thiếu thống kê tổng quan theo tenant ở đầu trang

Cần thêm khu vực thống kê (giống pattern "Social Content" 01-Atomize: Tours/Atoms count) ngay dưới bộ lọc hoặc trên bảng — hiển thị theo tenant đang chọn (hoặc "All"):

* Tổng số bài viết.
* Breakdown theo channel (bao nhiêu bài mỗi channel).

### 3. Thiếu sort cho các cột

Bảng chính hiện chỉ có filter, chưa sort được. Thêm sort (click header) tối thiểu cho: Gate count, Retry count, Created at — có thể mở rộng cho các cột khác nếu hợp lý.

### 4. Nội dung bài viết trong accordion bị giới hạn chiều cao

Phần "CONTENT" trong accordion đang có scroll box riêng, cắt ngắn nội dung — cần cho phép mở rộng để xem hết mà không phải cuộn trong 1 khung nhỏ (VD: expand/collapse toàn bộ, hoặc bỏ max-height cố định).

### 5. Lineage hiển thị 1 dòng dài, khó đọc

Hiện tại: `Tour: X — Atom: Y — Slate: Segment — Z` nối thành 1 dòng dài. Cần tách mỗi thực thể xuống 1 dòng riêng (Tour / Atom / Segment / Route / Hub / Slate), dễ quét mắt hơn.

### 6. Header cột bảng chính mất khi cuộn xuống

Cuộn xuống các hàng dưới, header (TOPIC/TENANT/TOUR/CHANNEL/...) biến mất — cần sticky header, đúng pattern đã áp dụng cho các trang khác trong Social Content (theo [AA-551](https://linear.app/aa-ecosys/issue/AA-551/buildui-tach-adminatom-curation-platform-wide-01-05-admintenant)/[AA-566](https://linear.app/aa-ecosys/issue/AA-566/buildui-sua-bug-djem-sai-my-catalog-audit-sticky-header-toan-he-thong) fix sticky trước đây — dùng đúng 2 ingredient đã học: `minHeight:0` + `height:"100vh"`, không lặp lại lỗi thiếu 1 trong 2 như các lần trước).

## Built + deployed + live-verified (all 6 points)

**PR #353** merged, deployed to Vercel production (`aa-cis.lumiguides.it.com`, deployment `dpl_CgYoTJ8qhisJ68tgVwjCE74jFdRu`, `READY`). All UI-only, no backend/schema touched (per this issue's own STEP0 exemption).

1. **English labels** — "Round N — Lý do yêu cầu viết lại" → "Round N — Retry reason". Grepped the whole page file + shared components (`auditPanels.tsx`/`adminUi.tsx`/`AdminSidebar.tsx`) for Vietnamese diacritics first — this was the only real UI-visible string left; everything else was already English or a code comment.
2. **Tenant stat header** — total pieces + per-channel breakdown, computed client-side from the already-loaded rows (no new endpoint). Dynamic, not a fixed grid — only shows channels actually present in the current filtered result, so it stays honest when a filter narrows the data.
3. **Sortable columns** — Gate count / Retry count / Created at (the issue's stated minimum), click-to-toggle asc/desc, client-side.
4. **Content block** — removed the fixed `maxHeight`/`overflowY` scrollbox; full piece text now renders inline.
5. **Lineage** — split into one line per real entity (Tour / Atom / Segment / Route / Hub / Slate). Route and Hub used to be one merged string ("Route/Hub — {hub} (Day X-Y)") — now genuinely 2 separate lines. Verified on both a Segment-sourced pick and a Route-sourced Blog pick (real data, both shapes).
6. **Sticky header** — real root cause was more specific than the issue's own guess: `minHeight:0`/`height:"100vh"` were ALREADY correct on this page's scroll container. The actual bug was a redundant `overflowX:"auto"` on the table's own inner wrapper div — per the CSS overflow spec that silently forces `overflow-y: auto` too, making that never-actually-scrolling inner div hijack `position:sticky`'s containing block instead of the real outer scrollport. Fixed by moving `overflowX` to the real scroll container.

**Live-verify**: 7 new Playwright tests (`tests/e2e/aa572-content-trace-fixes.spec.ts`) + the 1 pre-existing test that hardcoded the old Vietnamese string (updated). Ran the full set — 7 new + 11 pre-existing regression tests (aa568 + aa562 suites) — **twice**: once against a local dev server (real deployed backend data), once against real production (`https://aa-cis.lumiguides.it.com`) after the deploy. **18/18 passed both times**, no regressions.
