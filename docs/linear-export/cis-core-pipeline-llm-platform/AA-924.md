## Problem

Split from [AA-787](https://linear.app/aa-ecosys/issue/AA-787/t10-gates-drop-f8-framework-promises-an-option-f3-f5-merge-f7f16-f15) (Nghiệp approved S245, 20/10/2026). Two of [AA-787](https://linear.app/aa-ecosys/issue/AA-787/t10-gates-drop-f8-framework-promises-an-option-f3-f5-merge-f7f16-f15)'s merges were not done:

* F15_voice_warn → F15.
* F2 variants + the F15 stock list → one lexicon gate.

Both need one gate to carry violations of different severity: some block (hold the piece) and some only warn. Today the gate ledger records one result per gate (pass / warn / fail), so merging a blocking check with a warn-only check would either block on things that should only warn or hide real failures. They also overlap with the [AA-800](https://linear.app/aa-ecosys/issue/AA-800/brand-pack-tenant-signature-vocabulary-split-the-forbidden-list-into) word layers (signature words, luxury cues) added since S234.

## Scope

1. Gate ledger: let one gate entry list its violations, each with its own severity (`block` / `warn`). The gate's overall result is the worst severity. Keep the old shape readable for older pieces.
2. Merge F15_voice_warn into F15 using per-violation severity.
3. Merge the F2 variants and the F15 stock list into one lexicon gate, reconciled with the [AA-800](https://linear.app/aa-ecosys/issue/AA-800/brand-pack-tenant-signature-vocabulary-split-the-forbidden-list-into) word layers (no word judged twice).
4. Admin Content Quality: show per-violation severity; old gate names are labelled "(retired)" as in [AA-787](https://linear.app/aa-ecosys/issue/AA-787/t10-gates-drop-f8-framework-promises-an-option-f3-f5-merge-f7f16-f15).
5. Offline replay on the S234 pieces plus the [AA-729](https://linear.app/aa-ecosys/issue/AA-729/eval-golden-set-100-samples-from-existing-data-scoring-script-for) golden set: the passed/held decision must be unchanged unless a difference is explained.
