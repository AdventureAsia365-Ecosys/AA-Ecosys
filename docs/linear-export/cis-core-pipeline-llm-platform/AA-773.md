# AA-773 — [T9 seed] Offered vs included status on every moment — "Status: OFFERED, NOT INCLUDED" line + writer rule

## Problem

S234 r4: `promises_an_option` warned on 8/8 blogs (32 final pieces pooled); F17 "optional-as-plan" fired 15× in the pool; the panel found 'optional' flipped both ways (boat ride written as included; Tsaatan day called optional). The seed shows "take boat rides on the water" as if included while the itinerary says "Optional activities include…" (`atom_seed.py:272-298`). chị Thư's repo labels the source line itself (`write.py:654-670`).

## Scope

1. `services/acp_shared/atom_seed.py` `compose_seed` / `compose_route_moment`: match `quality_gates._OFFERED_PHRASES` at **sentence level** against the evidence sentence naming this moment; append `Status: OFFERED, NOT INCLUDED (the itinerary says: "…"). Describe it as available, never as something the reader will do.` or, on a day with offered items, `Status: included in the trip. Never call it optional.`
2. Keep `Status:` out of `moment_fact_count`; add it to the F9 v2 seed-prefix contract (`claim_rules.number_source_lines`).
3. `prompts.py` SYSTEM_PROMPT: the Status rule (plan §3.1, second bullet). Update the byte-identical guard test on purpose.
   Out of scope: a stored `offered_moments` column (later build).
