## Problem

ADR 0020 (S271). No gate is trustworthy without human-anchored labels. The blog golden set has one human label, and it is a test stub. The first-line panel agrees with the final labels at kappa 0.35. The live fact judge is unpinned and uncalibrated (decision D7).

## Scope

* A claim-level label set (CL-1) for T9 plus the S1 L2 and T2 sets. The agent panel does the first pass, and the tech lead adjudicates disputes and a random 20% audit (D11: about 2–3 h over 1–2 weeks). Size the set from a sample-size table per detector, not a fixed count.
* A golden-set version bump that drops the leftover test label (t9b-002) and re-derives labels under the policy; list every label that flips.
* R1 calibration of at least two instrument candidates (GPT-6 Luna on the OpenAI API and one acc2 non-Claude model), in entailment and extraction modes as separate instrument ids. Measure the code tripwires and the A3 evidence producers the same way.

## Done when

* The label sets have 0 internal contradictions; per-class agreement and the panel error rate are reported.
* One instrument is pinned with a measurement record per class: precision lower bound and recall on enough labelled fires.
* Total judge-only spend ≤ $2.
