## Problem

`docs/STYLE.md` allows cropped screenshots (PNG or WebP under 300 KB) for UI how-to guides. The admin docs reader (`/admin/docs`) and the Guide tabs only show SVG: `GET /api/admin/docs/asset` accepts `.svg` paths only. Guides that need a picture of a page have no way to show one.

## Scope

* The asset route also serves `.png` and `.webp` from the docs bundle:
  * repo-relative paths only, no traversal;
  * a size cap of 300 KB, the same as STYLE;
  * the right content type and cache headers.
* The docs bundle build (`tools/docs/build_docs_reader.py`) carries those images.
* The docs lint checks that every image link resolves, has alt text and stays under the cap.
* One guide uses a real screenshot as the proof.

## Done-when

* On Dev, one admin guide page shows a PNG screenshot in EN and VI.
* The lint refuses a missing or oversized image.
* Tests for the route (allowed types, traversal refused, size cap).
