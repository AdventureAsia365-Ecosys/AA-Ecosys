## Problem

The S263 gateway gap audit (`docs/audits/2026-11-01-S263-gateway-gap-audit/plan.md`, 59 confirmed gaps vs ADR 0009 v2) found the CIS gateway core incomplete: no per-stage kill switch / declared degrade mode, `shared.prompt_version` not seeded, embedding calls missing ledger fields, tenant budget not fail-closed, legacy dispatch paths and missing route deadlines, no CI guard against calls that bypass the gateway in all four apps. Tech lead approved creating this issue (S263, T-20).

A1, A2, A3, A4, A5, A6, A8, A9, A10, D1, D2, D4, D8, G1, G2.
