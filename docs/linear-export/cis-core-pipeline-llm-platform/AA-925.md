## Problem

Quality System v1 (root `docs/audits/2026-10-20-S245-quality-system/design.md`, Nghiệp approved D1–D11 on 20/10/2026, S245) targets the two most expensive failure kinds first:

* Repairs that break something that already passed. [AA-777](https://linear.app/aa-ecosys/issue/AA-777/t10-f9-judge-consistency-sticky-pass-for-unchanged-sentences-cut-truth) took 7 days, 3 PRs and 2 paid rounds.
* Silent fail-open paths. Jev 402 failed about 48k times unnoticed.

The [AA-729](https://linear.app/aa-ecosys/issue/AA-729/eval-golden-set-100-samples-from-existing-data-scoring-script-for) baseline (fixture 1.1.0) shows S1 passes 26 of 44 rewrites that humans failed. Day-count errors are one of the classes that leak, for example a 3-hour ride split into Day 1–4.

## Scope

1. `repair_contract`**.** Add 5 invariants that every repair path checks: no gate that passed may fail after a repair; no new specifics; no truncation; scope kept; tags balanced. Attach it at the existing splice points in A1 flag_fix, T3 and T9. This generalises the [AA-528](https://linear.app/aa-ecosys/issue/AA-528/t9bug-viet-lai-toan-bo-khi-sua-gate-gay-hoi-quy-56percent-piece-ket) regression guard.
2. **Fix the** [AA-740](https://linear.app/aa-ecosys/issue/AA-740/s1-pipeline-deterministic-seo-meta-seo-title-length-fit-after-the-last) **meta fitter.** No more "cut then add a period": regenerate shorter, or cut at a sentence boundary.
3. `degraded[]` **counters.** Count every fail-open path: Jev unavailable, day check skipped, a hard-class detector not run. If a hard-class detector is degraded, the output is held and an eval run is marked INVALID.
4. **S1 day-count oracle.** A deterministic check that compares the source duration and day structure with the output itineraries. Run it over the \~900 stored A1 tours and report the numbers.
5. **Q0 corpus.** About 55–60 labelled cases that run the full deterministic post-processing chain in production order, inside the existing pytest unit job. CI checks that every new case fails on the merge-base. Add a PR template section asking for the real writer input to be dumped first.

## Done when

* Q0 runs in the unit job, and a deliberate PR that flips a passed gate through a repair is blocked (run link).
* The oracle has run on the stored A1 tours, with counts per class reported in the PR.
* A forced Jev failure holds the output and increments `degraded`, verified on Dev (live check).
* Merged, deployed, and verified live per aa-ship.
