## Problem

`acp_shared.facts` (platform + tenant scope) is read by `services/acp_content_writing/facts.py`, but there is no API and no UI to write it; the [AA-529](https://linear.app/aa-ecosys/issue/AA-529/t9gap-thieu-tang-facts-entry-claim-giamuavisa-khong-co-nguon-trich-ket) branch was never merged. Admins need SQL, tenants cannot add their own prices/terms, so writers lack grounded tenant facts (S236 inventory).

## Scope

1. Admin API + page: CRUD platform facts (kind, subject, value, source, valid_until), with audit.
2. Tenant API + portal page: CRUD tenant-scope facts, isolated by tenant (RLS / tenant_id check).
3. Writers (T2/T9) pick tenant facts over platform facts for the same subject; seed shows the source.
4. Reuse the fact-edit audit pattern from [AA-774](https://linear.app/aa-ecosys/issue/AA-774/place-cards-keep-visitingpractical-card-facts-out-of-the-writer-seed).
   Out of scope: bulk import from Excel (later).

## Done when

* On Dev a tenant adds a price fact and the next T9 piece seed for that tour cites it (writer_input evidence); another tenant cannot read it (403/empty).
