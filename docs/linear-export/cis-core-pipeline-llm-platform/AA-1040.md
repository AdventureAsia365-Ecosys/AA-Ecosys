## Problem

ADR 0019 d19 (S265). The EU AI Act transparency obligations (Art. 50) need two things:

* People must be told when they talk to an AI (the TripPlanner chat/narration, CRM AI drafts).
* AI-generated text and images must carry a machine-readable mark.

The S265 restructure set this as a fixed deadline before 02/12/2026. Plain explanation and dates: `docs/audits/2026-11-03-S265-ecosystem-restructure/clarifications.md` (TL-19). Some notices already exist per app ([AA-1033](https://linear.app/aa-ecosys/issue/AA-1033/ai-output-notice-across-apps-one-kit-component-ai-clause-in-crm-and) shipped notices in S264).

## Scope

* **One kit component:** an `AiNotice` variant per audience in the CIS canonical kit, synced to consumers (ADR 0016). It is used in TripPlanner chat and narration, CRM AI drafts and the Content studio labels.
* **Machine-readable marking.**
  * Every AI-generated piece stores `ai_generated` metadata.
  * Published HTML carries a meta tag or attribute.
  * Social posts carry the platform's AI label where its API supports it.
* **Docs:** the AI Use Register and the tenant terms reference.

## Done-when

* On Dev, each surface shows the notice.
* Published pieces carry the mark; checked by a test and one live publish to the WordPress test site.
* Screenshots for each surface.
