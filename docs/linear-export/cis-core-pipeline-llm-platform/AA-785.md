# AA-785 — [T10 F1] Year-format tolerance — accept "YYYY–YY" / "YYYYs" when the seed has the year (warn until fixed)

## Problem

S234 gate evaluation (80 pieces vs panel): all 22 F1_grounding violations are year formats the panel never raised (e.g. "1637–38"); F1 wrongly held 2 light pieces.

## Scope

F1 number matcher: accept "YYYY–YY", "YYYY-YY", "YYYYs" when the seed contains YYYY; F1 warn-only for these until merged. Unit tests from the 22 cases.

## Done when

* Offline replay on the 80 S234 texts: F1 false positives 22 → 0, no real number error lost.
