## Problem

ADR 0020 (S271). The source-fidelity rule is restated in about 10 places with 16 contradictions (three meta bands, six widths of place background). Each step reads a different version of "the source". Several exits skip the checks (S1 hitl exit, server approve of an unedited version, T9 post-loop edits).

## Scope

* `writing_policy.yaml` v1, frozen from the S271 decisions D1–D16. Add a compiler and a lint: the eval rubric, LABEL_RUBRIC, rule config and route rows are generated from it, and CI fails on a hand restatement. Writer-prompt fragments stay byte-equal until W5, except the contradiction-resolving lines (CTA, meta band, background, meals) with a 3-piece smoke per writer (about $0.50).
* A contradiction fixture suite: fire/no-fire twins per topic, run through every fixer, gate and rule.
* A FactSheet module (tour builder + route builder) as a parity refactor, then persistence (fs_id on the generated objects). Each line carries provenance (source_raw, human_verified, tenant_asserted, llm_derived, external).
* `final_contract` in REPORT mode on every exit of S1, T2 and T9, with a topology test. In T9, stored text sha must equal gated text sha.
* Input measurements: unanchored-atom share, pointer failures, master_drift census.

## Done when

* One policy_sha across all artefacts; 0 hand restatements; the code-vs-code contradictions go to 0; one meta band (140–155) in code.
* The contradiction suite is 100% as the policy expects.
* REPORT-mode final_contract runs on 100% of exits (topology test), and its report over the stored S1 v2 Masters is published.
