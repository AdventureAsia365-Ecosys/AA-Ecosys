# AA-774 — [Place cards] Keep "visiting/practical" card facts out of the writer seed; drafter writes only what/history/setting/naming

## Problem

S234 r4 blogs repeat place-card facts as trip promises: the permit sentence in 7/8 blogs; "Access requires a multi-hour horse or reindeer ride…" verbatim in 2 pieces; an invented "rim walk"; "visitors may witness \[shamanic practice\]". The drafter asks for "what visitors typically see, practical or safety notes" (`place_cards.py:90-92`) and `atom_seed._card_facts` (:112-116) drops the fact `kind`.

## Scope

1. `atom_seed.py`: `WRITER_FACT_KINDS = {what_it_is, history, setting, naming}`; filter card facts by `kind` (verify on Dev first that stored facts carry `kind`). Admin card view keeps all kinds.
2. Drafter prompt `place_cards.py:90-92` → plan §3.5 text (new cards only; bump PROMPT_SHA so misses re-evaluate).
3. Re-count thin moments (`THIN_FACTS=3`) on the 6 checkpoint requests offline and report before deploy.

## Done when

* r5: permit/access sentences 0/8 blogs; panel "invented sub-activity" ≤1/8; thin-moment count changes on ≤2/6 requests or the change is shown to Nghiệp.
