## Problem

The S229 T-series audit (`docs/architecture/t-series-audit-and-plan.md` §7 G6) found several parallel judge call paths (`invoke_judge`, judge_client, per-module helpers), T11 publish dispatch living outside `services/acp_publish`, and docstrings that still name retired models (e.g. "gpt-4.1 is the production judge" in `quality_gates.py`). All calls already go through the gateway; this is structure and accuracy, not routing.

## Scope

1. One judge client in `shared/llm_client` used by S1/T2/T10 judges.
2. T11 dispatch → `services/acp_publish`.
3. Remove/replace docstrings naming a fixed model (routes live in `shared.llm_role_config`).
   Out of scope: model changes ([AA-714](https://linear.app/aa-ecosys/issue/AA-714/llm-judges-on-gpt-luna-instead-of-gpt-41-ab-gpt-6-luna-vs-gpt-56-luna)).
