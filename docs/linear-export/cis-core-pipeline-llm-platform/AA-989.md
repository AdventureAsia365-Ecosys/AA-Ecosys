## Problem

After the S1 re-atomize ([AA-645](https://linear.app/aa-ecosys/issue/AA-645/eval-claude-sonnet-5-for-writer-stages-t2-generate-t8-angle-gen-t9)), the place layer still points at replaced atoms. Measured on Dev 25/10/2026 (S251):

* `geo.tour_place`: 2,480 rows for 123 tours; **2,038 rows reference atom ids that are no longer active**.
* Place cards: 112 (`auto_checked`); only 105 active atoms link to a card (\~0.4%).
* `acp_contract.atom_embedding`: 2,263 / 25,877 active atoms have an embedding (9%).
* `gold_aa_internal.published_tours.content_embedding` is NULL for all 892 active tours.

## Scope

1. Re-sync `geo.tour_place.atom_ids` (and `place_card_id`) to the new atoms for the 123 tours, then extend tour_place to the whole active catalogue through the existing place pass ($0 parts first; paid locate/days steps in subsets with cost).
2. Atom embeddings for every active atom (or the views that use them), with the embedding cost stated.
3. Decide `content_embedding`: still read anywhere? If not, record it for the Dead Table/column registry ([AA-850](https://linear.app/aa-ecosys/issue/AA-850/data-dead-table-registry-wave-1-quarantine-acp-gold-output-acp-silver)); if yes, backfill.
4. Coordinate with [AA-905](https://linear.app/aa-ecosys/issue/AA-905/data-geo-graph-backfill-for-the-8-countries-without-one-paid-place) (geo graph for the 8 countries without one) and [AA-784](https://linear.app/aa-ecosys/issue/AA-784/place-cards-platform-wide-build-7-97k-distinct-places-staged-by) (place cards platform-wide): this issue makes the existing rows correct; those two extend coverage.

## Done when

* 0 `geo.tour_place` rows referencing inactive atoms; tour_place covers every active tour that has place atoms (or a recorded reason).
* Active-atom embedding coverage ≥ 95% (or the consumer that needs them is named and covered).
* `content_embedding` decided and recorded (backfilled or registered as dead).
* Re-measured with the S251 coverage query, comment with numbers and cost.

Related: [AA-905](https://linear.app/aa-ecosys/issue/AA-905/data-geo-graph-backfill-for-the-8-countries-without-one-paid-place), [AA-784](https://linear.app/aa-ecosys/issue/AA-784/place-cards-platform-wide-build-7-97k-distinct-places-staged-by), [AA-850](https://linear.app/aa-ecosys/issue/AA-850/data-dead-table-registry-wave-1-quarantine-acp-gold-output-acp-silver), [AA-645](https://linear.app/aa-ecosys/issue/AA-645/eval-claude-sonnet-5-for-writer-stages-t2-generate-t8-angle-gen-t9).
