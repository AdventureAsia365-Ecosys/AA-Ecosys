## Problem

The approved AI & data provider gateway v2 (tech lead, S261 31/10/2026; root ADR 0009 draft, [AA-804](https://linear.app/aa-ecosys/issue/AA-804/ai-platform-root-adr-0006-ledger-v2-one-gateway-library-for); design `docs/audits/2026-10-31-S261-ai-gateway-design-v2/`) needs the registry to cover every paid provider kind and every model family as data. Today only CIS LLM connections are in the registry, the catalog `vendor` CHECK is a closed list (adding a maker needs code), `capabilities` is never read, request params live in code, and the model is chosen in several places. Design step 4.

## Scope

1. Jev, DataForSEO, Geoapify and Bedrock Guardrails as connection rows (kinds `decide`, `data`, `guard`) with `failure_domain`.
2. `llm_model_family` table; maker / host / path separated; capabilities read as data (reasoning mode, min output tokens, structured output, cache); drop the closed vendor CHECK.
3. `stage_model_params` (stage × model: max tokens, reasoning effort, temperature) read by every adapter, Converse included.
4. App dimension on routes (CIS, TripPlanner, CRM; Booking when needed); `account_route` replaced by a per-connection role list (acc2 = embed + judge/validate only, per the tech-lead decision).
5. Structural config changes by migration (reviewed); admin keeps toggles, priority, limits, budgets.
6. One place selects the model (no per-call bypass outside eval/probe).
7. UI: gateway page Routing tab, Models tab, connection drawer for the new kinds and read-only secret/URL/price, Budgets merged (provider / connection / app / stage / tenant / eval scope); Settings › Models and Jev Credit tabs removed with redirects.

No route change in this issue; no paid run.

## Done when

- [ ] Adding a model or a provider of a known kind is one PR + DB Migrate, with no application code change (shown once with a disabled candidate row).
- [ ] The admin shows only toggles / priority / limits / budgets for the registry; secret names, URLs and prices are read-only.
- [ ] Route snapshot before and after is identical (no route changed).
- [ ] Unit + e2e tests green; screenshots desktop/phone, light/dark of every changed page.
