## Problem

With the lesson format live (part 1), learners still need a place to read, track progress, take quizzes and earn certificates. Design: [AA-1098](https://linear.app/aa-ecosys/issue/AA-1098/knowledge-aa-learning-site-lms-courses-built-from-every-domain-method) `docs/research/lms/` §5–7 (approved S279; D17: `academy.<env domain>` served by the CRM web, courses and progress in the CIS API).

## Scope

1. P3: `learn` schema (migration, RLS, retention rows), the learning API in CIS, the academy reader and progress on `academy.lumiguides.it.com` (certificate, DNS record, one ALB host rule), presigned video URLs, link from CIS admin.
2. P4: server-graded quizzes, FSRS review, lab checker hook, certificates and the verify page, thresholds on the settings page.

Out of scope: lab environments (P4b), content paths (P5+).

## Done when

* `https://academy.lumiguides.it.com` serves the reader for an E2E staff sign-in and shows the sample lesson with progress saved.
* A quiz is graded on the server; passing issues a certificate whose verify page answers 200.
* Migration applied via DB Migrate; isolation probe green; settings editable on the admin page.
