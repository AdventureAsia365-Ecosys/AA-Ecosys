## Problem

The S278 system audit found four small defects that a pilot agency would hit on day one:

1. **M3 (CIS):** a blog piece held by the gates can still be published (v1 publish), with no warning.
2. **M13 (Booking):** the confirmation and voucher show the end date equal to the start date, and a B2B case shows "Custom trip".
3. **M6 (Content studio):** the piece preview drawer shows the internal brief and search context to the agency.
4. **M9 (legal pages):** the terms still say agencies sign in with an API key.

## Scope

Fix each defect where it lives, with tests. No new paid service.

## Done when

* A held piece cannot be published without an explicit, audited override. Agencies get a clear message.
* The voucher and confirmation show end = start + days − 1 (live PDF check). The B2B case shows the tour name.
* The preview shows the agency only its own text and the AA notice. A live screenshot confirms it.
* The legal page wording matches the sign-in that is live today.
* A live check is recorded for each item.
