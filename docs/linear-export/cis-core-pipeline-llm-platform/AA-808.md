# AA-808 — [Place cards] Drafter must not append traveller clauses to background facts

## Problem

The S235 card-kind audit covered 110 cards and 732 facts (root repo `docs/audits/2026-10-14-S235-ecosystem-team-pilot/card-kinds-audit/`). It found 31 writer-kind facts that carry access, view or itinerary promises. In most of them the drafter takes a valid physical fact and appends a traveller clause, for example:

* "…, making it a natural stopping point"
* "on clear days offers views of…"
* "standard inclusion on visits"
* "staging point for travel"
* "accessible to visitors"

Those 54 facts were re-kinded by hand through the [AA-774](https://linear.app/aa-ecosys/issue/AA-774/place-cards-keep-visitingpractical-card-facts-out-of-the-writer-seed) endpoint (PR [AdventureAsia365-Ecosys/AA-CIS-App#716](https://linear.app/aa-ecosys/review/feat-admins-can-re-kind-edit-or-drop-place-card-facts-audited-b7e8ffc9509a)). New cards will repeat the pattern unless the drafter changes.

## Scope

1. Add a rule to the drafter prompt in `services/acp_shared/place_cards.py` (`_CARD_SYSTEM` / extraction prompt): a what_it_is/history/setting/naming fact describes the place only. It must contain no clause about how travellers reach it, views they will get, what visitors do, itinerary combinations or "making it a stop/base". Such content is either its own visiting/practical fact or is left out.
2. Bump PROMPT_SHA. The change affects new cards only.
3. Add a deterministic post-check in `_clean_facts`: a writer-kind fact that matches traveller-clause patterns (views, access, "making it", "visitors", "combined with", "staging/stopping point") is re-kinded to `visiting`/`practical` and logged. This stays as a cheap guard even when the prompt drifts.
4. Unit tests built from real audit examples: the 31 agreed leaks must all be caught by the post-check, with no more than 3 false positives on the 22 agreed pure-background facts.

## Done when

* Merged and deployed. A trial build of about 3 new cards on Dev shows 0 writer-kind facts with traveller clauses (Claude panel check).
