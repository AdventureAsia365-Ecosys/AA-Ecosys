# AA-747 — [S1 pipeline] Trim LLM calls per tour — seo_meta out of flag_fix, cap itinerary nudges, S1 starts while SEO prefetch is still running

## Problem

S218 audit v4 measurements from 01/10 to 08/10:

* **flag_fix and seo_meta.** Before [AA-740](https://linear.app/aa-ecosys/issue/AA-740/s1-pipeline-deterministic-seo-meta-seo-title-length-fit-after-the-last), 91% of flag_fix passes existed only to fix seo_meta length. [AA-740](https://linear.app/aa-ecosys/issue/AA-740/s1-pipeline-deterministic-seo-meta-seo-title-length-fit-after-the-last) now fits seo_meta deterministically after the last LLM edit, but seo_meta can still be sent to the LLM fix pass.
* **Itinerary nudge.** 4,220 calls ($6.38): one LLM call per compressed day, up to 34 per tour, and ITINERARY_STILL_COMPRESSED is still common.
* **SEO prefetch.** It runs at cap 1, about 8 min per 50 tours. S1 for the batch waits for the whole prefetch to finish.
* **Judge shadow.** gpt-6-luna runs on 100% of samples ($2.23) while [AA-714](https://linear.app/aa-ecosys/issue/AA-714/llm-judges-on-gpt-luna-instead-of-gpt-41-ab-gpt-6-luna-vs-gpt-56-luna) is in review.

## Scope

1. Exclude seo_meta and seo_title from flag_fix fields whenever the deterministic fit lands in band; the fit stays the only fixer for length.
2. Cap nudges per tour (e.g. 3). Then ask for per-day target lengths in the main generate call instead of fixing day by day (measure on 10 tours first).
3. Enqueue S1 per tour as soon as that tour's SEO context exists (prefetch in small batches) instead of waiting for the whole prefetch.
4. After [AA-714](https://linear.app/aa-ecosys/issue/AA-714/llm-judges-on-gpt-luna-instead-of-gpt-41-ab-gpt-6-luna-vs-gpt-56-luna) is decided: shadow judge sampling at 10–20%.

## Done when

On a 50-tour wave:

* flag_fix runs on ≤ 15% of versions;
* nudge calls are ≤ 3 per version (per generate attempt — decided S223: a retry is a new text and may compress again);
* the first S1 starts < 2 min after the wave is enqueued;
* pass rate and judge score are not worse than the S218 baseline (India: 86% / 7.69).
