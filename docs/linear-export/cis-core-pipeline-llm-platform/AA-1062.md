## Problem

The Content studio partner terms and privacy pages (EN + VI, AA-Partner `web/app/(studio)/legal/partner-terms/terms.messages.ts` and `web/app/(studio)/legal/privacy/privacy.messages.ts`) still say an OpenAI model "may write it as a last resort". This has been stale since CIS 383. The same sentence is in the readiness packet Annex A and in the current-text part of root `docs/architecture/ai-use-register.md`. It over-discloses but does no harm.

## Scope

* One AA-Partner PR: Draft v0.6 of both pages in EN and VI, with the provider sentence matching route control today, plus a guard test that fails when the pages name a provider route that the AI Use Register does not list.
* The root copy of Annex A and the register's current-text sentence. Register line 90, the v1.12 history entry, stays as it is.

## Done-when

* `portal.lumiguides.it.com/legal/partner-terms` and `/legal/privacy` show Draft v0.6 with no "last resort" sentence, in EN and VI.
* The guard test is in CI.

Split from [AA-820](https://linear.app/aa-ecosys/issue/AA-820/legal-tenant-terms-clause-for-the-anthropic-usage-policy-effective) (S275, tech lead approved on the S275 decision page).
