# AA-691 — [A1 + Jev] Grounding check for master content — S1 output must be supported by the raw source

Design: `docs/architecture/at-series-v2-design.md` §4.1 A1-1.

## Problem (verified)

* A1 (S1 master rewrite) has **no grounding check**, apart from the meal/time regex in `brand_audit_node`.
* T3 compares a tenant rewrite with master content, not with the raw source. A fact invented in master content therefore reaches every tenant and passes T3.

## Scope

1. **Deterministic:** run `find_novel_numeric_claims` (already used by T3) on A1 output against the raw source fields → a hard code `UNSUPPORTED_NUMBER`.
2. **Jev:** code splits the rewritten fields into sentences; Noul per sentence "Is this supported by the source itinerary (paraphrase, unit conversion or sums allowed)?".
   * Reject → a hard code `UNSUPPORTED_CLAIM` with the sentence quoted, passed to flag_fix as specific feedback.
   * Grey → a soft note in the Review Queue.
3. The Review Queue shows the quoted sentence and the Jev probability.
