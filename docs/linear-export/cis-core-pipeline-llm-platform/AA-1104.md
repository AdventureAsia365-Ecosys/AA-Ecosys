## Problem

The tech lead approved the AA learning site design ([AA-1098](https://linear.app/aa-ecosys/issue/AA-1098/knowledge-aa-learning-site-lms-courses-built-from-every-domain-method), `docs/research/lms/`, 31 decisions approved S279; D17: `academy.` subdomain on the CRM web). Lessons can only teach what the repo sources say, and several sources are missing or disagree (gaps G2, G5, G6, G7, G13). Lessons also need a file format and a publish bundle before any course is written.

## Scope

1. P1: write the gap pages G2 (testing strategy), G5 (two working rules into the handbook operating model), G6 (canonical English rule pages), G7 (run-it-locally sections per `CONTEXT.md`), G13 (fix disagreeing sources). G1 comes from the playbook build.

Out of scope: schema/API/UI (part 2), course content (P5+).
