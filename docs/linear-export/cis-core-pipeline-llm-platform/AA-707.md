# AA-707 — [T2] Tenant rewrite uses keywords + PAA for the tenant's own market (research cache), not the admin's US keywords

T2 buys no DataForSEO (KAN-90, correct) but reads only `top_keywords` of the admin's `seo_context` row, which is **US market**. A tenant targeting UK/AU/DE/FR/NL gets US keywords, and PAA is ignored.

## Scope

* Resolve the tenant's market from its SEO config (same resolver as research, [AA-515](https://linear.app/aa-ecosys/issue/AA-515/rankingatom-score-stage-xep-hang-atom-djieu-kien-tien-quyet-cho-aa-510)/629).
* Read `acp_contract.search_demand` for that market: keywords naming the tour's title places / activity, volume > 0, top 10 by volume, plus their PAA.
* Use them as T2 `top_keywords` / `people_also_ask`; fall back to the admin `seo_context` row when the market has nothing for the tour (logged).
* Still zero DFS purchases from a tenant action.

## Done when

A UK-market tenant's T2 rewrite of a Bhutan tour receives UK keywords from the research cache (verified on Dev), fallback logged when none.
