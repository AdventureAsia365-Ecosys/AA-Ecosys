## Problem

ADR 0020 (S271). Behaviour still changes outside the gated path: runtime admin route and catalog edits, brand pack and SEO config edits, writing-memory releases, and upstream LLM fact producers. Dormant stages stay maintained but unused (t10_claims, seed-align tier 1, the adjudicator).

## Scope

* config_fp covers the route-control version, catalog deployments, stage params, mode flags, rendered prompt shas, policy_sha, writing-memory items and the brand / SEO / facts snapshots.
* UI edits on gated stages require an eval run id or a break-glass reason and are frozen during waves. Migration header rule: `-- eval: <run_id>` or `-- break-glass: <reason>`.
* Source-change fan-out ($0): a change to raw tours, facts, place cards, atoms or the Master re-checks the dependent objects.
* Delete or promote every dormant layer with its measured precision.
* Tenant writing-memory releases are constraint-only. Exemplars must pass a contract replay on that tenant's recent objects.

## Done when

* A seeded-regression PR (for example a meta band widened in the policy) fails CI without eval evidence.
* Replay shows 0 diffs after the deletions, and a grep shows 0 live paths for deleted stages.
* The source-change fan-out is shown on one tour.
