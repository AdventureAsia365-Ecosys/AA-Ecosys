# AA-744 — [Data] Deterministic backfill — 927 atoms with brand forbidden words + 32 legacy Masters with short seo_meta

## Problem

S218 audit v4 (08/10/2026), measured after the full rerun:

* **927 active platform atoms contain a brand forbidden word** (`explore` 918, `vibrant` 3, `embark on` 3, `discover` 2, `iconic` 2, `nestled` 1, `pristine` 1). Most were extracted before `_strip_atom_action` existed (PR [AdventureAsia365-Ecosys/AA-CIS-App#589](https://linear.app/aa-ecosys/review/fix-s218-audit-quick-fixes-atom-forbidden-strip-judge-path-status-ad196338c668)). Atoms feed tenant T-series content.
* **32 active Masters have seo_meta < 140 chars** (111–139). All were published 01–06/10, before [AA-740](https://linear.app/aa-ecosys/issue/AA-740/s1-pipeline-deterministic-seo-meta-seo-title-length-fit-after-the-last) (China 8, Laos 8, Korea 4, Thailand 4, Taiwan 3, Bhutan 3, Mongolia 2). No new ones since [AA-740](https://linear.app/aa-ecosys/issue/AA-740/s1-pipeline-deterministic-seo-meta-seo-title-length-fit-after-the-last).

## Scope

1. Atoms: apply `strip_forbidden` / `_strip_atom_action` (same substitutes as the 181-Master fix) to text + action of the affected atoms. Keep the atom ids stable (or re-derive and update segment membership if the id depends on the text — check first).
2. Masters: run `fit_seo_meta_final(meta, facts, tenant_forbidden)` on the 32 rows. Rows that cannot reach the band stay as they are and get listed.
3. Process per `destructive-ops.md`: DRY RUN diff (before/after per row) → snapshot/export to S3 → Nghiệp approval → apply → re-measure.

Out of scope: regenerating any content with an LLM.

## Done when

* Re-measure query: 0 active atoms with a brand forbidden word; 0 active Masters with seo_meta outside 140–155 (or an explicit list of the ones that cannot fit).
* Restore file on S3 for both sets.
