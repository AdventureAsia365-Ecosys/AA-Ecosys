## Problem

The S282 progress report and audit (G18, R29, G4) found two gaps left after [AA-1090](https://linear.app/aa-ecosys/issue/AA-1090/tripplanner-r8-tenant-custom-domain-for-the-agencys-tripplanner) (custom domains):

* `add_domain` does not check that the tenant holds the `tp.custom_domain` entitlement.
* Links to a verified tenant domain fail the d21 `subject_gate`.

CodeQL alerts #60 and #62 (ReDoS) are open, and AA-Partner has no CodeQL default setup.

## Scope

* `add_domain` refuses a tenant without `tp.custom_domain`.
* Verified tenant domains join the `subject_gate` allow-list.
* Fix the two ReDoS patterns.
* Turn on CodeQL default setup for AA-Partner.

## Done when

* Tests cover all three code changes.
* CodeQL #60 and #62 are closed.
* Partner CodeQL is on.
