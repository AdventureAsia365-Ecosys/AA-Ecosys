## Problem

Jev (TypeSafe) credit is paid per input token and has no batch tier, so its cost follows the number of calls. The S277 ledger read (11/11/2026) shows where it goes:

* Since the 04/10 top-up: 376,058 calls, 17.29 USD of 20 USD. About 2.71 USD is left (estimate).
* Last 7 days by stage: `a3_question_landing` 61k calls (1.00 USD), `a3_question_scope` 22k (0.40), `a3_demand` 24k (0.30), `a3_research` 13k (0.20). These four are about 80% of the week.
* One platform recompute on 09/11 made 111k calls in a day (1.74 USD).
* `decide()` already reuses the same wording for 180 days, so the spikes come from new wordings that a platform-wide recompute asks for, not from repeats.
* A normal day costs 0.1–0.15 USD. If credit runs out, Jev returns 402 and the stages fall back to code rules quietly (lower quality, no visible failure).

## Scope

* A recompute started by `a3_atomize` (scope platform) asks Jev only for the segments and questions whose inputs changed: the tours of the atomized version and the segments they belong to. Unchanged segments keep their stored verdicts.
* A spend estimate before a large recompute: the number of new Jev questions times the measured unit cost from `shared.llm_call_log`. Above a cap (setting, default 0.50 USD per run), the run is held with a bell and runs only when staff release it.
* The per-run Jev spend and call count are shown on the recompute job (job result and the job view).
* The low-credit alert threshold is now 6 USD (set live on the `typesafe` connection in S277). Keep it.

## Done when

* A test shows that a recompute after one atomized tour asks Jev only about that tour's segments.
* On Dev, the recompute after a 3-tour wave makes at most 10% of the Jev calls of the 09/11 run, read from `llm_call_log` by job.
* A recompute whose estimate is above the cap is held and shows the estimate; releasing it runs it.
* No change in the Score / Route outputs for unchanged segments (replay or a before/after read).

Created with the tech lead's approval, S277 (11/11/2026). Planned slot S278.
