# AA-694 — [A3 atoms/Score + Jev] Atom grounding, activity type, PAA landing (transit rule, country scope, belongs), demand ownership

Design: `docs/architecture/at-series-v2-design.md` §4.2 A3-1, A3-2, A3-5, A3-6. Ports Ms. Thư's tickets 01, 04 and 05.

## Now (verified)

* **Atoms:** "verbatim-derived" is enforced by prompt only.
* `land_questions_for_segment`**:** a question is shortlisted by one shared word, then always lands on the nearest atom of the same Segment (no distance cut), so `questions_count` (a Score axis) is inflated.
* `compute_demand`**:** a Segment claims a keyword's volume through one shared non-generic word.

## Scope

* **A3-1:** Noul per atom "Is this place-and-activity stated in this day's text?". Reject → not stored (logged).
* **A3-2:** Choice on `activity_type` when Haiku and `classify_exclusion` disagree.
* **A3-5:** rule: never land on a transit atom. Nouls: "about a place outside `<country>`?" and "would the asker be well served by an article about `<place — action>`?". Only accepted landings count.
* **A3-6:** Noul "does this keyword's demand belong to this moment?" on the best claimed keyword per Segment × market. Reject → next candidate. The verdict is stored so reruns stay deterministic.
