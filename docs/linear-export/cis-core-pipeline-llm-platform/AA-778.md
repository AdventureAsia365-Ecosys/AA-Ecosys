# AA-778 — [T9 voice] Em-dash — deterministic autofix, strip em-dashes from our prompts, then a residue guard

## Problem

182/195/200/182 em-dashes per 20 pieces (r1–r4), 14.2 per 1,000 words, 19/20 pieces in r4; panel AI-tells 4.75/10. Our prompts prime it: `acp_content_writing/prompts.py` 78, `acp_angle_gate/prompts.py` 28, `channel_spec.py` 25, `brand_pack.py` 8. chị Thư bans it in data and in the prompt.

## Scope (in order)

1. `hygiene.autofix` em-dash step (" — X — " → ", X,"; trailing " — X." → ": X." / ". X."), run after contrast-frame detection.
2. Remove em-dashes from prompt text (not code comments) in the 4 files.
3. Plan §3.1 first bullet (writer rule).
4. Add `—` to `_BANNED_PATTERNS_SEED` only after the offline check clears ≥95%.
   Count em-dashes inside tenant brand-pack data and report (T0 data, not fixed here).

## Done when

* Offline on `pieces_r4.json`: 0 em-dashes, 0 new comma splices in a 20-sentence sample; live r5 <1 per 1,000 words; panel AI-tells ≥5.5.

Plan 09 #5, §3.1. Cost $0.
