## Problem

S234 DB stats (80 pieces): 19/97 sentence retries (20%) added a new blocking fail, 18 of them F9; the regression guard reverted 16×. In 10/15 reverted pieces the F9 judge flagged a sentence it had passed one attempt earlier, unchanged (15/38 claims). Sentence repair fixes F9 49%; full rewrite fixed F9 0/6 (S233+S234). The F9/F8 judge is gpt-5.6-luna (judges must be non-Anthropic: ADR-2026-014/027); its run-to-run inconsistency is now the main source of blog holds.

## Scope

1. F9 path (`quality_gates.py:733-883`): per-job `f9_passed_sentences` (normalised quotes from earlier attempts) → drop re-flags of unchanged sentences, log `F9_sticky_pass`; pass via `run_quality_gates` kwarg.
2. Attempt 3 on blogs: an F1/F9 truth item still failing after one sentence repair is **cut** (`delete_flagged` + `tidy_after_cut`), not reverted/held. Attempt 2 stays sentence repair.
3. Judge A/B (adhoc, one-off ECS task, ≤$1): same F9 inputs ×3 runs on gpt-5.6-luna vs gpt-6-luna vs gpt-6-astra vs gpt-4.1 with fixed `seed` (AA-209) + temperature 0 → test-retest agreement and agreement with the S232 labelled claims; switch the `t10_judge` route only if clearly better.

## Done when

* r6 (n=20): retry-added-blocking-fail ≤8%; guard reverts ≤6/round; blog F9 holds ≤1/8; 0 blogs under `_BLOG_MIN_CHARS` because of cuts. Judge A/B report with a route decision.
