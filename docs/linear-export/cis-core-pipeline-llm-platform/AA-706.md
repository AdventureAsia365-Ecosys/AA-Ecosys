# AA-706 — [A1 + Jev] S1 keyword ideas — ask Jev "is this keyword about this tour?" (shadow first, then enforce)

S1 keyword ideas are filtered by substring today (keep an idea only if it names a title place or the activity, [AA-702](https://linear.app/aa-ecosys/issue/AA-702/admin-ui-audit-fix-broken-notifications-list-inconsistent-countscosts)). That misses synonyms ("Tiger's Nest" ↔ "Taktsang") and cannot judge intent.

## Scope

* New Jev question `a1_keyword_about_tour` (stage `a1_seo`, kind noul), seeded **shadow**.
* Asked in the `s1_seo_prefetch` job for each tour's candidate ideas (after the cross-tour exclusion, up to 30 per tour, by volume). State: tour name, country, title places, activity, keyword.
* Shadow: substring rule decides, verdicts go to `decision_log` for calibration on the rerun.
* Enforce (after calibration): an enforced accept keeps an idea the substring rule missed; an enforced reject drops one it kept.

## Cost

≈ $0.00002 per verdict, cached → < $1 for the 736-tour catalog.

## Done when

Shadow verdicts logged for the Bhutan wave; floors calibrated against Nghiệp's labels; question enforced.
