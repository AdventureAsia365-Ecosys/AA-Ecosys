## Problem

On 29/10/2026 the only chat source (Bedrock acc3) was blocked at account level and every writer stage stopped; loss of access was found by a paid eval run. The approved gateway v2 (tech lead, S261 31/10/2026) makes a **warm independent path mandatory**, and the tech lead stated that the direct APIs are **both Anthropic and OpenAI**. Design step 5 (`docs/audits/2026-10-31-S261-ai-gateway-design-v2/`, root ADR 0009 draft).

Live facts 31/10: the OpenAI key works (call returned 200, limits intact; the system spent \~1.72 USD in Sep and \~0.73 USD in Oct, last call 02/10). The Anthropic API path is prepared on Dev (two stages scoped, 150 USD/month cap) but has no key yet.

## Scope

1. Warm paths: Anthropic API (writer stages) and OpenAI API (judge stages), each capped (monthly cap stated and approved before enabling) and probed.
2. Daily probe per connection × deployment on Dev (< 1 USD/month), per-model access state and last probe time; lifecycle/EOL status.
3. Route deadline (total time cap incl. fallbacks); Bedrock clients built from the connection's timeout / retries (no hidden SDK retries).
4. Connection-level circuit (an account-wide block opens once); a provider spend-cap refusal stops that connection (`quota_exhausted`).
5. Re-queue of `llm_access_denied` jobs after recovery; jittered job backoff.
6. Instant alerts via the admin bell and the existing ops alert e-mail; provider section in the OPS-12 daily digest.
7. Failure-domain rule: every stage class has ≥ 1 enabled, funded fallback in another failure domain (report-only on Dev).
8. Monthly failover drill on Dev (\~0.25 USD each): one writer stage to Anthropic, one judge stage to OpenAI.
9. UI: probe and circuit state on the Providers tab, rule badges on Routing, re-queue action, drill report.

No route change and no paid run without the tech lead's explicit yes per run.

## Done when

- [ ] Both direct APIs have a key, a cap and a green probe; the availability strip shows two failure domains green.
- [ ] Drill report: a writer stage reached Anthropic and a judge stage reached OpenAI within the route deadline, with cost.
- [ ] Tests for deadline, connection circuit, `quota_exhausted` (fixtures from the documented refusal bodies), re-queue.
- [ ] A refused access shows in the bell/e-mail within the probe interval, without a paid job failing first.
