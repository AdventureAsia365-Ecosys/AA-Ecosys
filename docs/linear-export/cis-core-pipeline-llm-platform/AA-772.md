# AA-772 — [Place cards] Verified per-place fact cards (region, era, visit length, practical/safety notes, display name) as citable source for T2/T9

## Problem

S232 audit: content quality follows how many verified facts the seed holds (Trail Pulse \~3.6 facts/100 words → 4/6 light-edit; Pawangka \~1.5 → 0/12). A LinkedIn post about Pawangka had \~4 facts for 250–300 words, so the writer invented scene detail and location (Luang Prabang, Ladakh, "a monastery in China"). The [AdventureAsia365-Ecosys/AA-CIS-App#671](https://linear.app/aa-ecosys/review/fix-t9-location-in-seed-background-allowed-scene-detail-forbidden-aa-d6bda52760f1) "widely known background" allowance is unverifiable and caused unsourced cultural claims in approved pieces.

## Scope

1. A place card per Segment place: display name with city/region/country (e.g. "Pabongka Monastery, Lhasa, Tibet"), 6–12 verified facts (era/founder, what it is, typical visit length, altitude, practical and safety notes, naming sensitivities), provenance per fact.
2. Generate once per place (gateway call, logged), verify with the gateway LLM judge (no Jev — T-series stays off Jev for real tenants, S232 decision) plus a small spot-check; store as platform Facts (`acp_shared.facts` scope platform, linked to the place) — owner migration if a new table is needed.
3. T9/T2 seed cites card facts; background claims may only come from the card (replaces the [fix: T9 location in seed + background allowed, scene detail forbidden (AA-768 round 5)](https://linear.app/aa-ecosys/review/fix-t9-location-in-seed-background-allowed-scene-detail-forbidden-aa-d6bda52760f1) allowance); length tied to usable facts.
   Out of scope: the TripPlanner place pipeline move ([AA-712](https://linear.app/aa-ecosys/issue/AA-712/adr-0002-move-the-place-pipeline-itinerary-places-geocoding-tour-graph)) — reuse it if it lands first.

## Done when

* Cards exist for the places in the S232 measurement set + G7 tour list, each fact with provenance.
* A/B on the same 5 briefs (thin seed vs place card, n ≥ 20 each): fidelity and light-edit share improve, F9 hold rate drops; numbers reported.
