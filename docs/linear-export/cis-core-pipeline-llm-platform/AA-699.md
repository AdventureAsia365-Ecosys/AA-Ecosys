# AA-699 — [T-series + Jev] T0 brief sections, T2 judge, T3 grounding — reuse A1 questions where identical

Part of [AA-696](https://linear.app/aa-ecosys/issue/AA-696/t-series-jev-jev-for-allow-listed-test-tenants-t0-brief-t3-grounding). Design: `docs/architecture/at-series-v2-design.md` §4.3 (T0-1, T2-1, T3-1).

Decision (Nghiệp, S206): test tenants have almost no T-series data (5 T2 rewrites, 3 pieces, 3 angle requests), so we cannot calibrate \~200 items per question now. Wire everything through `decide()` (allow-list tenants only). Questions that are **identical** to an already calibrated platform question reuse its Calibration Record and may enforce. Every other question runs in shadow and is calibrated from the rerun's `decision_log`.

## Scope

* **T3-1:** tenant rewrite grounding (`tenant_pipeline._t3_grounding_check`). Numbers the regex flags + non-numeric sentences → `a1_claim_supported` (same question: "is this sentence supported by the source?"). Supported → no full rewrite. Reuses the A1 Calibration Record → enforce.
* **T2-1:** tenant judge tie-break → `a1_brand_fit` (shadow, like A1).
* **T0-1:** brand brief section Choice when fewer than 8 sections are found. ~~The parser is a flat-zip Lambda~~ **Premise outdated (S229):** the Lambda is retired; parsing is in-process python-docx at `POST /admin/brands/parse-docx` (`admin_pipeline.py`), so `decide()` can be called directly — no Infra change. Shadow first.

## Done when

Allow-listed tenant: `decision_log` rows for each point; a non-allow-listed tenant shows `zone=skipped`. T3 on one of the 4 new [AA-741](https://linear.app/aa-ecosys/issue/AA-741/t-series-audit-end-to-end-t0t11-test-run-on-controlled-tenants-per) brand tenants (WanderLux is being retired): a flagged number that the source supports no longer triggers a rewrite.
