# AA-792 — [T2] Tenant-voice writer prompt — T2 writes in the tenant's brand, not A1's neutral voice; judge gates on brand fit only

## Problem

T2 is the tenant's product, but its writer reuses the A1 master prompt ("neutral voice, never adopt a persona", tenant prompt "append only"). The judge then marks the copy as generic and caps the score at 6 when a "mission" is missing — a field the brand profile does not have (mission judged missing in 72/104 calls, 0 of those passed). Mean T2 scores: Trail Pulse 4.0, A&H 5.0, WildKind 5.75, Terra 7.0 vs A1 8.0 on the same tours; 21/104 judge calls passed. Nghiệp (S234): "T2 cần prompt riêng để viết đúng brand tenant — sản phẩm của tenant mà".

## Scope

1. A T2-specific base prompt (`prompts.py:112-130,374-383`, `batch_prompt.py:105`): write every section in the tenant's brand voice from the T0 brand pack (tone, audience, style guide, good examples, forbidden words, CTA); drop the neutral-voice and append-only rules for `is_tenant_rewrite`; keep "no invented facts".
2. Judge (`judge_node.py:33,134,141`, `brand_fit.py`): gate on brand fit only (as A1); log cross-brand-distinct and mission as diagnostics with no cap until a mission/core-idea field exists in T0.
3. Rerun the same 14 tour×tenant pairs (≤$5, approved).

## Done when

* Rerun: mean brand fit ≥7 per tenant; Nghiệp reads the Trail Pulse and A&H versions and confirms the voice.
