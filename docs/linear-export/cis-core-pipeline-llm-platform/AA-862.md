## Problem

[AA-856](https://linear.app/aa-ecosys/issue/AA-856/tripplanner-search-fails-under-load-cohere-embed-v4-quota-is-20) (closed S239): Cohere Embed v4 on acc2 is capped at 20 requests per minute. The `us.` quota L-EB8C1F30 is fixed. AWS declined the request to raise the global quota L-7089DC7D from 20 to 2,500 (case 179212369200770, 16/10, "account history / usage patterns").

Search never fails: the query cache and the keyword fallback catch it. But above about 20 searches a minute, results rank by keyword instead of meaning. CIS `f10_embed` / `a3_place_embed` share the same 20 rpm.

## Decision (Nghiệp, S239)

Chain per embed call:

1. query cache;
2. acc2;
3. acc3 (main satellite, 786888028788);
4. acc1 (fallback satellite, 867490540162);
5. keyword fallback, last.

Later, once acc2 has some usage history, re-request the acc2 quota in smaller steps and move the traffic back.

## Scope

1. In each satellite account (us-west-1), read and record the quota and model access for Cohere Embed v4: L-EB8C1F30 / L-7089DC7D, inference profile active, model access granted.
2. Add catalog/route entries so `tp_search_embed` (TripPlanner gateway) and `f10_embed` / `a3_place_embed` (CIS gateway) fall back to the same model `cohere.embed-v4:0` in acc3, then acc1, on throttle. Use the existing satellite pattern (AA-296, role `AA-Bedrock-Invoker`). Same model, so vectors stay comparable and nothing is re-embedded.
3. IAM:
   * the TripPlanner Lambda role and the CIS task role may assume the satellite invoker roles;
   * the satellite roles allow `bedrock:InvokeModel` on the Cohere Embed v4 profile;
   * all in Terraform, targeted apply.
4. Log the account per call in `shared.llm_call_log` (account acc2/acc3/acc1) and the fallback reason.
5. Calendar note: re-file the acc2 quota request (for example 20 → 100) after about 3–4 weeks of usage, then reorder the chain.

## Done when

* A burst like [AA-856](https://linear.app/aa-ecosys/issue/AA-856/tripplanner-search-fails-under-load-cohere-embed-v4-quota-is-20)'s (unique queries, 15 concurrent for 60 s) on Dev shows semantic ranking well above 20/min, with `tp_search_embed` rows in `llm_call_log` from acc2, acc3 and acc1.
* 0 HTTP 5xx, and keyword fallback only after all three accounts throttle.
* IAM and catalog changes are applied and in Terraform/migrations. Quota values per account are recorded on this issue.
