## Context (S191, [AA-603](https://linear.app/aa-ecosys/issue/AA-603/cleanup-drop-cum-bang-n7n8-dead-sau-khi-go-code-reader-deploy))

[AA-603](https://linear.app/aa-ecosys/issue/AA-603/cleanup-drop-cum-bang-n7n8-dead-sau-khi-go-code-reader-deploy) removed the old atom-weight feedback loop (`content_metrics.py` + `POST /v1/planning/metrics[/rollup]`) because it was wired to the dead N7/N8 schema (`acp_deliver.pieces` + `acp_shared.acp_v2_slots` + `content_metric_snapshot`), never ran on real data (every `tour_atoms.weight` was still the neutral 1.0), and its only downstream consumer was the N5 quarter-plan `engagement_adjustment` term (also effectively dead).

The **idea** was sound and is worth keeping: measure real post-publish engagement (reach/clicks/views) → feed it back into ranking so the system learns what content actually performs. The T-series pipeline currently has **no** engagement feedback loop — ranking (`acp_contract/atom_ranking.py`) is fully deterministic (demand / recurrence / PAA / said, ADR-0014), with no learning signal from published content.

## Why the old build could not simply be kept

* It read `acp_deliver.pieces` (dead), not the live T-series content store `acp_shared.content_piece`.
* It only influenced `quarter.py`'s `engagement_adjustment` term, not the live slate/angle ranking (`atom_ranking`), so even if it ran it changed nothing users see.

## What a real rebuild would need (investigate-first, not committed)

1. **Source of engagement data** — manual entry to start (same pragmatic starting point as the old build), reading/writing against `acp_shared.content_piece` + `acp_shared.publish_log` (the live T11 tables), NOT the dropped N7/N8 tables.
2. **Where it plugs into ranking** — decide whether engagement becomes a 5th rank-sum axis in `atom_ranking.rank_segments` (keeping it deterministic), or a separate re-rank pass. The old `tour_atoms.weight` → quarter-plan path is the wrong target.
3. **Automation later** — a real Search Console / Meta connector instead of manual entry, once the manual loop proves the model.
