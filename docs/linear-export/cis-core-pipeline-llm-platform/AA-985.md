## Problem

S248 [AA-984](https://linear.app/aa-ecosys/issue/AA-984/t9-blog-holds-f9-claims-on-heading-lines-are-unrepairable-over-long) live check: blog piece 4b58f52c (request 3c9dc7bb, Bhutan) was held on **F17_trip_fact** — "says it still holds a role the source dates as ended (the capital and seat of government of Bhutan, until 1955)" — for the sentence "Like all dzongs, it houses both monk bodies and government offices for district administration". The source dates only the *capital* role as ended; the dzong is still a district administration seat. The temporal-role rule matched a different, still-current role. This looks like a false positive, and the same rule shape (an ended role vs. a current, different role of the same place) probably fires elsewhere.

Nghiệp (S248 decision d18): analyse whether the error is systematic, find similar errors, and move toward calibration / self-learning for the whole system, not a one-off patch (see S248 decision d17: a labelling mechanism or page for every stage/flow, not only tour writing).

## Scope

1. Reproduce: the F17 temporal-role check on 4b58f52c's text + source (regression test from that shape).
2. Census (read-only): every F17 temporal-role hit since 01/10 on T9/T2 pieces, classify true vs false positive (agent panel + sample for Nghiệp), and the same for the other deterministic fact rules that share the matcher.
3. Fix the matcher so a role is "ended" only when the sentence claims the same role the source dates as ended (role identity, not place identity); tests for both directions.
4. Design memo (root docs/audits): a cross-stage calibration loop — error taxonomy, labelled sets per stage, regression gates in CI, measured precision/recall per gate, and how new labels feed back (self-learning) — reusing the [AA-783](https://linear.app/aa-ecosys/issue/AA-783/eval-human-calibration-of-the-t9-commercial-panel-40-pieces-labelled) label desk pattern.
