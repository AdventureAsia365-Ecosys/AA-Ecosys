## Now (verified, `services/ingestion/handler.py`, `shared/country_resolver.py`)

* Only exact duplicates are caught: file hash, and `lower(trim(name)) + provider`.
* The only drop rule is an empty itinerary. POI/hotel/transfer rows with some text get in (S184 trashed 30 POI by hand).
* Country comes from an alias table + the filename. Multi-country tours get one country; unknown → NULL.

## Scope

* **A0-1:** Jev Choice over tour / day tour / POI / accommodation / transfer / other. A confident non-tour → `ingest_details` drop `not_a_tour`. Grey → lands, flagged in the Upload preview.
* **A0-2:** a cheap shortlist of candidate pairs (name trigram within the country, or itinerary embedding) → Noul "same bookable product?". Accept → `upload_staging` for the existing human decision. Never auto-dropped.
* **A0-3:** Choice over the country master list when the resolver returns NULL or the text names another master country.
* **A0-4:** Noul "real day-by-day activities?". Reject → flagged `thin_itinerary`, excluded from the S1 batch.
* **A0-5** (column map → Jev Choice): shadow only.
* The Upload preview shows every Jev flag with its reason.
