## Problem

OWASP LLM Top 10 (LLM01 prompt injection, LLM05 improper output handling): AI text goes to agencies' WordPress sites as HTML converted from Markdown without sanitizing, and the preview does not show hidden markup. The S1 v2, T2 and T9 prompts carry supplier and source text without a fence that marks it as data. The prompt-injection trap set was last measured on writer v1.

## Scope

* Sanitize the HTML of every publish path (WordPress, Facebook, tenant pages) with an allow-list sanitizer; the preview shows what will be published.
* Put source and supplier text inside a clear data fence in the S1 v2, T2 and T9 prompts, with a system line that text inside is data, never instructions.
* Re-run the trap set (indirect injection in supplier text, hidden instructions, link and script injection) on the current writers; record pass rate and cost in `shared.llm_call_log` (small paid run, ≤ 1 USD, inside the caps).
* Tests that fail if a publish path skips the sanitizer.

## Done when

* A test post with script, iframe and event-handler markup publishes clean to the test WordPress site (screenshot).
* The trap set passes at the agreed rate on the current writers, with cost reported.
* CI guard for the sanitizer is green.
