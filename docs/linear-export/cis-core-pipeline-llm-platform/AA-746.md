## Problem

S218 reconciliation (08/10/2026): 10 `shared.pipeline_runs` rows are stuck at `status='ingesting'`: 7 from 20/07, 1 from 25/05, 3 from 01/10. `sync_batch_completion` (`services/export/handler.py`, [AA-476](https://linear.app/aa-ecosys/issue/AA-476/dashboard-6-muc-audit-aa-438-con-treo-3-double-fire-ingestion-p1-1211)) only counts `published`, `hitl_rejected` and `failed` as terminal. A batch that contains a trashed or superseded tour can therefore never complete. Display only; no data is wrong.
