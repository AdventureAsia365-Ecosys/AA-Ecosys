## Problem

All 23,509 active platform atoms have `distinctiveness = 'MED'` (S218 audit v4). Distinctiveness is only computed on the tenant T5 path, which has a competitor index (AA-445-02). Platform A3 atoms keep the default, so the field carries no information but is shown and available to ranking and T-series.

## Scope

Pick one:

* **(a)** Score at A3 with a per-country competitor corpus (reuse `score_distinctiveness`, DFS SERP already fetched in prefetch).
* **(b)** Mark the field as unknown for platform atoms and hide it from UI and ranking until (a) exists.

Recommendation: (b) now, (a) when T-series needs it.

## Done when

No UI or ranking reads a constant MED as if it were a measurement: either the values are real, or the field shows "not scored".
