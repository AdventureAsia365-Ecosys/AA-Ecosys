## Problem

The S282 audit ([AA-1109](https://linear.app/aa-ecosys/issue/AA-1109/audit-whole-ecosystem-deep-audit-state-of-every-area-gaps-and-a-ranked); R11, R28, G12) found three gaps in how AI calls are protected and capped:

* The F3 personal-data scrub runs in the CRM path only, not in the shared gateway for every free-text stage.
* CRM AI calls do not all go through the gateway ledger and its connection caps.
* The acc3 budget does not catch Marketplace (Claude on Bedrock) spend.

## Scope

* The F3 scrub moves into the shared gateway for free-text stages, failing closed. Accept ADR 0009 d10.
* CRM AI calls go through the gateway ledger and the connection caps.
* An over-cap flag in `catalog.v_llm_gateway_config_v1`.
* The acc3 budget includes Marketplace spend, or matches the gateway cap.

## Done when

* A free-text call with a planted e-mail or phone reaches no model unscrubbed (test plus a live probe).
* CRM calls show in the ledger with caps applied.
* The budget covers Marketplace spend.
