## Problem

Content staff have no list of what is due. They check about 15 pages: Review Queue, supply copy, AA content, place cards, compliance holds and others.

[AA-1148](https://linear.app/aa-ecosys/issue/AA-1148/cis-content-workspace-create-and-edit-tours-by-hand-tied-to-an-aa)'s planned content desk (M0) waits for the tour editor, so it would arrive late.

## Decisions (tech lead, S285, 19/11/2026)

* Q8 = **(a)**: My work is two linked halves, this CIS page and the Booking dashboard band ([AA-1159](https://linear.app/aa-ecosys/issue/AA-1159/booking-my-work-on-the-staff-dashboard-permission-filtered-queues)). No cross-app view; CIS does not read Booking queues. A cross-app contract view is added only if switching between the two apps proves to be a real problem.

## Scope

* New page `/admin/my-work` ("My work"). It is shown by capability, never by person.
* **Content band.** Each tile shows a count, the age of the oldest item and one link to the exact filtered page:
  * Review Queue waiting
  * supply copy drafts, and hotels or activities with no description
  * AA content drafts
  * place cards to review
  * compliance holds
* When [AA-1148](https://linear.app/aa-ecosys/issue/AA-1148/cis-content-workspace-create-and-edit-tours-by-hand-tied-to-an-aa) lands, add these tiles: my drafts, returned to me, tours below 100% complete, tours without a cover photo.
* `landingPage()` sends content roles here. Admin keeps `/admin/overview`, with My work in the nav.
* A link "Booking: My work" opens the Booking dashboard through `appPageUrl`, for users with a Booking grant (from `/auth/verify-admin` once [AA-1155](https://linear.app/aa-ecosys/issue/AA-1155/booking-cis-custom-staff-roles-roles-as-data-one-combined-role-per) returns it; until then the link is shown to content roles).
* Refresh button, no polling. English by default, Vietnamese on choice. Built with the UI kit.
* Replaces [AA-1148](https://linear.app/aa-ecosys/issue/AA-1148/cis-content-workspace-create-and-edit-tours-by-hand-tied-to-an-aa) M0.

Out of scope: Booking queues ([AA-1159](https://linear.app/aa-ecosys/issue/AA-1159/booking-my-work-on-the-staff-dashboard-permission-filtered-queues)), any cross-app read (Q8).
