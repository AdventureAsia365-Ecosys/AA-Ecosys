# AA-779 — [T9 FAQ] Questions from People Also Ask first; every answer names its question's subject

## Problem

r4 FAQ non-answers in #5, #17, #19 ("Who are the Tsaatan?" left unanswered). The PAA list is already in `dfs_paa_snapshot` but T9 reads only `related_keywords` (`service.py:924-925`); `write_faq` invents questions (`generate.py:431-444`). chị Thư takes FAQ questions only from PAA (`write.py:96-102`), answers 40–60 words.

S245 checkpoint: both blog requests had **no** PAA. Cause (confirmed by read-only SQL): the only SERP T8/T9 can use is the tour-level one on the tour title ("Khovsgol and Gobi tour Mongolia", US, 02/10), and Google showed no PAA box for that rare query. 648/918 tours (71%) do have PAA. Two of the route's 10 Segments already hold 10 matched questions (`acp_contract.atom_matches`, kind `question`) that T9 never reads.

## Scope

1. Done (CIS [AdventureAsia365-Ecosys/AA-CIS-App#870](https://linear.app/aa-ecosys/review/feat-faq-uses-in-scope-people-also-ask-questions-and-every-answer-ca851d678227)): scope-filtered `people_also_ask` passed as search questions into the blog writer, rewrite and `write_faq`, plus a deterministic subject check next to F16.
2. **Real-question source chain** for blogs (owner-approved S245): (A) Segment/place-level questions already in the DB (`atom_matches` kind `question`, `search_demand.people_also_ask`), $0; (B) admin-side top-up: one SERP per place still without questions, `people_also_ask_click_depth=2`; (C) fallback DataForSEO Autocomplete with question prefixes. LLM-invented questions never count as real. Each piece records the source of its questions (visible in admin only). Top-up buys run in an admin job only, ≤ $3 total; tenant actions buy no DataForSEO data ([AA-646](https://linear.app/aa-ecosys/issue/AA-646/p0bug-dfs-research-runs-platform-wide-after-every-tenant-rewrite-scope)).
3. Block off-meaning PAA (e.g. "moron" pulls questions about the insult, not the town Mörön) through the existing scope filter.

Advice and SQL: root `docs/audits/2026-10-20-S245-aa779-paa/README.md`.

## Done when

* ≥ 80% of blog Subjects have ≥ 3 real, in-scope questions after A → B → C (measured once, read-only; below 80% = not Done).
* Next 8-blog checkpoint: ≥ 6/8 blogs use ≥ 2 real questions, and ≥ 50% of FAQ questions come from a real source.
* The panel finds 0 FAQ non-answers in the 8 blogs; F16_faq holds stay 0; every answer passes F1 grounding.
