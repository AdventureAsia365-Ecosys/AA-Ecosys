## Problem

Only the final attempt's `gate_ledger` is stored (warn results at attempt 1 known for 45/80 pieces); 6 gates fired 0 times in 80 pieces so their precision/recall cannot be measured; no human labels exist.

## Scope

1. Store each attempt's ledger (repair_log entry or a column).
2. Content Quality drawer: "Label" action (as-is / light / heavy / reject + reason) → `content_piece_label` (CIS migration).
3. 30 synthetic pieces with planted faults to test rare gates in CI.
   Human labelling of 40 pieces is tracked in [AA-783](https://linear.app/aa-ecosys/issue/AA-783/eval-human-calibration-of-the-t9-commercial-panel-10-pieces-scored-by) (criteria pack ready).

## Done when

* New pieces keep every attempt's ledger; label action works on Dev (UI verified); fault set in CI with each rare gate catching its planted fault.
