# AA-645 — [EVAL] Claude Sonnet 5 for writer stages (t2_generate, t8_angle_gen, t9_write, s1_atom_writer) vs Sonnet 4.5/4.6 on Bedrock

*Created S198. The writer tiers are a generation behind. Evaluate before moving; decide by data, like* [AA-619](https://linear.app/aa-ecosys/issue/AA-619/sub-cmeasure-ab-atomize-haiku-vs-sonnet-ha-t5-atomize-xuong-haiku) *and* [AA-620](https://linear.app/aa-ecosys/issue/AA-620/sub-gbe-tach-stage-t2-generate-config-ui-sonnet-cho-t2-tenant-a1-giu)*.*

## Current state (code read, `main` c5b8c6f)

* **acc2 native T1:** `us.anthropic.claude-sonnet-4-5-20250929-v1:0` (`pricing.py BEDROCK_SONNET`).
* **acc3/acc1 satellites** (the common path in practice): `global.anthropic.claude-sonnet-4-6`.
* **Haiku 4.5:** `global.anthropic.claude-haiku-4-5-20251001-v1:0`.
* **TripPlanner compose/renarrate:** `global.anthropic.claude-sonnet-4-6` (`backend/config.py`).
* Stage defaults: `t2_generate`, `t8_angle_gen`, `t9_write` and `s1_atom_writer` are Sonnet. `s1_generate`, `t5_atomize` and `s1_flag_fix` are Haiku.

## Why look

First-party list prices: **Claude Sonnet 5 costs $2 / $10 per 1M, versus Sonnet 4.6 at $3 / $15**. So Sonnet 5 is both newer and cheaper per token at list price. Bedrock pricing is partner-set, so check the Bedrock pricing page for the real rate. Haiku 4.5 ($1 / $5) remains the cheapest Claude.

## API differences to handle (Sonnet 5)

* `temperature` **/** `top_p` **/** `top_k` **return 400.** CIS Bedrock bodies do not send `temperature` today (verified: `_call_bedrock*` / `invoke_claude` bodies carry no sampling params). `LLMRequest.temperature=0.7` is only forwarded to OpenAI, so there is no change needed, but add a test so nobody adds it later.
* `budget_tokens` **returns 400**, and thinking defaults to adaptive when omitted. Thinking tokens are billed, so set `output_config.effort` (low/medium for rewrite) and measure.
* **No assistant prefill.** Verified: no prefill anywhere in CIS.
* **Model id / inference profile on Bedrock:** confirm the Sonnet 5 inference profile is enabled on acc3/acc1 in us-west-1. Native acc2 Sonnet is blocked for channel-program accounts (AA-291/AA-329 history).
* **Tokenizer and pricing:** add a catalog/pricing entry before any traffic moves. Otherwise the unknown-model fallback misprices it.
