# AA-768 — [T9 writer] Source fidelity — the writer invents numeric facts; 5/5 pilot pieces held by F1_grounding / F9

## Problem

S231 G3 pilot (`docs/audits/2026-10-12-S231-t-series-pilot.md`): 5/5 final T9 pieces (2 blog, 3 LinkedIn, 3 brand tenants) ended `held`. Tenants received nothing publishable.

* **F1_grounding** — the writer states numbers that are not in the content seed: "900-metre drop", "3,120 metres", "since the 1970s", Laos e-visa price and processing days, "12-day", "16/7".
* **F9_cta_fact** — audit returns `manual_check` (FACT_CHECK_MANUAL_CHECK) on the repaired attempt.
  The one repair attempt per piece did not fix it (attempt 2 held again). Cost is still paid: blog ≈ $0.14, LinkedIn ≈ $0.057 per piece.

The S1 writer got the source-fidelity rule in S223 ([AdventureAsia365-Ecosys/AA-CIS-App#629](https://linear.app/aa-ecosys/review/feat-s1-writer-may-add-place-background-never-tour-promises-the-source-8199b63e3634)): background about named places is allowed (A), promises/numbers the source lacks are forbidden (B). T9 never got it.

## Scope

1. Apply the A/B rule to the T9 prompt (`services/acp_content_writing/generate.py`): numbers, dates, heights, prices, durations only when present in the seed/facts; otherwise write without the number.
2. Make the repair round target the exact F1 sentences (pass the violation list) instead of a general rewrite.
3. Check why F9 returns `manual_check` on these pieces (read the audit output) and whether the CTA fact check has the data it needs.
   Out of scope: changing gate thresholds.

## Done when

* Re-run the same 5 pilot requests on Dev: ≥ 4/5 pieces pass F1 and F9 (not held), measured from `acp_shared.content_piece.status` + `held_reason`; cost per piece reported.
