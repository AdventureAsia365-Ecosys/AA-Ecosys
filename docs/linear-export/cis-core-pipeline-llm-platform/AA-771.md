# AA-771 — [T8/T9/T10] Tenant brand pack everywhere — compile the tenant rubric from T0 fields, feed it to T8 + T9, remove hard-coded "Adventure Asia / AA / premium" from T-series prompts

## Problem

S232 audit (49 pieces, 4-lens panel): brand voice is the second root cause of non-publishable T9 content.

* `services/acp_produce/brand.py::fetch_brand_rubric_text` reads only `tenant_brand_rules.system_prompt`, which T0 intake never fills → F9 and Jev judge every tenant against `AA_BRAND_IDENTITY_PROMPT` ("Discreet Executive Adventure", 40–60 y/o, $250k+, forbidden "fun/exciting").
* T8/T9 receive only `customer_segment` + `customer_mindset` (+ brand name since [AdventureAsia365-Ecosys/AA-CIS-App#669](https://linear.app/aa-ecosys/review/fix-t8t9-seed-atom-evidence-hook-segment-siblings-aa-768-round-3-981693166ed0)) — never `core_idea`, `voice_examples`, `forbidden_words`, `good_examples`, `style_guide`, `brand_type`.
* Hard-coded platform brand: `acp_angle_gate/prompts.py:28` "senior content strategist for Adventure Asia (AA)"; `goals.py` "quan điểm AA" (Vietnamese, sent verbatim to an English writer); `channel_style.py` "AA positioning", "premium không kiêu"; `acp_content_writing/prompts.py` "a premium travel brand".
* Result: 3/5 angle briefs broke the tenant's own "Avoid" rules; 25/29 LinkedIn posts had invented "At <Brand>, we…" lines; invented brand names were all expansions of "AA".

## Scope

1. Compile a per-tenant rubric from the structured T0 fields when `system_prompt` is empty (or at T0 save); block T9 for a tenant whose rubric would still be the AA fallback (admin-visible reason only).
2. Brand pack (core idea, brand type, voice examples, forbidden words, good examples, style guide, audience) into T8 angle generation and the T9 writer prompt.
3. Remove AA / premium / Vietnamese text from all T-series prompts, goals and channel specs; channel style per brand type later (separate item).
4. F9_brand_style and Jev `t10_brand_voice` use the tenant rubric.
   Out of scope: changing gate thresholds.

## Done when

* For each of the 4 test tenants, the rubric used by F9 (logged) is the tenant's own, not the AA fallback.
* grep shows no "Adventure Asia", "AA positioning", "quan điểm AA" or "premium" in T8/T9 prompt text.
* Re-run of the S232 measurement set: panel brand-voice score for LinkedIn ≥ 7 (was 5.2–5.6).
