## Problem

ADR 0020 (S271). The writers are mostly sound, but the control half after them loops. T9: 2% first-pass yield, a 750-line repair loop with special cases. S1: a saturated score drives routing, and repairs cannot see the source. T2: a source-blind brand judge drives retries and status.

## Scope

* Code composes the contract fields: meals, day count, meta, slug at a word boundary, CTA, FAQ count. The LLM writes the narrative only.
* One taxonomy-driven routing table maps each error class to repair_sentence, cut, regenerate_section, rewrite or hold. A lint checks it covers every gate id.
* Local, source-aware repair with a contract re-check replaces S1 flag_fix and meta re-repair. T2 becomes a small linear orchestrator. The S1 brand judge leaves the live path (D9).
* T2 elephant-riding tours keep the Master text verbatim, with 0 LLM calls and a review row (D8).
* A publish/export contract on outgoing payloads. A channel profile per slate channel (Facebook first). Human edits re-checked in REPORT mode.

## Done when

* A free full-chain replay over the stored corpus shows only declared diffs.
* A \~$1 smoke per workflow shows 0 contract violations in stored text.
* Exit integrity holds on 100% of paths.

### 2026-11-11 10:34 — nghiep pham quoc

S277: the path A recompose (fixed fields of served Masters by code, no model) is **rejected after two Dev pilots**. Nothing stays applied, and no further run is planned.

**v1 (CIS #1444)**
- Pilot of 3 tours: it cut the writer's trailing "Overnight: X." / "Distance: N km." clauses and added nothing, because these sources have no fact lines in that form. The pages lost facts.
- Restored the same day.

**v2 (CIS #1445)**
- A clause is cut only when the same day gets the same source fact line. New `facts_would_be_lost` state, and APPLY refuses unless facts_lost = 0.
- Full DRY RUN over 844 active Masters: 164 due (not 705), 678 no_op, 2 pending review. facts_lost=0. Verdicts unchanged (160 publish, 4 source_hold).
- Pilot of 3 tours, with an RDS snapshot first. The real diff showed the change is **worse for readers**:
  - "Meals: breakfast, dinner." became the source's verbatim code line "Meals: B, D".
  - On one day the prose kept "Meals: breakfast, dinner." and a new line "Meals: B" was added under it: two meal facts that contradict each other. The source's meal code says B while its own narrative mentions dinner, so the source itself is inconsistent there.
  - The seo_meta template replaced a natural sentence with a mis-capitalised template line.
- All 3 restored to the previous text and checked by diff. Both pilot waves are closed.

**Conclusion**
- The S277 audit's "compose diff 708" counted format differences between the writer's readable fact clauses and the train's verbatim source lines, not page defects.
- The served Masters stay as they are. The recompose script stays on main as a DRY RUN instrument only.
- Cost: about 0.08 USD of A3 re-atomize, no writer calls.

Lesson recorded: a DRY RUN for a text rewrite must show a real before/after sample and lines removed vs added. A changed-field count alone is not evidence.
