# AA-733 — [Docs][Skills] Restructure AA skills — slim SKILL.md + references, delete superseded content, 6 workflow skills, one source in repo skill/

## Why

The three AA skills have the failure the handbook describes in Sec 13 (one growing instruction file):

| Skill | Size | Signs |
| -- | -- | -- |
| `ai-nghiep` | 47 KB | 8 appended "ADDITIONS" blocks, 26 "lỗi thời/SAI" markers |
| `aa-cis-schema` | 41 KB | 38 stale markers; duplicates `docs/architecture/db-schema-reference.md` |
| `aa-ecosys-repos` | 26 KB | 19 stale markers |

Concrete wrong content found 06/10: atoms described as T5 per-tenant only (reversed by [AA-526](https://linear.app/aa-ecosys/issue/AA-526/archt5-di-doi-atomize-sang-a-series-trigger-tai-a3-go-bo-hoan-toan)); pipeline described as Step Functions + Validation Lambda; closed AAA accounts (ap-southeast-1) still listed; "never write code in Claude Chat" rule no longer matches how the tools work.

## Scope

1. Keep the 3 skill names, slim each `SKILL.md` to ≲150 lines; detail moves to `references/` loaded on demand.
2. **Delete** superseded content instead of annotating it "lỗi thời". History lives in git + Notion archive.
3. `aa-cis-schema` points at `docs/architecture/db-schema-reference.md` (repo source of truth) instead of copying tables; keeps gotchas + ECS exec + destructive-op procedure.
4. New workflow skills: `aa-session`, `aa-ship`, `aa-ui-verify`, `aa-linear-issue`, `aa-jira-update`, `aa-wave-rerun`.
5. One source: repo `skill/` (version-controlled since S210), synced to Kiro steering and uploaded to Claude.
6. Conventions the new skills encode: PRs use `Refs AA-xxx` (not auto-closing `[AA-xxx]`), Done only with live evidence; one canonical Notion page per topic, superseded pages get a banner.

## Process

Draft set produced in Claude Chat (06/10) → Nghiệp runs it through Claude Code/Kiro against local code (every `VERIFY:` marker resolved) → uploads back → Claude Chat reviews against REVIEW-CHECKLIST.md → upload to Claude + steering.

## Done when

* Every `VERIFY:` marker resolved or deleted; no "lỗi thời/SAI/cũ" annotations remain.
* Each `SKILL.md` ≤ \~150 lines, total ≤ \~55 KB (today 114 KB; Vietnamese diacritics cost bytes). Draft from Claude Chat: 54 KB.
* New skills trigger correctly in a dry-run session (start session, ship a PR, post a Jira update).
