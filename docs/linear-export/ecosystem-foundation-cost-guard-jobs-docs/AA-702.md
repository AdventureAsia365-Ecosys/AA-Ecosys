# AA-702 — [Admin UI audit] Fix broken notifications list + inconsistent counts/costs before the platform rerun

Playwright audit of every admin page + tab (S207, 01/10/2026, Dev :407). 0 console/JS errors and no 4xx/5xx except item 1. Fix these before the clean rerun so the rerun can be observed correctly.

## Fix before rerun

1. **Notifications list returns 500** — `GET /admin/notifications` does `dict(payload)` on a jsonb value asyncpg returns as a string (no codec on the pool). Count endpoint works, so the bell shows "3" but can't open. Hides DFS low-balance + budget alerts.
2. **S1 Rewrite lists inactive/superseded sources** — S1 shows 761 tours (736 active + 25 inactive, incl. the 20 superseded duplicates from S206); Upload "Ready for Rewrite" 642 is derived from the same set. Only active sources should be rewritable.
3. **Spend logs use two keys for the internal tenant** — External Spend shows `aa_internal` and `00000000-…0001` as separate tenants (LLM table has aa_internal twice; DFS table shows raw UUID), so "Tenants active" = 5 while there are 4.

## Fix in the same pass (display correctness)

4. Dashboard → Model Usage shows only `claude-haiku-4-5` at $0.0000 (External Spend: $42.49 / 30d). Pass rate shows 0% when there are no runs (should be "—").
5. Dashboard → SEO Intelligence: tours-per-country sum to 256 vs 119 published; "Top keywords" lists tour names, not keywords.
6. Tenant detail: LLM Cost $0.000 (External Spend: WanderLux $2.04); "Quota" 9.9% in detail vs 1.5% in the table — two different metrics under the same label.
7. Master Content "Total LLM Cost $0.0538" only sums legacy `pipeline_runs`, not `llm_call_log`.
8. S1 Rewrite model dropdown is hardcoded (Haiku / Sonnet 4.5 / GPT-4.1) instead of the model catalog used by Settings → LLM Models.
9. Route/Hub: Score shows raw floats (`1392.3333333333333`).
