## Problem

CloudWatch (09/10/2026, 30-day window, acc2 us-west-1) shows 7 CIS Lambdas with **0 invocations**:
`aa-cis-dev-validation`, `aa-cis-dev-ingestion`, `aa-cis-dev-export`, `aa-cis-dev-authorizer`, `aa-cis-dev-seo`, `aa-cis-dev-content`, `aa-cis-dev-brand-brief-parser`.
Some may be leftovers from the old architecture (Step Functions path bypassed, AA-22; ACPv1 cluster, [AA-477](https://linear.app/aa-ecosys/issue/AA-477/investigate-cum-14-bang-acpv1-goc-acp-runs-6-router-2-lambda-0-row0)). Others may be designed-but-not-yet-used, or on a rare trigger (the `authorizer` is still referenced by API Gateway per AA-432; `ingestion` was the S0 upload path). Zero calls alone is **not** proof a function is dead.

Found during [AA-735](https://linear.app/aa-ecosys/issue/AA-735/jobs-job-model-modularization-follow-ups-adr-0003-nac-3-6) nac 4 review: 4 of the 5 Lambdas nac 4 listed no longer exist; only `aa-cis-dev-dfs-balance-check` remains (active, 21 runs/30 days). Nac 4 was dropped.

## Scope

For each of the 7 functions, record evidence before deciding:

1. Triggers and references: event source mappings, S3 notifications, EventBridge rules, API Gateway integrations and authorizers, Step Functions definitions, Lambda permissions (resource policy). Search `AA-CIS-Infra` Terraform and `AA-CIS-App` code and workflows for the function name and ARN.
2. Last real invocation (CloudWatch metrics over 90+ days, plus the log group's last event), and the last deploy of its code.
3. Design intent: ADR / CONTEXT.md / Linear history. Is it a planned feature not yet switched on, or superseded? Name the replacement if superseded.
4. Verdict per function: **keep** (needed / planned, with reason) | **retire** (obsolete, with replacement) | **ask Nghiệp**.

Retire only after Nghiệp approves the verdict table. Remove via Terraform (not console): plan shows only those resources; remove dependents (IAM, log groups, permissions, triggers) in the same plan. Snapshot the code zip and config to `s3://aa-cis-bronze-005097885195/scripts/restore/` first.

## Out of scope

TripPlanner Lambdas (`aa-tripplanner-dev-*`, active). `dfs-balance-check` (active).
