## Problem

The S275 study of an Odoo tour & travel app (AA-1065, report root `docs/research/2026-11-10-odoo-tour-travel-plugin-comparison.md`) found these gaps. The tech lead approved building all of them (S275, 10/11/2026). We build the features in our own code; the app's code is OPL-1 and is never copied.

## Scope

* **Agency service catalogue (own ancillaries with cost, sell and quantity basis)** (crm-23, missing, value medium, effort M).
  * Today: crm.agency_supplier (category, default_commission_pct) only; each crm.option / booking_line is typed by hand (sell_amount, net_amount, title). No reusable products, no quantity basis.
  * Build: crm.agency_service(service_id, tenant_id, agency_supplier_id, category (ancillaries per b6), name, unit_net, unit_sell, currency, qty_basis per_person|per_adult|per_booking|per_room|per_night|per_person_night, valid_from/to, active) + optional crm.agency_service_tier(min_pax, max_pax, unit_net). Builder 'add from catalogue' computes qty from the party/rooms/nights and fills option net/sell (snapshot, not live link).
* **Supplier booking requests grouped per supplier** (crm-24, partly, value medium, effort M).
  * Today: crm.booking_line (supplier_kind agency) planning -> confirmed -> cancelled with confirmation_no checks (crm.booking_line_confirm); cancel run opens one cancel_with_suppliers checklist task. No 'requested' state and no request document.
  * Build: Add status 'requested' (requested_at, request_ref) on agency lines; action 'Request from suppliers' builds one e-mail draft per supplier from the trip's lines (dates, pax, rooms, names only when needed) sent from the agency mailbox and threaded on the trip; supplier reply with a confirmation no moves the line to confirmed.
  * Depends on: crm-23 (optional)
