**S279 review (13/11/2026): scope update.**

**Scope:** campaigns (R14) in the merged agency app.

* Sent only from the agency's own mailbox (BYO).
* Content that sells passes the d21 gate.
* A tour flagged retired by the CRM fan-out (`crm.tour_retired_flag`, [AA-1093](https://linear.app/aa-ecosys/issue/AA-1093/cross-app-lifecycle-events-across-apps-tour-discontinued-in-crm-tenant) part 1) is pulled from scheduled campaigns. This replaces the d20 event in the old text.

**Rules:**

* Contacts without consent are excluded.
* An unsubscribed contact who is re-imported stays suppressed.

**Edge case:** a list over the mailbox's daily send limit is spread over several days. That limit is a platform setting with an agency range ([AA-1096](https://linear.app/aa-ecosys/issue/AA-1096/platform-every-threshold-limit-and-cap-editable-on-an-admin-page)), not a constant.

**Done when:** Global Done, plus tests for consent, suppression, the retired-tour pull and the daily spread. An independent review runs before the feature is enabled for any pilot tenant.
