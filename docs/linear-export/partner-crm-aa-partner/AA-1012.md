## Problem

AA-955 (CRM-25 contracts and waivers) closed Done-with-scope in S261: e-sign v1 is a KMS-sealed text envelope (RSASSA-PSS), verified live. Agencies and travellers cannot yet download a PDF whose signature a standard PDF reader validates.

## Scope

1. Render the signed envelope (terms, waiver, insurance declination, signer, times) to PDF with an embedded EN/VI font.
2. PAdES-B-B signature with pyHanko using an external signer that calls `kms:Sign` on the existing seal key; an X.509 certificate for that key (self-issued company CA on Dev; decision for prod).
3. Download from the agreements panel and the client portal.

## Done when

- [ ] A signed envelope on Dev downloads as a PDF that pyHanko validates (signature intact, PAdES-B-B profile).
- [ ] Vietnamese text renders correctly (screenshot).
- [ ] The private key never leaves KMS (code + IAM review).
