**S279 review (13/11/2026): scope update (ADR 0019 b6).** The 'needs an LLM path' blocker is gone: acc1 Bedrock and the Anthropic API both serve the gateway since S278.

**Scope:**

1. **R10:** AI reads supplier confirmations only for non-AA ancillary suppliers (flights, insurance, visa, transfers, fees), attached to the existing supplier booking requests (crm-053). AA tour lines take their status from Booking over `booking.b2b.v1`, never from AI.
2. **R40:** notes → options picks only from the tenant's live AA tour_ids and atoms. An option code outside the day's closed list is rejected.
3. **R41:** voice profiles.

**Rules for every stage:**

* It goes through the AI gateway with `pii_class us`, after the F3 scrub.
* It counts against the tenant AI budget (`hard_stop` default true, [AA-1096](https://linear.app/aa-ecosys/issue/AA-1096/platform-every-threshold-limit-and-cap-editable-on-an-admin-page)).
* It shows the kit AI notice and follows the current route control.
* Passport images are never sent.

**Done when:**

* A trial of 3, then ≤ 50 runs on a synthetic agency, with cost per run from `shared.llm_call_log`.
* Tests for the closed-list rejection and the no-passport rule.
* An independent agent review before merge, and a live check on Dev.
