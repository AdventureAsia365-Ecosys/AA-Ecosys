## Today

There is no shared visual language across the three front ends:

* CIS keeps its tokens in `frontend/app/_brand/tokens.ts` ([adventure.asia](<http://adventure.asia>): Fahkwang/Poppins, gold `#DB9628`, pill buttons), with inline styles in the admin.
* TripPlanner uses its own Tailwind config.
* AA-Booking exists only as Figma screens (`docs/AAA/figma_AAA`).

## Target

* **One token source.** A JSON file (Style Dictionary) generates:
  * TypeScript tokens;
  * a Tailwind preset;
  * CSS variables.
* **Component kit:**
  * Button, Badge, Card;
  * DataTable (TanStack), Drawer, Modal, Tabs;
  * PageHeader + breadcrumbs, EmptyState, Skeleton;
  * Toast, FormField.
* **Distribution.** Start as a folder in a new small repo, or publish as a private package, consumed by all front ends. **\[DECISION\]** at build time.
* Light/dark theme and accessibility baseline (contrast, focus states).

## Done when

The tokens package is consumed by the CIS admin (first page migrated) and by TripPlanner (Tailwind preset), and the AA-Booking UI spec references it.
