# AA-668 — [Portal] Writer panel — segment/topic opens a right-side panel: Goal → Angle → auto-write with live streaming (social + tour rewrite); CTA from brand defaults

## Today (Ms. Thư's feedback)

* Picking a Subject expands `AngleGateWizard` **inline** under the Slate, so the tenant has to scroll down to find the goal/angle picker and the writing output.
* T9 can stop with a 422 asking for a CTA after the angle is chosen, which is an extra step.
* Tour rewrite shows `LiveWriter` inside the catalog detail; the experience differs between tour and social.

## Target

* One **Writer panel** (right-side drawer on desktop, full-screen sheet on mobile), used by both **Social Content** and **Tour rewrite**:
  1. context header (segment/topic, channel, market);
  2. Goal (the 8 fixed goals, as cards);
  3. Angle (3 generated options, as cards);
  4. **writing starts automatically after the Angle is picked**;
  5. live streaming text (ADR 0004) with a step indicator (write → check → done);
  6. result actions: copy/export, publish, save to My Content, regenerate angle.
* **CTA**: comes from the tenant's Brand defaults (new field in Brand settings). The 422 path becomes a fallback only when the brand has no CTA, with an inline field, not a blocking step.
* The status comes from the job (queued / writing / checking / done / failed + Retry). No row inference.
* Closing the panel keeps the job running; a toast notifies on completion.

## Done when

A Playwright flow on Dev: pick segment → goal → angle → streamed text → piece saved, with no scroll needed at 1440 × 900. Same panel for tour rewrite.
