## Problem

Content staff edit tours in a drawer that saves straight into the live record on blur: no draft, no reason, no author, no diff, no preview. An Excel re-import overwrites hand edits, and a wave rerun can overwrite them too. Agency T2 copies are only flagged "source changed" when facts change.

## Scope

* Quick fixes (option A of the content-editing advisory): promote goes through the re-check gate, drawer fields follow permissions, audit on base-tour edits, Review Queue can edit the itinerary.
* Tour versions with draft, diff against the live version, publish; a published tour is locked against wave reruns.
* T1: Excel re-import shows a per-field diff; untouched fields auto-accept, hand-edited fields ask; result is a draft.
* T2: self-publish on Dev; a "needs second person" switch in admin for prod (content_lead publishes).
* T3: a fact change (FactSheet diff) re-runs T2 only for agencies using the tour, within a monthly cost cap editable in admin; agency-untouched copies are replaced after checks, agency-edited copies become a pending version with a banner and compare view; at the cap only mark stale and notify. Wording-only edits never re-run T2. Calls logged to shared.llm_call_log.

## Approved S285 (access page D1–D11, all yes)

* D1: new permission content.publish and a separate switch cis.content.publish_two_person (admin only; changing it also needs a second person); Dev off, prod on. Content loses review.act self-publish.
* D3: content may re-run AI for one tour (cost shown first, within the cap); batch runs (S1 batch, wave, SEO prefetch) content_lead + admin only.
* D5: content and content_lead lose price edit on the base tour now; customer_success keeps entering until the tour has a Booking price, then read-only; remaining price/provider edits keep the old value in audit.
* D10: the AA Facts "price" type comes from Booking ("from" price); season type admin + content_lead; tenant_qa the rest.
* D11: E2E account A10f (content_lead, Dev only, test tours only) proves the two-person flow.
* A2: T2 rerun cap 10 USD/month on Dev, alert at 80 %, editable in admin.

## Done-when

* Editing a tour's wording creates a new version with a diff; publishing shows it on TripPlanner.
* A wave rerun skips the locked tour; an Excel re-import shows per-field differences and the hand edit wins.
* A fact change re-runs T2 for one agency on Dev within the cap, logged in llm_call_log.
* CI green, deployed, live check recorded here.
