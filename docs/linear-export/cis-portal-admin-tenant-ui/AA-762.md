# AA-762 — [Portal] Team & roles — tenant users (owner/editor/viewer), invites, self-serve API keys — after the ecosystem identity ADR

Split from [AA-672](https://linear.app/aa-ecosys/issue/AA-672/portal-account-pages-billing-activity-log-team-and-settings) (S229). **Blocked by the ecosystem identity ADR** (CIS + AA-Booking).

Today a tenant is one API key, no users (`shared.tenants.api_key_hash`; `/auth/tenant-login` exchanges the key for a 24 h JWT; no session revocation — an offboarded tenant's JWT works until expiry).

## Scope

* Tenant users keyed by verified email, roles owner/editor/viewer, invites, remove member.
* Self-serve API keys (create/rotate/revoke, last used).
* Session revocation (token version or short-lived JWT + refresh).
* Built together with [AA-703](https://linear.app/aa-ecosys/issue/AA-703/auth-passwordless-login-for-admin-tenant-googlefacebook-sign-in-and-8) (passwordless login for admin + tenant) and aligned with [AA-680](https://linear.app/aa-ecosys/issue/AA-680/aaa-identity-customer-otp-auth-shared-with-tripplanner-staff-rbac) (AAA identity) — one identity model.
