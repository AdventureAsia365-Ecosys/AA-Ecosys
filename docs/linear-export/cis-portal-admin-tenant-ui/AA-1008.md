## Problem

AA-994 closed Done-with-scope in S261. Its remaining Done-when items are not met: there is no shared app shell, no automated visual check on every page, and the conformance guards are not yet required checks with empty suppression files.

## Scope

1. **S6e:** a shared `ShellFrame` in kit core (CIS canonical copy, synced to the other apps).
2. **S1d/S2c:** a visual job in GitHub Actions (not the agent's IP) for CIS admin, the portal and CRM web: every changed page at 1440 and 390, light and dark, with a page-level horizontal overflow assertion (`scrollWidth == viewport`) and 0 console errors; screenshots as artifacts; runs on PR previews and after the production deploy.
3. **S6f close-out:** suppression files empty in all four staff/partner repos; Tabs roles tracked.
4. **H3:** the kit and visual checks become required checks in branch protection. This step needs the tech lead to sign in to GitHub.

This issue holds a CI/workflow PR, which counts as risky: independent review before merge.
