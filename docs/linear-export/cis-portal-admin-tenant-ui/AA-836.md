## Problem

The S237 read-only UI verify of the tenant portal found layout and data-display defects on tenant-facing pages (tenant atlas-hearth; 1440 and 390 px; light and dark). No open issue tracks them. On a phone, the Ready to Publish list is barely usable.

* **D2 (Medium) — T11 Publish at 390.** The Ready-to-Publish card content column shrinks to about 90 px beside the "Connect WordPress to publish" button. Titles wrap one word per line, the preview is cut to "A weaver…", and the button does not stack under the content.
* **D3 (Low) — T11 Publish.** The StickyBar's white background extends about 27 px above its card and covers the bottom border of the card above. Seen at both 1440 and 390.
* **D4 (Low) — My Catalog drawer.** "See original content" calls `fetchPoolTour` (`catalogApi.ts:46`, used by `CatalogDrawer.tsx:171`), which sends GET `/api/tenant/v1/tours/pool/{id}`. `api/routers/v1_tours.py` has only GET `/pool` and POST `/pool/{id}/rewrite`. Every drawer open returns 404 and logs a console error.
* **D6 (Info) — T11 and T10.** Ready-to-Publish previews start with raw markdown (`## Title …`). The T10 My Content drawer shows the body as raw markdown.
* **Other issues at 390:**
  * The My Content filter row overflows.
  * Dashboard Recent Activity titles wrap 1–2 words per line.
  * The ROUTE pill renders as an oval.

## Scope

* **T11 card:** at narrow widths, stack the action button below the content and let the title and preview use the full card width.
* **StickyBar:** fix its offset and background so it no longer overlaps the card above, at both widths.
* **My Catalog drawer:** pick one fix and note the choice in the PR:
  * add a tenant-scoped GET `/v1/tours/pool/{published_tour_id}` that returns the Master source content, or
  * point "See original content" at an existing endpoint.
    Either way: no 404 and no console error.
* **Markdown:** render it, or strip it to plain text, in the T11 previews and the T10 drawer body. The tenant must never see `##` or `**`.
* **390 px fixes:**
  * The My Content filter row wraps or scrolls inside its own container.
  * Recent Activity titles get a sensible minimum width or truncate with an ellipsis.
  * The ROUTE pill keeps the kit pill shape.
* **Constraints:** use UI kit components only, and follow the tenant-sees-content-only rule (no gate, flag or held wording).
