# AA-663 — [Admin] Information architecture consolidation — one Dashboard, remove duplicates and legacy routes, Brand Identity + system config into Settings, drop the "ADMIN" tag

## Findings (S199)

* Two "Dashboard" nav items: "ACP v2 — Setup & Approval" and "AA Internal Content".
* The legacy route group `(internal)/{catalog,upload,brand,review}` duplicates `/admin/*`.
* Brand Identity is a top-level page.
* Platform Stats and Tenant Activity overlap: both report pieces and gates per tenant.
* The "ADMIN" tag on nav items is noise.

## Target navigation (review §5.5)

* **Overview:** a single system dashboard (see the Overview issue).
* **Content:** Upload · Rewrite (S1) · Review Queue · Master Content.
* **Intelligence:** Atoms · Segments · Scores · Routes & Hubs (the current Social Content sections as tabs).
* **Tenants:** Tenant list → Tenant 360. Tenant activity and quality move inside the tenant area.
* **Operations:** Cost Operations · Jobs.
* **Settings:**
  * Models per stage;
  * AA brand identity;
  * Integrations (DFS, WordPress defaults, Jev, key status);
  * Budgets & limits;
  * Markets;
  * Users & roles.

## Scope

* New sidebar grouping.
* Redirects from old URLs (no dead links).
* Delete the `(internal)` duplicates after the redirects are in place.
* Remove the "ADMIN" tag. Visibility follows real permissions (see the staff auth issue).
* Update `middleware.ts` PROTECTED_ROUTES accordingly.

## Done when

Every old URL redirects. `next build` is clean. The Playwright smoke test visits every nav item at 1440 px and 400 px with no JS errors.
