# AA-759 — [Portal] PortalShell on the kit — grouped nav, real ⌘K, mobile bottom bar, theme, route renames (no T-number slugs)

Split from [AA-670](https://linear.app/aa-ecosys/issue/AA-670/portal-information-architecture-page-by-page-ui-audit-fix-inconsistent) (S229). Same approach that worked for the admin ([AA-752](https://linear.app/aa-ecosys/issue/AA-752/admin-ui-v2-admin-shell-redesign-collapsible-sidebar-logo-overview) shell, [AA-663](https://linear.app/aa-ecosys/issue/AA-663/admin-information-architecture-consolidation-one-dashboard-remove) IA).

## Today (verified in code, S229)

* No shell component: `portal/layout.tsx` (234 lines) holds state + raw fetches, hand-rolled toast, portal-local PageHeader/Skeleton/CommandPalette/Badge/EmptyState duplicates (`_components/ui.tsx`).
* Only 2/15 pages use `app/_kit` + react-query (My Catalog, My Content). Inline styles, no CSS variables, pinned light theme, no responsive breakpoints beyond the 900px drawer.
* Route slugs are internal T-numbers (`t0-brand`, `t1-rewrite` = "Browse Tours", `t4-pool` = "My Catalog", `t7-planning`, `t8-angle-gate` reachable by deep link only, `t10-review`, `t11-publish`).
* ⌘K only jumps to Browse with a search string; search box hidden on phones; date format "09 Oct" vs admin "9 Oct".

## Target

* `PortalShell` on the kit: sidebar grouped by workflow — **Tours** (Browse / My Tours) → **Brand** → **Create** (Social / Articles) → **Content** (My Content, publish as an action) → **Account** (Billing, Activity, Team & Settings, API, Integrations).
* Real ⌘K over tours, my content and pages; phone bottom bar; collapse rail; light/dark via kit tokens; AA brand ([AA-605](https://linear.app/aa-ecosys/issue/AA-605/uiux-djong-bo-phong-cach-admin-portal-voi-trang-chinh-adventureasia) style).
* Routes: `/portal/tours`, `/portal/tours/mine`, `/portal/brand`, `/portal/create/social`, `/portal/create/article`, `/portal/content`, `/portal/account/*`; 308 redirects from every old slug; delete `page.tsx.bak.old`.
* Shell state via react-query (no raw fetch on mount); one date formatter shared with admin; toast `role=status`; nav as a `nav` landmark.
* ESLint kit rule ([AA-732](https://linear.app/aa-ecosys/issue/AA-732/ciui-playwright-smoke-on-vercel-preview-for-key-adminportal-pages)) extended to `app/(tenant)/portal`.

## Done when

Every portal page renders inside PortalShell on Dev at 1440 and 400 px, light and dark; old URLs redirect; Playwright smoke covers every portal page with no JS errors (needs `E2E_TENANT_API_KEY`, [AA-741](https://linear.app/aa-ecosys/issue/AA-741/t-series-audit-end-to-end-t0t11-test-run-on-controlled-tenants-per) phase 0).
