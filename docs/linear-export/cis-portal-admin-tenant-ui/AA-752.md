# AA-752 — [Admin UI v2] Admin shell redesign — collapsible sidebar, logo → Overview, topbar with real ⌘K search, mobile bottom nav

## Problem

The admin shell is a fixed 248px sidebar rendered by every page, with the account card + theme switch at its foot and no topbar. It can't be collapsed or resized, the logo goes nowhere, there is no way to jump to a tour/tenant/job without opening the right page first, and on a phone the only navigation is the hamburger drawer ([AdventureAsia365-Ecosys/AA-CIS-App#605](https://linear.app/aa-ecosys/review/fix-admin-smoke-covers-all-16-pages-responsive-admin-jev-acted-nan-19e7f0e5072f)). Nghiệp (S221) asked for a professional, commercial-grade admin that keeps the [adventure.asia](<http://adventure.asia>) identity.

Design (approved direction, mockups): [https://claude.ai/artifact/Hsr5SaBRNS7AxgRdoDhBAx](<https://claude.ai/artifact/Hsr5SaBRNS7AxgRdoDhBAx>) — A expanded + topbar (light), B collapsed rail (dark), C phone.

## Scope

**PR A — shell**

* Sidebar: collapse/expand (button + `[` shortcut), state persisted per browser; collapsed = 68px icon rail with tooltips and count badges (Review Queue pending); optional drag-to-resize 200–320px.
* Logo (gold mountain mark + "Adventure Asia / CIS Admin") links to `/admin/overview`.
* Topbar on every admin page: breadcrumb, **global search (⌘K)**, theme switch, notifications, account menu (moved from the sidebar footer). **No environment label.**
* Global search is real: new `GET /admin/search?q=` (admin-secret) → top matches for tours (raw `src_name` + rewritten `aa_name`, country, status → opens the tour), tenants (name/slug), jobs (id prefix / kind); admin pages matched client-side. Debounced, keyboard-navigable (↑↓ Enter Esc), bounded result counts.
* Phone (< 768px): compact topbar (☰, page title, search), **bottom nav** with Overview · Review (badge) · Master · Jobs · More (opens the drawer); tables already scroll in their box.
* Shell parts live in the UI kit (`frontend/app/_kit`): AppShell, Sidebar, Topbar, CommandPalette, BottomNav — with a demo in Settings › UI Kit.

**PR B — page consistency**

* Kit `PageHeader` (Fahkwang title, subtitle, actions on the right) on all 15 admin pages; buttons follow the brand (gold pill uppercase primary, gold-outline secondary) — matching [adventure.asia](<http://adventure.asia>) ENQUIRE / EXPLORE.

## Done when

* Collapsed/expanded state survives reload; logo → Overview; no environment label anywhere.
* ⌘K finds a real tour by part of its name and opens it; finds a tenant and a job; p95 search < 300 ms on Dev.
* 390px: bottom nav visible, no page-level horizontal scroll (UI smoke), light + dark.
* UI smoke green on all admin pages; screenshots reviewed.
