# AA-721 — [Admin UI v2] Jobs page rebuild — kit + react-query, worker-ECS-aware (per-kind, concurrency, workers)

The Jobs page (`/admin/jobs`, [AA-650](https://linear.app/aa-ecosys/issue/AA-650/p1-durable-job-runner-postgres-queue-worker-ecs-service-replaces-in)/687) still uses the legacy admin primitives (`adminUi.tsx`) with hand-rolled `useState`/`useEffect`/`setInterval` fetch and a scoped `eslint-disable react-hooks/set-state-in-effect`. Its worker-health panel was built when the job worker ran **in-process inside the API**; [AA-651](https://linear.app/aa-ecosys/issue/AA-651/p1infra-worker-ecs-service-for-the-job-runner-aa-cis-infra) since moved it to a **dedicated worker ECS service** (`aa-cis-dev-worker`, Spot, autoscaling min1/max3, task-revision gating from [AA-711](https://linear.app/aa-ecosys/issue/AA-711/bugjobs-draining-ecs-task-keeps-claiming-jobs-after-a-deploy-runs-them), `JOB_WORKER_IN_API=false` on the API). The page should be rebuilt to match the new architecture and the UI-v2 standard.

## Scope

* Migrate to the UI kit (`DataTable`, `StatusBadge`, `Drawer`, `PageHeader`) + react-query (`useQuery`/`useMutation`, `refetchInterval`); drop the `setInterval` + `eslint-disable set-state-in-effect`.
* Show the registered job kinds correctly with their per-kind **concurrency / max_attempts / expected_seconds** (from `/admin/job-runner/summary` `kinds`), plus counts per status over the window.
* Worker panel reflecting the **separate ECS worker service**: live workers (by task-revision), queue depth, running-per-worker, reaper totals; make clear the API no longer runs jobs in-process.
* Keep existing features: cancel/retry, job detail drawer (lifecycle, cost split, LLM calls, domain links), progress/ETA, deep links (`?job=`, `?kind=`, `?status=`, `?tour_id=`).
* No backend change expected (reuse `/admin/job-runner/*`); add an endpoint only if a needed signal is missing.

## Context

Follows the UI-v2 rebuild line ([AA-662](https://linear.app/aa-ecosys/issue/AA-662/ui-kit-shared-adminportal-components-datatable-filter-sort-columns) kit, [AA-718](https://linear.app/aa-ecosys/issue/AA-718/admin-ui-master-content-page-fix-5-dataux-bugs-redesign-for-a)/664 migrated pages). Builds on [AA-650](https://linear.app/aa-ecosys/issue/AA-650/p1-durable-job-runner-postgres-queue-worker-ecs-service-replaces-in) (durable queue), [AA-651](https://linear.app/aa-ecosys/issue/AA-651/p1infra-worker-ecs-service-for-the-job-runner-aa-cis-infra) (worker ECS service), [AA-687](https://linear.app/aa-ecosys/issue/AA-687/admin-jobs-observability-job-detail-with-llm-calls-and-cost-split) (jobs observability), [AA-711](https://linear.app/aa-ecosys/issue/AA-711/bugjobs-draining-ecs-task-keeps-claiming-jobs-after-a-deploy-runs-them) (task-revision gating).
