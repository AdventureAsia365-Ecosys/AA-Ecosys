## Problem

Checking app health, deployed versions and api/worker parity is a manual session-start step; staff actions have no tamper-resistant audit; spend cannot be split per app in the console. Overview ([AA-858](https://linear.app/aa-ecosys/issue/AA-858/admin-ops-overview-extend-adminoverview-with-tripplanner-traffic), Q9) needs this data.
