## Idea

Ms. Thư (14/10/2026): "Chị đang suy nghĩ build 1 cái CRM, quản lý khách hàng cho tenant." Nghiệp: note now, research and design later. No build until a design is approved.

## Research questions

1. What tenants actually need: lead capture from published content (T9/T11 links, forms), contact list, pipeline/stages, notes/tasks, email follow-up, segmentation, reporting — validate with 2–3 tenants.
2. Build vs integrate: a light CRM inside the CIS portal vs connectors to HubSpot / Zoho / Pipedrive (export, webhooks) — cost, effort, data ownership.
3. Overlap with AA-Booking: Booking already models customers, leads (unverified → verified on OTP), trip cases and proposals for AA's own B2C flow. Can a tenant CRM reuse that model (multi-tenant) or must it stay separate? ADR implications (ADR 0001/0004).
4. Identity and access: tenant users and roles from ADR 0006 / [AA-813](https://linear.app/aa-ecosys/issue/AA-813/portal-tenant-user-accounts-invite-users-roles-ownereditorviewer-api); tenant isolation ([AA-817](https://linear.app/aa-ecosys/issue/AA-817/security-cis-api-runtime-role-aa-cis-admin-is-not-filtered-by-rls) RLS finding must be fixed first).
5. Privacy/compliance: personal data per tenant, consent, deletion/export (GDPR for EU tenants), retention.
6. Pricing/plan: which membership plans include it.
