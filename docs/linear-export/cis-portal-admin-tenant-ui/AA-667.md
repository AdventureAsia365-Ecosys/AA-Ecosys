# AA-667 — [Admin] S1 Rewrite page — live streaming while writing (reuse LiveWriter / ADR 0004) + job-based progress

Ms. Thư asked for the admin Rewrite page to stream while writing, like the tenant portal.

**Scope:**

* Bind the stream sink for `s1_generate` inside the S1 job.
* Expose `GET /admin/progress/s1/{job_id}` (the same Redis snapshot format as `/v1/progress`).
* Render `LiveWriter` in a right-side panel, with step progress: generate → validate → judge → brand audit → flag fix → revalidate.
* Batch runs (a rerun wave) show a per-tour progress table instead, with click-through to the live panel.

Depends on the job runner issues.

Shipped: backend binds the sink in `_run_tour_job` (S1 runs in-process via shared.pipeline_jobs, so a short-lived Redis client is opened from REDIS_HOST; best-effort, never blocks the rewrite). Frontend `AdminLiveWriter` (kit tokens) polls `/api/admin/progress/s1/{jobId}` ~0.8s with a typewriter view, opened from a 'Live view' button on each running tour row in the S1 Rewrite page. Reuses the existing astream + on_stage plumbing and TOUR_STEPS/TOUR_STAGE_STEPS presets — no schema change.
