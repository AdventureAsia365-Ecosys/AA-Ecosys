This is the base for every UI v2 page. It follows the brand tokens (`frontend/app/_brand/tokens.ts`) and the ecosystem design-system issue.

* **DataTable** on TanStack Table:
  * server- or client-side filtering per column;
  * multi-sort;
  * column show/hide;
  * pagination;
  * sticky header;
  * row selection + bulk actions;
  * saved views (localStorage, per user);
  * CSV export.
* **Drawer** (right-side detail/edit), **Modal** (confirm / destructive), **Tabs**, **PageHeader** (title, breadcrumbs, actions), **Toast**.
* **EmptyState**, **Skeleton**, **ErrorState** with retry.
* **StatusBadge** driven by job status (see the job runner issue).

Replaces the ad-hoc `adminUi.tsx`, `FilterBar.tsx`, `Pagination.tsx` and the portal `ui.tsx` primitives. Migrate page by page.
