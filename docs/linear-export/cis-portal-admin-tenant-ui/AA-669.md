**Target:** a DataTable from the shared UI kit.

* **Columns:** title, channel, place/topic, goal, angle, status (ready / published / not ready), words, created, published at, actions (view in drawer, export HTML/fragment, publish, duplicate/regenerate).

* **Sort:** any column.
* **Views:** saved views ("Ready to publish", "Published this month").
* **Bulk actions:** export selected, publish selected (blog + WordPress connected).
* **Constraints kept:** tenant-safe projection (no gate data), copy-lock rules ([AA-614](https://linear.app/aa-ecosys/issue/AA-614/social-tenantsub2-fe-tenant-my-content-phang-an-gateheld-khoa-copy-man)).
