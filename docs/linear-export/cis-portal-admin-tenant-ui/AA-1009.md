## Problem

The official UAT round 1 (AA-855) waits on three gates. The tech lead decided in S260 that dry runs start from S261: scenarios for stable areas run every session as regression checks, with internal videos only. Today the pilot scripts (PORTAL-PUB-01, TP-PUB-01) live outside the repo, and there is no harness, no per-identity sign-in setup and no fast mode.

## Scope

1. Move the pilot scripts into a repo tool folder with a pinned Playwright version (per the aa-uat-video skill).
2. Two modes: **fast** (asserts only, no video or TTS) for regression, and **record** (video + subtitles + free local TTS) for internal dry-run videos.
3. Sign-in setup per identity: public, E2E tenant, E2E CIS admin (read-only today), Booking E2E (read-only), CRM agency E2E. Cognito sessions only, never password sessions.
4. About 20 public or read-only scenarios across TripPlanner public pages, the portal, Booking Figma-complete screens and shipped CRM flows.
5. One command runs everything and prints a pass/fail table. Run with the VPN off (Vercel challenge).

Out of scope: write scenarios (they need the Dev-only UAT write permission follow-up), official round-1 videos.

## Done when

- [ ] The harness is merged and fast mode runs at least 20 scenarios, with the pass/fail table committed under `docs/audits/<date>-S<nnn>-uat-dry-run/`.
- [ ] The sign-in setup works for each listed identity, or a written reason says why one waits.
- [ ] Record mode produces one dry-run video from the harness. Total cost $0.
