# AA-722 — [Admin UI v2] Retire / de-dupe the old Dashboard page after Overview + SEO Intelligence

After [AA-664](https://linear.app/aa-ecosys/issue/AA-664/admin-overview-dashboard-whole-system-view-pipeline-a0a3-intelligence) (Overview dashboard) and [AA-705](https://linear.app/aa-ecosys/issue/AA-705/admin-ui-v2-seo-intelligence-page-demand-by-market-keyword-table-paa) (SEO Intelligence as its own page), the legacy `/admin/dashboard` page (`frontend/app/admin/dashboard/page.tsx`) overlaps and now has a dead tab.

## Problem

The old Dashboard has 3 tabs:

* **Overview** — pipeline-runs / model-usage / pass-rate metrics (`GET /api/admin/metrics?days=7`). Overlaps conceptually with the new whole-system Overview ([AA-664](https://linear.app/aa-ecosys/issue/AA-664/admin-overview-dashboard-whole-system-view-pipeline-a0a3-intelligence)) but from a different angle.
* **SEO Intelligence** — 3 KPIs + country table + short keyword list. **Superseded by the full** `/admin/seo-intelligence` **page (**[AA-705](https://linear.app/aa-ecosys/issue/AA-705/admin-ui-v2-seo-intelligence-page-demand-by-market-keyword-table-paa)**)** → this tab is now redundant.
* **Content Library** — published totals / by-country / score distribution. Overlaps partly with Master Content ([AA-718](https://linear.app/aa-ecosys/issue/AA-718/admin-ui-master-content-page-fix-5-dataux-bugs-redesign-for-a)).

Both nav entries ("Overview" and "Dashboard") sit in the sidebar's Overview group, which is confusing.

## Scope (decide the IA, then clean up)

1. Remove the **SEO Intelligence tab** from the old Dashboard (it is fully replaced by [AA-705](https://linear.app/aa-ecosys/issue/AA-705/admin-ui-v2-seo-intelligence-page-demand-by-market-keyword-table-paa)'s page); redirect or drop any link to it.
2. Decide the fate of the old Dashboard's Overview + Content Library tabs: either fold the still-useful widgets (daily volume chart, model usage, score distribution) into the new Overview / Master Content pages, or keep Dashboard as an "analytics" page clearly distinct from the whole-system Overview — Nghiệp to decide.
3. Collapse the sidebar so there is one clear entry (no two near-duplicate "Overview"/"Dashboard" items), matching the [AA-663](https://linear.app/aa-ecosys/issue/AA-663/admin-information-architecture-consolidation-one-dashboard-remove) IA.
4. Keep the legacy page on the kit if it stays; retire it cleanly (next.config redirect) if it goes.
