## Problem

Staff accounts in `shared.admin_users` can only be created with `scripts/create_staff_user.py`; there is no UI to create, disable or change roles. ADR 0004 O1 makes the same CIS login serve Booking staff, so this becomes the single staff directory (S236 inventory).

## Scope

1. Admin-only page `/admin/staff`: list, create, disable, change role, force password reset; audit rows.
2. Roles: existing admin/reviewer/content + Booking app roles (sales, contracting, booking_admin) carried in the JWT for `aud=booking`.
3. Backend endpoints under `/admin/staff` with admin-only write rule in `lib/rbac.ts`.
   Out of scope: SSO.

## Done when

* On Dev an admin creates a `sales` staff user in the UI; that user logs in to CIS and receives a Booking JWT with role `sales` (decoded token evidence); a disabled user cannot log in.
