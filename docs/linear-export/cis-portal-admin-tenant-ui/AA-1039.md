## Problem

ADR 0019 d13, d20, d21 (S265). The CIS admin mixes the AA atom/segment/route/hub store with tenant-written content, and spreads tenant management and AI pages across groups. Writing memory should become a lab that improves each pipeline stage. Plan: `docs/audits/2026-11-03-S265-ecosystem-restructure/` README §6, clarifications TL-13, TL-20, TL-21.

## Scope

* **Navigation groups:** Home / Tenants / AA Catalogue / Tenant content QA / AI & spend / Writing Lab / Platform. Merge, move or retire pages per the IA table.
* **AI & spend group.** Brings the providers, routing, budgets and calls pages together, and includes routing by `pii_class` (PII → us).
* **Anthropic.** The Anthropic line is added when the business owner provides the key.
* **Writing Lab, per stage:**
  * samples
  * labels
  * experiments
  * prompt versions
  * eval gate
  * `ai_ops` read of tenant text, logged (R2)
* **AA-subject gate, no LLM:** each tenant article or post must link at least one live AA tour or place, checked at create time and again before publish.
* **Tour retirement fan-out.** The event `catalog.tour_liveness_changed` (ADR 0015):
  * hides the tour in TripPlanner;
  * cancels pending publishes;
  * flags published posts;
  * sends the tenant an in-app notification plus an e-mail digest.

## Done-when

* Admin nav shows the new groups; every old route redirects.
* A tenant post without an AA subject is refused before publish.
* Retiring a test tour hides it in TripPlanner and notifies the synthetic tenant (bell + e-mail).
* Writing Lab shows one stage end to end.
* Screenshots at 1440/390, light and dark.
