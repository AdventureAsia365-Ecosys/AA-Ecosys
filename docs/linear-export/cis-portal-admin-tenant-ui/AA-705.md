Nghiệp (S207, 01/10/2026): the Dashboard → SEO Intelligence tab is too thin (3 KPIs, a country table, a short keyword list). Rebuild it as its own page on the UI v2 kit ([AA-662](https://linear.app/aa-ecosys/issue/AA-662/ui-kit-shared-adminportal-components-datatable-filter-sort-columns)).

## Data sources (merge both — the main reason the page looks poor today)

* **Segment research** (`acp_contract.search_demand`, PAA landings, scores) — \~4,849 keywords with real volume per market (US/UK/AU/DE/FR/NL).
* **S1 seo_context** — per-tour seed, keyword ideas (now multi-seed + relevance-filtered, [AA-702](https://linear.app/aa-ecosys/issue/AA-702/admin-ui-audit-fix-broken-notifications-list-inconsistent-countscosts)), PAA, related keywords.
* **dfs_call_log** — spend, cache hits; **published_tours.seo_keywords_used** — what the content actually used.

## Tabs

1. **Overview** — KPIs: % published tours with ≥1 keyword that has volume, total monthly demand per market, PAA questions found, research spend (period), data freshness (median age, % expired). Demand by country × market chart.
2. **Keywords** — DataTable: keyword, market, volume, CPC, competition, source (S1 / Segment), tours using it, used-in-content yes/no; filters by country/market/source, sort, CSV.
3. **Questions (PAA)** — questions travellers ask, which tours/segments land them, which are unanswered.
4. **Gaps** — published tours with no keyword that has volume, expired data, never researched; each row links to the research action.
5. **Spend & cache** — DFS cost per keyword/tour/day, cache hit rate, by endpoint.

## Done when

Page live on Dev with real data from both sources, Playwright check, numbers reconcile with External Spend (DFS) and published counts (119-style totals must match Master Content).
