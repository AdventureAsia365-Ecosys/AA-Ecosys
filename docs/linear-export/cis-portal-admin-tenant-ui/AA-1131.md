## Problem

The S283 UI audit (`docs/audits/2026-11-17-S283-fe-audit/README.md` section 6, batch K1) found accessibility gaps in shared kit components, so the same fault appears in all four apps.

## Scope

1. **K1 Kit accessibility** (M, top 6), in the CIS canonical `_kit/core`, then `tools/kit/kit-sync.sh` to every app: DataTable page-size `aria-label`; keyboard-openable rows when `onRowClick`; Drawer name, initial focus, focus trap and return; PageHeader text basis; PageFrame `main` `position: relative`; sidebar footer pinned; dark-mode danger badge tone; Select needs a name; an axe / role-name check in UI smoke.
2. **H1 Audit harness** (XS): keep the S283 audit scripts reusable in skill `aa-ui-verify` (fresh login before each app, sequential runs).

## Done when

* Kit change synced to all apps (kit drift check green), UI smoke with the axe check green in every app, screenshots of Drawer and DataTable keyboard use.
