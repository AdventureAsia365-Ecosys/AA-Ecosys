# AA-907 — [CIS] Bump langchain / langgraph and drop chromadb before the pip-audit ignores expire (30/11, 31/12)

## Problem

`.github/pip-audit-ignore.txt` (AA-CIS-App, [AA-868](https://linear.app/aa-ecosys/issue/AA-868/ci-cis-cideploy-hardening-blocking-pip-audit-deploy-concurrency-fail)) accepts four findings with an expiry; `pip_audit_gate.sh` turns Security Audit + Unit Tests red once an entry expires:

* PYSEC-2026-4240 langgraph-sdk 0.3.15 (fix 0.4.4), pulled in by `langgraph==1.1.8` — expires **2026-11-30**.
* PYSEC-2026-2192 langchain 1.2.15 (fix 1.3.9), pipeline dependency — expires **2026-11-30**.
* PYSEC-2026-3813 / 3814 chromadb 0.4.24, no fixed release; only `shared/rag/client.py` imports it and no runtime code imports that module — expires **2026-12-31**.

No issue tracked this (S244 master plan, gap list). Placed in Data Platform because CIS Core is at 96/100 unarchived issues.

## Scope

1. Bump `langgraph` (and with it `langgraph-sdk` ≥ 0.4.4) and `langchain` ≥ 1.3.9; adjust `langchain-core` / `langchain-community` / `langgraph-checkpoint-postgres` as needed.
2. Remove `chromadb` and `shared/rag/client.py` (or the RAG stub) after a grep proving no runtime import.
3. Delete the four ignore lines.
4. Regression: unit + integration suites, plus a 3-tour S1 rewrite run on Dev (job on the worker; cost logged, \~$0.30) compared with the last run.
