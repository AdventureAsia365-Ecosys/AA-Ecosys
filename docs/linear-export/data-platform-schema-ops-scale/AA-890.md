# AA-890 — [CI] PR template, PR title lint and squash-only settings in all repos — plus Infra .bak cleanup

## Problem

PRs have no shared template (risk, rollback, cost, docs), Booking/TripPlanner commit-convention compliance is lowest, all 5 repos still allow merge commits and CIS has \~730 stale remote branches (S243 guide §7 N3/N8/N11).

## Scope

* `.github/pull_request_template.md` (What/Why + Refs, Risk & rollback, Cost, Docs checklist) in all 5 repos.
* Semantic PR title check in Booking and TripPlanner.
* `delete_branch_on_merge=true` and squash-only (merge commit + rebase off) on all repos; prune merged remote branches.
* Delete Infra `main.tf.bak`, `main.tf.bak2`, empty `envs/dev`.

## Done when

* `gh api repos/<org>/<repo>` shows the settings on all 5 repos.
* A new PR shows the template.
