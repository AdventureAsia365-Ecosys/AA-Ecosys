## Problem

There is no prod design: Dev is single-AZ, PITR 7 days, roles not split, DSN not on a private name, no environment model ADR. Trigger: a go-live date is set (D-16/D-17, default acc2).

## Scope

1. ADR 0012 environment model (dev/prod on acc2, Infra env rename, Terraform layout).
2. Prod blueprint: own instance, Multi-AZ, PITR 14 days, cross-region AWS Backup, quarterly drill, RPO/RTO (DM-9.6); roles split from day one, master break-glass only, Enhanced Monitoring, pgaudit (D-08); DSN via private CNAME; NAT GW per AZ, internal ALB, default VPC removed; Security Hub FSBP + Config; agent has no prod access; rotate master/GitHub tokens (D-02/D-03).
3. One reconciled monthly cost (C3 estimate \~150–300 USD), quoted before any apply (D-19).

Prerequisites: X1 done ([AA-860](https://linear.app/aa-ecosys/issue/AA-860/security-x1-split-the-cis-runtime-role-cis-owner-owns-tables-cis-app) + [AA-852](https://linear.app/aa-ecosys/issue/AA-852/data-per-app-db-owner-roles-db-migrator-task-def-bk-owner-tp-owner)), restore drill (done S241), N3 remainder.
