## Problem

Workflow runs triggered by `dependabot[bot]` get no Actions secrets, so the "Vercel deploy" preview job always fails with `VERCEL_TOKEN is not set` (seen 19/10 on Booking #38/#40/#44 and TripPlanner #102/#104). Every Dependabot PR looks red although tests pass, which trains people to ignore red checks.

## Scope

* In the Vercel preview workflows of AA-Booking, AA-TripPlanner-Web and AA-CIS-App (admin + portal): skip the job when `github.actor == 'dependabot[bot]'` (job-level `if:`), and report a neutral/skipped status instead of failure.
* Do **not** give Dependabot the Vercel token as a Dependabot secret (a dependency update must not run with deploy credentials).
* Keep the build/lint/test jobs running for Dependabot PRs.

## Done when

* A Dependabot PR in each repo shows the Vercel job as skipped and all other checks green (links).
* A normal PR still deploys its preview.
