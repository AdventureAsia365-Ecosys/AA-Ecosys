## Problem

Nothing checks docs today: broken links, stale pages, literal resource IDs in the public CIS repo and multi-line AWS CLI commands (which hang WSL) all slip in. S243 proposal §2.6 (`docs/audits/2026-10-19-S243-sdlc-docs-versioning/docs-standard-proposal.md`).

## Scope

* Root `.github/workflows/docs-lint.yml` (the root repo's first workflow, no AWS access): front-matter schema, internal link check (lychee offline), weekly external links, freshness report `docs/generated/freshness.md` (warn > review_every_days; runbook last_tested > 180 d), resource-ID regex (`arn:aws:` warn-only in private repos, blocking in public repos), multi-line AWS CLI check, ADR status lint, gitleaks on docs.
* Smaller job in Infra and the app repos (links + ID regex).
* `docs/adr/README.md` index in CIS, Booking, TripPlanner, Infra.

## Done when

* A test PR adding an `sg-` ID or a backslash-continued `aws` command fails.
* The freshness report is generated on schedule.
