# AA-868 — [CI] CIS CI/deploy hardening: blocking pip-audit, deploy concurrency, fail-closed guard

## Problem

S241 P0-7: the required "Security Audit" check in CIS runs `pip-audit ... || true`, so it can never fail. `deploy-dev.yml` has no `concurrency`, and 40/550 runs overlapped (one failed on the same-SHA step). The `shared.job` deploy guard passes when its credential is missing.

## Scope

1. Remove `|| true`; use an `--ignore-vuln` list with expiry dates (Booking pattern).
2. `concurrency: {group: deploy-dev-cis, cancel-in-progress: false}` on the deploy workflow.
3. `shared.job` guard fails closed when the credential is missing or the gate call errors.
4. Keep `--desired-count 1` in `deploy_family.sh` and add a comment with the reason (wakes a service scaled to 0).

## Done when

* A run with a non-ignored vulnerability fails Security Audit (run link), and `main` is green with the expiring ignore list.
* Two deploys dispatched back to back run one after the other, not overlapping (run links).
* The guard step exits non-zero when the credential is empty (test run or script test), and a normal `main` deploy reaches rollout COMPLETED with `/health` 200.
