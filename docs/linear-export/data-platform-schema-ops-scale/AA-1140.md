## Problem

`/admin/overview` mixes ops, month-to-date finance, content inventory and tenants in one scroll. It has no page-level verdict, eight different time windows, three cost totals that disagree, raw alert codes, no Partner CRM, no ECS/RDS, no `booking.job` / `crm.job`, and hard-coded thresholds. The tech lead cannot see at a glance whether the ecosystem is healthy now and what happened in the last 24 h (S285 advisory `docs/audits/2026-11-19-S285-session/advisory-ops-overview.md`).

## Scope

Build the "Ecosystem status" page approved by the tech lead on 19/11 (mockup v2: [https://claude.ai/artifact/7xYvpcrux9thE3K7sPXJVL](<https://claude.ai/artifact/7xYvpcrux9thE3K7sPXJVL>)), on the CIS admin at the same route, using the UI kit:

 1. One verdict at the top ("All systems normal" / "N things need you") with the attention list (severity, runbook link).
 2. App tiles for CIS, TripPlanner, Booking, Partner CRM: requests, 5xx, 4xx, p95, 24 h business activity, deployed SHA, ready state.
 3. Golden-signal charts on one time axis with deploy markers and alarm bands.
 4. Services and data grid: every ECS service and Lambda, rollout, version, uptime strip against an SLO; RDS USE tiles.
 5. Job queues (`shared.job`, `booking.job` through its owner view, `crm.job` through the CRM ops read), deploy gate state, top failing kinds.
 6. AI gateway spend per app and per connection against caps; cost card (month to date, budget, forecast).
 7. Event timeline (deploys, alarms, ops checks, job failures, guards, cap hits) and delivery / nightly guards.
 8. Page controls: time range (1 h, 6 h, 24 h, 7 d, custom), app filter on every section, severity/status filters, sort on every list, legend tick boxes per chart (show/hide, only, reset), compare with the previous period, view state in the URL.
 9. Every chart shows its thresholds (warn, critical, capacity or cap) and a headroom line; every threshold is a `cis.ops.*` setting or the CloudWatch alarm's own limit.
10. One server endpoint aggregates the sections with `as_of` per source; a 5-min sampler (`shared.ops_sample` / `shared.ops_event`) for ECS state and alarm diffs, 0 USD. No cross-app grant beyond the owner views the apps already expose.
11. What moves off the page: cost tables, content inventory, pipeline funnel, tenant quotas go to Spend, Data coverage and Tenants.

## Done when

* The page is live on Dev at `/admin/overview`, read at 1440 / 390, light / dark, EN / VI, with screenshots (aa-ui-verify).
* Each section reads real Dev data with its `as_of`; a signal not wired yet shows "not measured yet", never green.
* Every chart draws its thresholds from Settings or the alarm and a headroom line.
* Filters, time range, legends, sort, compare and URL state work as in the mockup.
* 0 USD new AWS spend.
