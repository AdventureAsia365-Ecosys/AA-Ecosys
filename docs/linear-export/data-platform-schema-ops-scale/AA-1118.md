## Problem

The S282 audit (R12, R19, R20, R21, R24, R26, R35, R37, G16, G36) found that the docs drift from reality:

* Runbooks have no `last_tested`.
* Some pages keep stale phrases.
* `alarms.md` prints load-balancer and target-group IDs.
* The free-tier limits are not written down.
* `features.yaml` has no planned rows and no "proven" field.
* `plan.json` drifted: for example M-OD shows 0/4 but is 4/4.
* CIS `CONTEXT.md` is too long.
* The postmortem template has no detected/resolved times.

## Scope

* Every runbook gets `last_tested`, or is marked untested.
* A stale-phrase lint.
* Mask the IDs in `alarms.md`.
* A free-tier limits table in `finops.md`.
* `features.yaml`: planned rows and a "proven" field.
* `plan_sync.py` fails CI on drift.
* Split CIS `CONTEXT.md`.
* Add `detected_at` / `resolved_at` to the postmortem template.

## Done when

All the lints are green and the listed pages are updated.
