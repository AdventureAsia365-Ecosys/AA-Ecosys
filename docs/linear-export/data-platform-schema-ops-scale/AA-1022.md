## Problem

The S261 architecture review (items N10, d, N11 free part, G12) found free hardening gaps with no issue: S3 traffic from private subnets goes through the NAT instance, the NAT instance has no auto-recover, Infra workflows use action tags (`@v4`, `@v6`, `@v7`) instead of pinned SHAs, the GitHub OIDC trust has no ref condition, and CIS has no Dependabot for GitHub Actions. Mapping: `docs/audits/2026-11-01-S262-assessment-followup/README.md` §5 P3. Approved by the tech lead in S263 (free and simple).

## Scope

* S3 gateway VPC endpoint on the acc2 Dev VPC route tables (free; bucket policies unchanged).
* CloudWatch EC2 recover action (status check failed system) on the NAT instance.
* Pin every third-party action in AA-CIS-Infra workflows to a commit SHA (comment with the tag).
* OIDC role trust: restrict `sub` to the expected repo refs/environments.
* `.github/dependabot.yml` package-ecosystem github-actions for AA-CIS-App.
