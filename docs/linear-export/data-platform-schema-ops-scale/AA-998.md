## Problem

acc1 (867490540162, profile `pqnghiep-admin` / `acc1-legacy-default`) is Nghiệp's **personal** AWS account. Its compute/network was destroyed on 09/07/2026 (AA-271), but it is still part of the ecosystem: it is the **fallback LLM satellite** (role `AA-Bedrock-Invoker`, AA-296, `shared/llm_client/bedrock_satellite.py`), it is in Terraform (`accounts/acc1-bedrock/`), and secrets/policies there may still be referenced. Its bill is under 1 USD/month today, but Nghiệp wants **no personal money spent at all**: the ecosystem must run on **acc2 (infrastructure) and acc3 (Bedrock)** only.

## Scope

1. **Audit (read-only, every repo + live account)**
   * Code: every reference to acc1 in AA-CIS-App, AA-Booking, AA-TripPlanner-Web, AA-Partner, AA-CIS-Infra and the root repo — account id, profile names (`pqnghiep-admin`, `acc1-legacy-default`), role ARNs (`AA-Bedrock-Invoker`), `bedrock_satellite` fallback routing, `shared.llm_role_config` / `llm_model_catalog` rows that route to acc1, env vars and task definitions, CI workflows, scripts, docs/runbooks, skills, memory.
   * Live acc1 inventory (read-only): every service with resources or cost in the last 90 days (Cost Explorer by service), IAM users/roles/policies, Secrets Manager, SSM parameters, KMS keys, S3 buckets (incl. Terraform state), CloudTrail, CloudWatch logs/alarms, SNS, budgets, Bedrock model access / provisioned throughput, any leftover from AA-271 / [AA-517](https://linear.app/aa-ecosys/issue/AA-517/infra-djieu-tra-chi-phi-rds-secrets-manager-lac-tren-acc-1).
   * Report in `docs/audits/<date>-S<nnn>-acc1-removal/` with a table: object → used by → replacement on acc2/acc3 → delete step.
2. **Cut over**: route the LLM fallback to acc3 (or drop the fallback by an explicit decision), remove acc1 from `shared.llm_role_config` / model catalog / gateway code and tests, remove the acc1 Terraform root and its state after the resources are gone, remove profiles and docs references (CLAUDE.md, skills, runbooks, memory).
3. **Delete on acc1** (DRY RUN list first, per `skill/aa-cis-schema/references/destructive-ops.md` spirit): IAM roles/policies/users created for the ecosystem, secrets (with the shortest recovery window), buckets (after export of anything needed), logs, alarms, budgets, KMS keys (schedule deletion), Bedrock settings. Keep the account itself only if Nghiệp wants it for personal use.
