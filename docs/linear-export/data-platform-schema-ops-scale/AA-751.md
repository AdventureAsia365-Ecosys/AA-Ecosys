# AA-751 — [Jobs] X6 per-owner job tables (ADR 0003a): DDL template + comparison test, booking.job parity, Booking deploy guard, DB Migrate idle check, backlog-age alarms, acp_runs readers

## Re-scoped to roadmap X6 (S240, 16/10/2026, Nghiệp: "làm tiếp [AA-751](https://linear.app/aa-ecosys/issue/AA-751/jobs-x6-per-owner-job-tables-adr-0003a-ddl-template-comparison-test)")

The original premise, granting `shared.job` to a second repo, is superseded by **ADR 0003a** (one job table per owner schema, root `docs/adr/0003a-per-owner-job-tables.md`). The S238 proposal (comment below) is the scope.

## Scope

1. **Reference job DDL template** in `apps/AA-CIS-App/shared/jobs/`:
   * columns (CIS 174 shape), status set, kind-prefix CHECK, lease CHECK, `updated_at` trigger;
   * indexes, including the `finished_at` retention index;
   * queue autovacuum settings.
     Per-owner CI test comparing each `<schema>.job` with the template (CIS, Booking).
2. `bk-NNN` **on** `booking.job`: add `cancel_requested`, `progress`, `cost_usd`, `parent_job_id` and the `finished_at` index. The Booking runner releases or requeues its running jobs on shutdown.
3. **Booking deploy job guard** in `deploy-dev.yml`: block the deploy while `booking.job` has queued/running rows.
4. **DB Migrate idle check** (AA-CIS-Infra): loop over every owner's job table; refuse `apply` if any is busy, naming the table.
5. **Backlog-age alarm per owner**: oldest queued older than 15 min, or a running job past 2 × its `expected_seconds`. State the monthly cost before applying.
6. `acp_runs` **readers move to** `shared.job`**.**

`tripplanner.job` is created from the template only when TripPlanner cuts its first kind (needed before [AA-861](https://linear.app/aa-ecosys/issue/AA-861/data-tripplanner-outbox-payload-pii-redaction-after-90-days-blocked-on)).

## Done when

* Template + comparison tests green for CIS and Booking in CI.
* `bk-NNN` applied on Dev through DB Migrate.
* A Booking deploy is blocked by a seeded queued `bk_` job, and goes through once the table is idle.
* DB Migrate refuses `apply` while any owner's job table is busy and logs which table.
* Backlog-age alarms exist for `shared.job` and `booking.job` (OK state), one fired + recovered once.
* No runtime reader of `acp_runs` remains.
* ADR 0003 header points to 0003a; `schema-ownership.md` job row + kind prefixes updated.
