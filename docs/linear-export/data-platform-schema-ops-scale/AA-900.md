## Problem

Prompt and model changes have no register, runbook or generated route table; reviewers cannot see which prompt/model version a stage ran (S243 guide §4, P3).

## Scope (narrowed S243, decisions N-4 / N-5)

* Prompt register (id, version, file, stage, eval baseline) and an eval runbook.
* Generated route / model-catalog table (from `shared.llm_role_config` + `shared.llm_model_catalog`).
* Eval runs **by hand / workflow_dispatch** on the [AA-729](https://linear.app/aa-ecosys/issue/AA-729/eval-golden-set-100-samples-from-existing-data-scoring-script-for) golden set (D-23); every call through `LLMClient`, `stage=adhoc_aa900`, with a cost cap. The eval run ID goes in the PR when a prompt/model/route changes.
* Out of scope: the `prompt_version` column — it ships with the ledger v2 migration of [AA-804](https://linear.app/aa-ecosys/issue/AA-804/ai-platform-root-adr-0006-ledger-v2-one-gateway-library-for) (N-5); an automatic per-PR eval gate — only if Nghiệp later approves the recurring spend (N-4, up to \~30 USD/month); the golden set itself ([AA-729](https://linear.app/aa-ecosys/issue/AA-729/eval-golden-set-100-samples-from-existing-data-scoring-script-for)).

## Done when

* The prompt register and runbook exist and the route table regenerates without manual edits.
* One prompt-change PR shows a manual eval run ID and its cost.
