## Problem

API reference is not exported or versioned; a breaking change to a public route would only be noticed by a broken client (S243 guide §4, P2).

## Scope

* CI exports `openapi.json` for CIS and Booking.
* oasdiff on PRs against `main`.
* `response_model` for public routes.
* Publish the spec with the release.

## Done when

A test PR removing a public field fails unless labelled breaking.
