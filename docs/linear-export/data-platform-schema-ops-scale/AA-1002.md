## Problem

The AWS setup grew patch by patch during Dev. Two accounts are billed by two different resellers (infra account via TrueIDC as a member of TrueIDC's org; AI account left eCloudvalley's org on 29/10/2026 and AWS now refuses every Bedrock model, "Error 002"). The company has no AWS Organization of its own, no staging/prod environments, and the whole AI path depends on one provider path. The tech lead has created a new AWS account to become the company's management account and asked (S258, 29/10/2026) for professional, table-driven architecture advice plus the answers the business owner asked for: "an email listing everything we need on AWS" and "a thorough question list" for resellers (Sunny Cloud meeting 30/10).

## Scope

1. **Organization and governance:** management account (new), OU tree, member accounts to create and in which order (log archive, security/audit, shared AI, dev, staging, prod), how to invite existing accounts (infra, AI) as members, IAM Identity Center groups → permission sets → accounts, SCP/RCP/tag/backup policies, budgets, break-glass, access reviews.
2. **Billing:** Billing Transfer vs reseller consolidated billing vs AWS direct, keeping the management account with the company in every case; credits, Marketplace, invoices/VAT, exit.
3. **Environments:** dev / staging / prod (data, sizing, HA, RPO/RTO, access, deploy gates, domains, Vercel/Cognito/Route 53 per env, promotion of the same artifact). Amend ADR 0012 (prod on its own account).
4. **IaC:** reorganize infra/AA-CIS-Infra to current Terraform practice (modules + per-account/env stacks, state per account with S3 native locking, assume-role per account, OIDC per account, plan on PR / apply on merge / prod approval, drift, tflint/trivy, naming + tagging), with a state migration plan that keeps DB Migrate working. Learn from AdventureAsia365/AA-Project-Infra.
5. **CLI profiles:** sso-session based profile convention; retire legacy profiles.
6. **AI / LLM gateway:** plug-and-play multi-provider paths (Bedrock on any account/region, Anthropic API, OpenAI API): a new path = add a credential + enable in admin, no code; cross-provider fallback per stage; cost logging parity; availability card (CIS [AdventureAsia365-Ecosys/AA-CIS-App#1148](https://linear.app/aa-ecosys/review/feat-llm-availability-card-and-fail-fast-on-account-level-llm-refusals-0c430555e106)).
7. **Lifecycle:** roadmap (design → build → test → cost → prod → operations), test plan, cost per account/phase, operations runbooks/cadences, risks, decisions to approve.
8. **Business owner deliverables:** the AWS needs email, reseller question list (table, with "why we ask"), and the reseller comparison sheet (7 options × 18 weighted criteria, editable) on the report page.
   Out of scope: signing any contract, paid services without explicit approval (GuardDuty/Config/Security Hub stay off until approved).
