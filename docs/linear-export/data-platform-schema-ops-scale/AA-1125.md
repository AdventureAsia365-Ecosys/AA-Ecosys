## Goal

The tech lead can see, on Platform › Delivery, how well the merge queues work and where the code is changing. The Delivery page ([AA-1108](https://linear.app/aa-ecosys/issue/AA-1108/devops-platform-delivery-page-cicd-and-dora-per-app-durations-failure)) already shows CI/CD and DORA per app. The tech lead asked in S283 (17/11/2026) for two more tabs.

## Problem

Three repos merge through a GitHub merge queue: AA-CIS-App, AA-Booking and AA-Partner. Nobody can see how long a PR waits in the queue, how often the queue ejects a PR, or what the queue costs in CI time. There is also no view like GitLens or a git map: commit activity, file churn hotspots, who changes what (agent App vs human), and the commit graph per repo.

## Scope

1. **Data, $0, same pipeline as** [AA-1108](https://linear.app/aa-ecosys/issue/AA-1108/devops-platform-delivery-page-cicd-and-dora-per-app-durations-failure)**:** extend the root `delivery-metrics.yml` collector (GITHUB_TOKEN, public repos) to add:
   * merge-queue entries per repo from GraphQL (`mergeQueue`, merge_group workflow runs): time in queue, outcome (merged / ejected / removed), ejection reason, merge_group CI duration and re-runs;
   * git activity per repo: commits per day/week, authors grouped as aa-agent App / ci-bot / release-please / human, files and directories by churn (changes × lines) over 30/90 days, top hotspots, merges per branch prefix (feat/fix/docs/chore).
     Same bundle, served read-only by the CIS API.
2. **Merge queue tab:** per repo, plus an overview:
   * queue wait p50/p95;
   * ejection rate and reasons;
   * time from enqueue to merge;
   * throughput per day;
   * CI minutes spent in merge_group;
   * flaky signals (an ejection then a green re-run).
     Thresholds (green/amber/red) are settings in the Platform › Settings registry, never constants.
3. **Git map tab:**
   * commit-activity heatmap (calendar) per repo;
   * churn treemap or hotspot table by directory/file with drill-down;
   * author-kind split;
   * recent commit graph (main branch, squash merges with PR links).
     Kit components, EN/VI, light/dark, mobile.

Out of scope: private data, paid services, writing anything to GitHub.
