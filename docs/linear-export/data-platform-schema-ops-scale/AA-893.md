## Problem

\~36 CloudWatch alarms e-mail on ALARM/OK but none links to a runbook; network/inventory/IAM facts are hand-copied (with literal IDs) and go stale (S243 proposal §2.3, ARCH/OPS rows).

## Scope

* Step 1: a runbook link in every `aws_cloudwatch_metric_alarm` description + generated `docs/generated/alarms.md`.
* Step 2: root Terraform outputs for VPC, subnets, SGs, RDS, ECS, ALB, NLB, API GW; `docs-gen.yml` in Infra (after apply + nightly, read-only OIDC role) writes `docs/generated/{network,inventory,iam-roles}.md` via a bot PR into root (same pattern as `db-schema-dump.yml`).

## Done when

* Each alarm in `alarms.md` links to an existing runbook.
* Zero added cost stated in the PR.
