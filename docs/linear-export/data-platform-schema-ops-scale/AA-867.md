# AA-867 — [Security] Free GitHub security features, org 2FA, force-push and branch-deletion block

## Problem

S241 P0-4: secret scanning, push protection, Dependabot, CodeQL default setup and private vulnerability reporting are off on the public app repos; Dependabot alerts are disabled on AA-CIS-Infra; the org does not require 2FA and members can create public repos; the archived ACP repo history (if it still exists) was never scanned.

## Scope

1. AA-CIS-App, AA-Booking, AA-TripPlanner-Web (public): secret scanning + push protection + validity checks, Dependabot alerts + security updates, CodeQL default setup, PVR.
2. AA-CIS-Infra and the root repo (private since S241, D-14): Dependabot alerts + updates, `dependabot.yml` for `terraform` and `github-actions`; re-check Infra `secret-scan.yml`.
3. Org: require 2FA; members cannot create public repos.
4. Ruleset on each default branch: block force-push and branch deletion only (no PR/approval requirement during the dev phase, D-13).
5. gitleaks over the archived ACP repo history; rotate findings; delete it or make it private.

## Done when

* `gh api repos/<r>` shows `security_and_analysis` enabled on every public repo; Infra Dependabot alerts endpoint returns 200.
* `gh api orgs/AdventureAsia365-Ecosys` shows `two_factor_requirement_enabled=true`, `members_can_create_public_repositories=false`.
* A test force-push to `main` is rejected on each repo.
* gitleaks report saved in the private audit folder.
