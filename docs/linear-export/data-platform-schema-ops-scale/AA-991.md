## Problem

After the S1 catalogue rewrite ([AA-645](https://linear.app/aa-ecosys/issue/AA-645/eval-claude-sonnet-5-for-writer-stages-t2-generate-t8-angle-gen-t9)), finding what had not followed the new atoms took a manual read-only coverage query (S251, 25/10/2026). Nothing alarms today when a downstream layer falls behind its source, and we have not proven that the automatic paths (new tour → S1 → atoms → segment match → route/ranking → place pass → catalog readers; tour retire/pause → [AA-986](https://linear.app/aa-ecosys/issue/AA-986/tour-retirement-propagation-a-tour-deleted-at-s0a0-hides-every) lifecycle) keep everything in step for a single new or changed tour.

## Scope

1. A nightly freshness probe (same pattern as the [AA-986](https://linear.app/aa-ecosys/issue/AA-986/tour-retirement-propagation-a-tour-deleted-at-s0a0-hides-every) liveness gate, report + alarm) that counts, per active tour: atoms older than Master; atoms without a segment; orphan segments; current routes older than atoms or missing; ranking missing; `geo.tour_place` rows on inactive atoms; place cards missing for place atoms; tenant versions older than Master; expired SEO context. Baseline = the S251 numbers.
2. Thresholds: red on any stale link for a tour changed > 24 h ago (Dev has no traffic, so no grace windows beyond the job run time).
3. **Auto-sync proof**: take one new synthetic tour and one existing tour edited by hand and show, with timestamps, that each layer updates by itself through the job chain (no manual script), and that a retire/pause still propagates ([AA-986](https://linear.app/aa-ecosys/issue/AA-986/tour-retirement-propagation-a-tour-deleted-at-s0a0-hides-every) L1–L7).
4. Wire the probe into the session-start checks (backlog §1) and the master plan tracker.

## Done when

* Probe runs nightly on Dev; first run report attached; alarm tested red → green once.
* Auto-sync proof documented in `docs/audits/` with per-layer timestamps for both tours, and any layer that did not update by itself has a fix PR or a follow-up issue.
* After the other S1 propagation issues close, the probe shows 0 stale links.

Related: [AA-645](https://linear.app/aa-ecosys/issue/AA-645/eval-claude-sonnet-5-for-writer-stages-t2-generate-t8-angle-gen-t9), [AA-986](https://linear.app/aa-ecosys/issue/AA-986/tour-retirement-propagation-a-tour-deleted-at-s0a0-hides-every), [AA-853](https://linear.app/aa-ecosys/issue/AA-853/dataci-schema-drift-diff-against-a-replayed-db-migration-ownership) (drift report pattern).
