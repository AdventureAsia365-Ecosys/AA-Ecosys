## Problem

DM-6.1 requires every PII column to carry a `pii:<class>` tag. Booking and TripPlanner columns holding names, e-mails, phones and inquiry payloads are untagged, so there is no machine-readable PII inventory for the RoPA, erasure runbook or a future lint.

## Scope

1. `COMMENT ON COLUMN ... 'pii:<class>'` for existing PII columns, through owner migrations (`bk-NNN`, `tp-NNN`), Infra byte-copy and DB Migrate (D8).
2. Regenerate `docs/architecture/db-schema-reference.md` from the dump workflow.
3. Produce a RoPA table from the tags (input to the legal packet).

## Done when

* Live dump shows the tag on every PII column in `booking.*` and `tripplanner.*` (list + count in the PR).
* Schema reference regenerated; RoPA table committed in the private root repo.
