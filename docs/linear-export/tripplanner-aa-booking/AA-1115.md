## Problem

The S282 progress report (G19, G4, G9, G23, G24) found that TripPlanner reaches agencies in one live form only: the hosted page `/{slug}/plan`.

* The launcher is part of the basic plan but has no code.
* Agency pages still show "Adventure Asia" strings.
* `html lang` ignores the tenant locale.
* B2C leftovers remain (`/sign-in`, `/trips`).

## Scope

* A launcher snippet a basic-plan tenant copies, which opens `/{slug}/plan`. No iframe; CSP unchanged.
* The agency name in the title, description and `og:site_name`, with a test guard against "Adventure Asia".
* `html lang` follows the tenant locale.
* `/sign-in` and `/trips` answer 404.
* `tp.ai_sessions` enforced.
* A compose-body guard test.

## Done when

* A synthetic agency's site and launcher work live with only its own brand (screenshots).
* The tests and guards are green.
