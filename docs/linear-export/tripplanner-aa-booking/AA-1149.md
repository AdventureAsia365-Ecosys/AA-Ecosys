## Problem

When an agency books a whole tour, Generate does not split it into service bookings per component (hotel, vehicle, guide…); ops add them by hand, and a DB constraint allows one service booking per tour line. Vehicles, guides and meals lack their attributes and quantities. A tour can be sold to agencies before every component has an AA supplier.

## Scope (T15, T16, B12, B13)

* T15: on agency confirmation, snapshot the component list from the quote calculation; Generate splits each component into a service booking grouped by supplier; unique index moves to per component (bk-NNN). Later tour edits do not change sold trips.
* T16: typed columns per service type (vehicle type, max pax per vehicle, from/to, private/shared; guide languages; meal type and menu) with CHECKs, no JSON. Quantity is an editable field with a suggested value; fewer seats than pax blocks sending, more than suggested warns and asks for a reason and shows the added cost. Per-vehicle, per-person tiered and shared-vehicle pricing. Excel gets a Services sheet processed before prices.
* B12: every component has an AA supplier; trip_plans.supplier_id is shown as "Operations contact" (prefilter + emergency number on vouchers), never used for pricing.
* B13: "Can operate" check per tour: block B2B sale when a night lacks a hotel (unless marked no hotel needed), a price is out of date, or a supplier is suspended/blacklisted; warn on a transfer day without a vehicle or a missing guide. Admin exception: chosen rule, reason ≥ 20 chars, expiry default 14 days max 30 (settings), audited, and trips sold under it get an ops task.
