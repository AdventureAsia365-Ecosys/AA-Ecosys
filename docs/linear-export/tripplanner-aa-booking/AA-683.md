# AA-683 — [AAA] Figma review → UI spec aligned with the ecosystem design system (staff admin + customer app)

`docs/AAA/figma_AAA/` has about 110 screens covering:

* activities, countries, destinations, hotels, suppliers;
* trip templates / plans / cases, itinerary builder;
* payments / invoices;
* users / admins, audit logs, notifications, settings.

**Scope:**

* Map each screen to an ERD v2 entity and to a PRD module. Flag screens that no longer fit: country/destination management moves to golden records owned by CIS; templates are synced from CIS.
* Define the page list and navigation for **staff admin** and **customer app**, using the shared DataTable / Drawer / Modal patterns and tokens (same look as CIS admin).
* Add ecosystem-specific screens missing from Figma:
  * trip case legs from TripPlanner (source tours, transfers);
  * catalog sync status;
  * inquiry inbox.

**Output:** `docs/ui-spec.md` in the AA-Booking repo, reviewed with Ms. Thư.
