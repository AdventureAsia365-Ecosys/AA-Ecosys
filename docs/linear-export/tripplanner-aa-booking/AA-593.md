# AA-593 — [UI] Xác nhận ActivityIcon đủ 8 activity (nợ 'icon 6+2')

## Việc (nợ UI từ restructure — 'Icon 6+2 ActivityIcon')

Xác nhận iconography cho activity đầy đủ.

## Kết luận (S182, Kiro) — KHÔNG cần sửa code

`backend/shared/schemas.py` `class Activity(str,Enum)` có đúng **8 giá trị** (trekking, cultural_heritage, wildlife_nature, water_activities, culinary, wellness_relaxation, adventure_sport, local_immersion) — khớp 1-1 với frontend `ACTIVITIES` (types.ts) và `ICONS` map (ActivityIcon.tsx). Không có activity nào rơi vào fallback dot. Icon render ở FilterChips + DestinationPopup.

'Icon 6+2' là mô tả cũ thời emoji map (đã thay bằng SVG line icons từ trước). Đóng như đã hoàn tất.
