## Problem

ADR 0019 d8/d9 (S265). The tech lead chose `all_in_booking`: AA's B2B back office issues every invoice to agencies, both the SaaS subscription and tour settlement. Today `booking.invoices` is B2C only (`bill_to_kind` customer, `trip_case_id` NOT NULL), and the B2C intake is frozen by R0 ([AA-1034](https://linear.app/aa-ecosys/issue/AA-1034/platform-r0-b2b-only-model-adr-0019-b2c-paths-off-by-flag-backlog-re), bk-036). Design: `docs/audits/2026-11-03-S265-ecosystem-restructure/clarifications.md` (TL-9, TL-8, BO-14..17). Related: [AA-1029](https://linear.app/aa-ecosys/issue/AA-1029/pricing-tour-price-chain-ready-for-data-cis-master-tour-booking-trip) (RRP), [AA-1030](https://linear.app/aa-ecosys/issue/AA-1030/pricing-agency-price-tiers-b2b-margin-per-partner-tier-or-contract) (price tiers).

## Scope

* **Schema.** A Booking migration adds:
  * `booking.agency_invoice` (`party_tenant_id`, `invoice_kind` saas|settlement, `e_invoice_no`, recipient snapshot)
  * `agency_invoice_line`
  * `agency_payment` (maker-checker, document required)
  * `invoice_sequence` (AAS- / AAT-)
  * `billing_entity`
  * `tax_rule`
* **Configurable terms.** Deposit %, due days, warn/suspend days, tiers and tax live in config rows editable in admin, not in code (BO-15/16/17 must stay adjustable).
* **Jobs.** `bk_saas_invoice_draft` and `bk_settlement_draft`.
* **CIS link.** View `booking.v_tenant_billing_status`, read by CIS `tenant_billing_tick` (past_due → suspend).
* **Booking CHECK** limits work to `b2b`; nav cleaned up; Partners and Settlement pages; RRP "from" price.
* **VAT e-invoice (Vietnam, Decree 70/2025).** In phase 1 the accountant issues it in the e-invoice software and its number goes into `e_invoice_no`. The provider API comes later (about 1 session).
* **B2C retirement.** The frozen B2C tables get a DRY RUN drop; a maker-checker manual payment slice is ported to the CRM if it has none.

## Done-when

* On Dev, a SaaS invoice and a settlement invoice for a synthetic agency are drafted by the jobs, numbered, recorded as paid by maker-checker, and the agency's billing status reaches CIS.
* No B2C write path is left.
* Tests green; Booking CONTEXT.md updated.
