## Problem

Child prices, cancellation terms, stop-sale and allotment were designed three different ways across the hotel, activity and tour advisories. Booking has no structured restriction or allotment model, and its role set is heavier than a startup needs.

## Scope

* T12: one restriction/allotment table per component (room or service) with inventory type `allotment` / `free_sale` / `on_request` (B8: per AA–DMC contract, room type and date range; release days); tiered cancellation terms and structured payment terms on the contract (offers only override); `pax_type` on prices; one engine precedence order.
* B4: child price = supplier price, else a contracting-set default ratio (editable setting), else adult price with an age note.
* B7: every price stored as net; importer converts "published price + commission %" to net and keeps both source numbers.
* T13 (superseded by the S285 lean-roles decisions): roles now live in [AA-1150](https://linear.app/aa-ecosys/issue/AA-1150/cis-booking-lean-staff-roles-step-1-three-people-role-presets-finance) (step 1), [AA-1155](https://linear.app/aa-ecosys/issue/AA-1155/booking-cis-custom-staff-roles-roles-as-data-one-combined-role-per), [AA-1157](https://linear.app/aa-ecosys/issue/AA-1157/cis-booking-view-as-a-lower-role-read-only-logged-never-changes-the) and [AA-1158](https://linear.app/aa-ecosys/issue/AA-1158/booking-infra-approval-rules-for-a-three-person-team-business-owner). This issue keeps only the stop-sale rule: stop-sale = contracting + admin.

## Done-when

* A test contract with 50 % child price, tiered cancellation and a stop-sale on 24/12 prices correctly: the child line is 50 % and 24/12 returns "on request".
* contracting can set a stop-sale; sales gets 403.
* Migration applied on Dev; CI green, deployed, live check recorded here.
