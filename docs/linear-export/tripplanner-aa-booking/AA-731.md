# AA-731 — [TripPlanner] Harness fixes before real customers — idempotent Send-to-advisor, read v_active_tour_atoms, rerun after waves, renarrate grounding

## Why

PRD v0.3 already gets the core right (event log as source of truth, deterministic category verify, no LLM on browse). Four gaps remain from the Harness Engineering review — all matter once real customers and AA-Booking ([AA-681](https://linear.app/aa-ecosys/issue/AA-681/aaa-trip-case-workflow-mvp-inquiry-versions-v1vn-approved-confirmed)) are on the other end.

## Scope

1. **Idempotent "Send to advisor".** It hands off into AAA ([AA-681](https://linear.app/aa-ecosys/issue/AA-681/aaa-trip-case-workflow-mvp-inquiry-versions-v1vn-approved-confirmed) creates a trip case from the inquiry). Double-click or a retry after a dropped response must not create two trip cases or two advisor emails. Key `(trip_draft_id, last_event_seq)`; store `sent_at` + `handoff_id`; re-send after real edits gets a new key by design.
2. **Read the atom contract, not the table.** Atoms are platform-wide again ([AA-526](https://linear.app/aa-ecosys/issue/AA-526/archt5-di-doi-atomize-sang-a-series-trigger-tai-a3-go-bo-hoan-toan)) and follow Master status through `acp_contract.v_active_tour_atoms` ([AA-713](https://linear.app/aa-ecosys/issue/AA-713/a3-atoms-follow-the-tours-master-content-status-inactivetrashed-tours)). The extraction pipeline should read that view. PRD was written at 31 active tours; Master is now \~277.
3. **Rerun extraction after each rerun wave** and on Master trash ([AA-716](https://linear.app/aa-ecosys/issue/AA-716/a3-raw-tour-discontinuation-cascade-trashing-a-source-tour-must)) so no `itinerary_component` points at an inactive tour. Add a check: 0 components whose `source_tour_id` is not active.
4. **Ground** `renarrate`**.** Customer-facing LLM text must only use facts from the components' `text_extract` — reuse `find_novel_numeric_claims()` (same discipline as A1/[AA-691](https://linear.app/aa-ecosys/issue/AA-691/a1-jev-grounding-check-for-master-content-s1-output-must-be-supported)).
5. **Go-live config:** advisor email is still the test address in PRD §8/§9.1 — move to config and switch before real customers.

## Done when

* Double-submitting Send to advisor yields 1 email and 1 handoff record.
* Component check after the Laos wave: 0 orphaned components.
* A renarrate output with an invented number is caught in a test.
