## Problem

S278 system audit:

* **M20:** `catalog.v_tenant_tour_v1` does not exist yet, so TripPlanner reads the AA catalogue instead of each agency's view (ADR 0019 d10 pending).
* **M21:** an agency's branding leaks onto AA tour pages, and the Sign in button is still shown.
* **M12:** the CIS tour page lacks `source_id`, so Book now may book the wrong tour.

## Scope

1. The view contract `catalog.v_tenant_tour_v1`, versioned as a contract: the tours a tenant adopted, with its rewritten text. CIS owns it. TripPlanner reads it on tenant paths and keeps the AA catalogue on the demo path.
2. Agency branding appears only on that tenant's paths. AA pages show AA branding and no Sign in button.
3. The CIS tour page and its JSON carry `source_id`, and Book now uses it.

## Done when

* A synthetic tenant path lists only its adopted tours with its own text.
* An AA tour page shows no agency branding.
* Book now from a tour page creates the line for the same `source_id`.
* Each item has a live check with screenshots at 1440/390.
