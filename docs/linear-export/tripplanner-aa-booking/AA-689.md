# AA-689 — [EPIC] TripPlanner — Trip.com-style planner on AA data (Jira PR-11)

## Goal

A visual trip planner that works like [Trip.com](<http://Trip.com>)'s Trip.Planner, built only on Adventure Asia data. It keeps AA's own brand: gold/ink colours and the "discreet executive adventures" tone. Every route comes from days of real AA tours, so an advisor can sell it.

This epic tracks the whole plan. Nghiệp approved it on 29/09 (S202).

## Reporting

* Each phase is reported to Ms. Thư separately on Jira, once it has shipped (not beforehand).
* **Jira PR-11 is reported after Phase A is done.**
* Nghiệp reviews every Jira draft before it is posted.

## Phase A — [Trip.com](<http://Trip.com>) layout on existing AA data (in progress)

**Start screen** (left panel, map on the right)

- [ ] **Heading to**: country or destination, with "You might enjoy these places" (AA destinations).
- [ ] **Date/Duration** popover:
  * *Date* tab: two-month calendar;
  * *I'm flexible* tab: days (−/+, presets) and a month.
- [ ] **Preferences** popover:
  * travel companions, style (→ AA activities), pace (→ intensity), accommodation, day rhythm, other needs;
  * fields AA cannot filter on are passed to the advisor.
- [ ] **Create it myself** and **Plan with AA routes** buttons.
- [ ] **My itineraries**: kept in browser storage for guests until Phase B.

**Route choice**

- [ ] Proposal cards (tour names, days, places).
- [ ] The map draws the chosen route by day.
- [ ] "Use this route".

**Editor**

- [ ] Top bar: trip title (editable), departure date, total days, "Built from N AA tours".
- [ ] Tabs **Itinerary | Ideas**. Itinerary chips: **Overview · Day N · To be planned · Notes**, plus add day.
- [ ] Each day has three blocks:
  * **How to get there?**: suggested leg (road km/time, or flight/transfer), gateway airports;
  * **What to see & do?**: AA activities of that tour day, as toggles, with + Add;
  * **Where to stay?**: the AA tour's overnight place.
- [ ] Each day has an editable title and notes, plus extra night and remove day.
- [ ] **Add to Day** panel: search, then Recommend (suggestions along the route) and Saved (To be planned).
- [ ] **Ideas** tab: highlights from AA tours in the chosen country, filtered by activity.
- [ ] **Map**:
  * markers and route lines coloured by day;
  * clicking a day tab frames that day;
  * category toolbar (activities, airports);
  * no tile flood at world zoom (944 HTTP 503s in the production check).
- [ ] Line icons instead of emoji (emoji showed as empty boxes).
- [ ] Mobile layout.

**Done when**

* Playwright on production covers the flow: start → route → editor → activities → add day → reload.
* Screenshots are compared with [Trip.com](<http://Trip.com>).
* [AA-674](https://linear.app/aa-ecosys/issue/AA-674/tripplanner-multi-tour-trip-composition-route-constrained-suggest-next) property test: 20 random pin sets.
* The Jira PR-11 report is drafted, and posted once Nghiệp approves.

## Phase B — Accounts and saved itineraries

- [ ] **Ecosystem ADR** (`AA-Ecosys/docs/adr/`): customer identity on **Amazon Cognito** (acc2, Terraform in AA-CIS-Infra), shared with AAA / AA-Booking later.
- [ ] Sign in with Google, Apple, or an email one-time code (no passwords), like [Trip.com](<http://Trip.com>)'s sign-in.
- [ ] A guest trip is attached to the account at sign-in (existing `customers` / `sessions`).
- [ ] **My itineraries** on the server: auto-saved, with share link and PDF download.

## Phase C — Content enrichment

- [ ] **Photos**. Dev today has 0/1,251 destinations with a cover image, and all 9,046 atoms have empty `media`.
  * The AA marketing team supplies photos (brief sent via Nghiệp).
  * Ingest them to S3, then fill `shared.destinations.cover_image_url` and the atom media.
  * Fallback: Wikimedia Commons / Unsplash, with credit.
- [ ] **AA-preferred stays**, from the 487 "stay" atoms and the overnight places in `tour_day`. No prices; booking belongs to AAA.
- [ ] Optional: ratings and opening hours (Google Places or TripAdvisor, paid), after a cost check.
- [ ] Best months, from `season_note` (478 atoms) plus CIS research.

## Phase D — AI on AA data

- [ ] **Plan with AA AI**: the model picks and explains among deterministic AA route proposals. It never invents a place.
- [ ] **Ask anything about the trip**: a chat grounded on AA tour content, via the Model Gateway, with cost logged.

## Out of scope (belongs to AAA)

Flight and train search, prices, booking, payment. The planner only suggests transfers; the advisor arranges them.
