# AA-592 — [UI] Hover tên nước trong picker → highlight polygon nước trên map (preview)

## Việc (nợ UI TripPlanner từ đợt restructure S181)

Hover tên nước trong picker → highlight tạm polygon nước đó trên map (preview), rời chuột về theo selection.

## Root cause (tại sao nợ treo)

Country picker cũ là `<select><option>` native — `<option>` KHÔNG bắn `onMouseEnter` tin cậy (render tầng OS). Phải đổi picker.

## Đã làm (S182, Kiro) — phương án A (Nghiệp chốt)

* `useTrip.tsx`: thêm `previewCountry` + `setPreviewCountry` vào context.
* `FilterChips.tsx`: đổi country picker sang **custom listbox** (button list, giữ grouping theo region). Hover button → `setPreviewCountry`; rời/click → clear; click ngoài đóng.
* `MapView.tsx`: effect riêng highlight ưu tiên `previewCountry ?? filters.country` → `COUNTRY_ISO` → `country-highlight-fill/line`.
