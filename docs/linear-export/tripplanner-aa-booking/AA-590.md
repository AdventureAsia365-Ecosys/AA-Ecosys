# AA-590 — [#5][MAP] Suggest next place theo itinerary — kết hợp taste-similarity + geography

## Việc (Ms.Thư #5, ưra tiên \*\*\*)

Khi user đã pin điểm, gợi ý điểm kế tiếp dựa trên itinerary: kết hợp độ tương đồng sở thích (đang có) + gần lộ trình (stop cuối).

## Đã làm (S182, Kiro)

`backend/assembly/suggestions.py`:

* Giữ pgvector taste-vector ranking làm nguồn candidate (pull `limit*4`).
* Re-rank kết hợp: `0.6 * taste_rank + 0.4 * geo_score`.
* `geo_score`: khoảng cách km TUYỆT ĐỐI tới stop cuối (ramp NEAR_KM=150 → FAR_KM=1500), không phụ thuộc pool (cách B, Nghiệp chốt).
* `_last_stop_coord`: sequence pinned components (nearest-neighbor) lấy toạ độ stop cuối.
* Không có anchor → degrade về taste order thuần (giữ hành vi cũ).
