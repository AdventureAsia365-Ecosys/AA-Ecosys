## Problem

ADR 0005 (accepted S235) says Booking needs pricing tables before [AA-681](https://linear.app/aa-ecosys/issue/AA-681/aaa-trip-case-workflow-mvp-inquiry-versions-v1vn-approved-confirmed) can send a priced quote, but no issue covers that work. Today `booking.*` has no price, margin or FX data (S236 design review).

## Scope

1. Migration `bk-00x`: `booking.pricing_rules` (channel: b2c_tailor_made / fixed_departure / b2b; target margin, floor margin, peak uplift points), `booking.fx_rates` (base USD → EUR/GBP/AUD/SGD, dated, buffer 2–3%).
2. Manual net cost per version item (column on `trip_case_version_itinerary` or a cost line table).
3. Pure-function engine: sell = net ÷ (1 − margin), card fee built in, FX conversion with buffer, USD rounding to $5; unit tests with fixed examples.
4. Below-floor override requires a reason and writes `booking.audit_logs`.
5. Seed margins from ADR 0005 (30/20, 25/18, 15/10) flagged as "to confirm with Ms. Thư".
   Out of scope: supplier contracts, cost sheets per pax band × season, Excel loader, tax_rules (later slices).

## Done when

* Migration applied on Dev via DB Migrate; `booking.pricing_rules` + `booking.fx_rates` exist (schema reference regenerated).
* Engine unit tests green in CI; a Dev endpoint (staff-auth) returns the computed price for a version with ≥2 items in USD and one other currency.
