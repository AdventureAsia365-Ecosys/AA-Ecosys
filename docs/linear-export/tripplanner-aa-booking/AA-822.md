# AA-822 — [AAA] Wave 2a — suppliers + supplier contracts (bk-008): API + staff admin /suppliers list, form, detail

## Problem

Booking wave 1 (trip cases, versions, pricing) is live, but staff still price every item by hand with no supplier record. Wave 2 (Nghiệp, S236: build all 3 waves) starts with the supplier master data that hotels/services (wave 2b), supplier bookings and bills (wave 3) all reference.

## Scope

* Migration bk-008: `booking.suppliers` (name, kind, country, contact, payment terms, currency, status) and `booking.supplier_contracts` (supplier_id, valid_from/to, currency, terms, document ref), audit columns. Migration-only PR first, then the Infra byte copy, DB Migrate apply, then the code PR (S237 migration flow).
* API: CRUD + list/filter, staff RBAC (admin/sales write, others read), audit log entries.
* Staff admin (frontend/): /suppliers list, create/edit form, detail with Profile / Contracts tabs, CIS UI kit tokens (booking-ui-spec).
* Contracts carry the supplier currency, priced through [AA-810](https://linear.app/aa-ecosys/issue/AA-810/aaa-minimal-pricing-engine-adr-0005-first-cut-pricing-rules-dated-fx) FX rates.

## Out of scope

Hotels/services supply records (wave 2b), supplier bookings and bills ([AA-682](https://linear.app/aa-ecosys/issue/AA-682/aaa-operations-mvp-supplier-bookings-trip-checks-invoices-payment)), document upload storage.

## Done when

* bk-008 applied on Dev (`/booking/health/ready` reports bk-008).
* A supplier and a contract are created, edited and listed through the staff admin on the Vercel preview (screenshots desktop + mobile), and the rows plus audit-log entries are visible through the API.
* CI green, deployed, live check recorded on this issue.
