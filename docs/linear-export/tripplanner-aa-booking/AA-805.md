## Problem

S235 AI-first review: tp_compose narration is the only public, unauthenticated AI surface — no API GW throttling, loads by trip_id only (no session-ownership check), no cache, no spend cap, not labelled AI-assisted. Search embeds queries as search_document (should be search_query) and does not filter inactive tours. The hand-off payload is v1.1-shaped but labelled version 1.

* API GW stage throttling ([tripplanner.tf](<http://tripplanner.tf>)); /narrate checks the session owns the trip; tp\_\* spend_budget hard stop; narration cache keyed by itinerary hash; "AI-assisted" label in the UI.
* Fix the gateway fork's defects until the shared gateway lands (shadow ignored, success-only logging, NULL price → 0).
* [search.py](<http://search.py>): input_type search_query; filter to active tours (v_active_tour_atoms / published master_status).
* [handoff.py](<http://handoff.py>): SCHEMA_VERSION 1.1.
