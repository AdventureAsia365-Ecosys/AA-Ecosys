# AA-904 — [TripPlanner] Planned Next.js 14 → 15 upgrade (replaces Dependabot PR #104)

## Problem

Dependabot security group PR AA-TripPlanner-Web #104 bumps `next` 14.2.15 → 15.5.27 (+ postcss, brace-expansion, source-map-js). It fails `Frontend (lint + build)` with `ERESOLVE` (`eslint-config-next@16` vs `eslint@8.57.1`). A major Next upgrade is not a drop-in Dependabot merge: it changes async request APIs, caching defaults and the ESLint setup, and the frontend still carries security advisories on Next 14.

## Scope

1. Branch from main; upgrade `next` to 15.x (or straight to 16 to match CIS/Booking, decide in the PR), `react`/`react-dom` as required, `eslint` 9 + flat config with `eslint-config-next` of the same major.
2. Apply the Next codemods (async `cookies()`/`headers()`/`params`, fetch caching defaults) and fix the build.
3. Map, search, plan and "send to advisor" flows checked on the Vercel preview (desktop + 390 px).
4. Close Dependabot #104 with a link to this PR.

## Done when

* CI green (lint + build + backend tests) and the preview passes a manual smoke of the four flows with screenshots.
* Deployed to `tripplanner.lumiguides.it.com`; `npm audit` shows no high/critical advisory for `next`.
