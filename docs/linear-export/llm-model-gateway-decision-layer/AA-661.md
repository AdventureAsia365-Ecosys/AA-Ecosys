# AA-661 — [RESEARCH] Jev confidence thresholds — when may Jev block content? Calibration study + 3-zone policy

## Re-scoped (S203, 29/09 — Nghiệp): we calibrate ourselves, for enforce

Method: `docs/architecture/at-series-v2-design.md` §5.

* \~200 samples per question from Dev data, stratified by the current rule's verdict.
* A Jev shadow pass on the sample.
* The agent proposes labels with reasons. Nghiệp reviews ≥ 20% at random plus every agent-vs-Jev disagreement. If more than 10% of the reviewed labels are overturned → re-pose the question.
* Floors are set at ≥ 95% precision on each side; the grey zone keeps today's behaviour.
* The record goes to `docs/calibration/<question>.md`, with `threshold_version` in the DB.
* Agent labels are not independent human labels; every record states this.

## Question (Nghiệp, 28/09)

What confidence threshold lets Jev block or gate content? Ms. Thư measured only **51% agreement** with human labels using an uncalibrated floor of 0.15.

## Method

1. **Labeled set per question.** 200–300 items, stratified (good / bad / borderline), labeled by 2 people. Measure inter-rater agreement with Cohen's κ. If humans disagree (κ < 0.6), rewrite the question before judging Jev.
2. **Shadow data.** Run Jev on the same items, plus the current checker (GPT-4.1 / regex).
3. **Calibration.** Reliability curve (expected calibration error). If needed, apply Platt/isotonic scaling per question.
4. **Choose thresholds by cost of error, per question.**
   * A **block** gate (product truth) needs precision ≥ 0.95 on the "fail" side at the chosen threshold. A false block costs a rewrite and tenant trust.
   * A **warn** gate (style/brand) optimises F1, or recall on "bad" at precision ≥ 0.8.
   * A **pre-purchase filter** (DFS keyword relevance) favours recall on "relevant" (≥ 0.95), so good keywords are not lost. Precision saves money.
5. **3-zone policy.**
   * `p ≥ t_high` → pass;
   * `p ≤ t_low` → fail (block or warn per gate);
   * in between → **abstain** and escalate to the LLM judge (GPT-5.6 Luna).

   Track the abstain rate. Target < 20%, so the LLM spend actually drops.
6. **Promotion rule.** `shadow` → `enforce` only when all of these hold:
   * κ(Jev, human) ≥ 0.6;
   * the target precision/recall above is met on a held-out set;
   * there are ≥ 2 weeks of stable shadow metrics.
7. **Drift monitoring.** Weekly agreement from a small human-labeled sample. Auto-demote to shadow on drop.
