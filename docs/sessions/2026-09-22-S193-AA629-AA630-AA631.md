## Lưu ý kỹ thuật

- **Migration Dev luôn apply qua ECS exec + Python asyncpg script (base64 push), KHÔNG dùng
  psql** — container `api` không có psql client cài sẵn, chỉ có `/usr/local/bin/python3`. Pattern:
  viết script `.py` nhỏ (idempotent, check tồn tại trước khi apply), base64-encode, ghi vào
  `run_*.sh` (tránh escaping lồng nhiều lớp trực tiếp trong lệnh `aws ecs execute-command`), chạy
  qua `control_bash_process`.
- **Thứ tự merge nhiều PR liên tiếp trên cùng nhánh `main`** — mỗi PR merge trigger 1 lần "Deploy
  Dev" riêng; nếu merge nhanh liên tiếp (như AA-629→AA-630 cách nhau ~2 phút), có 2 workflow Deploy
  Dev chạy gần đồng thời — đợi HOÀN TẤT CẢ (không chỉ workflow GitHub Actions "completed success"
  — còn phải verify `aws ecs describe-services` có `rolloutState: COMPLETED` thật, vì đôi khi
  workflow xanh nhưng ECS rollout vẫn đang chạy).
- **Đo threshold/tham số bằng data thật khi có thể, đặc biệt nếu cần chi tiêu thật (DFS/LLM)** —
  PHẢI hỏi Nghiệp xác nhận trước khi tốn tiền, dù nhỏ (~$0.06). Sau khi đo, ghi rõ trong code
  (docstring) bằng chứng đo được + lý do chọn số, không chỉ chốt số suông.
- **Khi tách code dùng chung (brand_fit.py khỏi judge_node.py)**: phải rà kỹ toàn bộ test cũ
  patch theo namespace module cụ thể (`patch("module.ClassName")` chỉ có tác dụng nếu import thật
  đang ở đúng module đó) — nếu không rà, test cũ sẽ pass giả (patch không có tác dụng, gọi LLM
  thật) hoặc fail cứng (AttributeError). Đã gặp cả 2 trường hợp trong phiên này (`test_aa206_judge.py`
  và 4 file khác), phải sửa từng patch target.
- **Terminal WSL vẫn treo lặp lại y hệt các phiên trước** — biểu hiện: lệnh không trả output kịp,
  hoặc trả về output rác lẫn ký tự lặp (do hiển thị lag, không phải lỗi lệnh thật). Cách xử lý
  hiệu quả nhất đã dùng: ghi output ra file trong workspace + poll bằng `grep_search` (không dùng
  `read_file` liên tục vì bị cache "unchanged since last read"), dùng `control_bash_process`
  background thay vì `execute_bash` trực tiếp cho lệnh dài/cần chờ (deploy, CI poll).
- File tạm `.tmp-session/` đã dọn sạch cuối phiên (trừ 1 file cũ `pr-body-aa610-redesign.md` từ
  phiên khác, không đụng).
